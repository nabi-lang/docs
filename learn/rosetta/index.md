# Rosetta: Common Tasks

Small, well-known programming tasks solved in Nabi, in the spirit of [Rosetta Code](https://rosettacode.org): FizzBuzz, a sieve of primes, a Caesar cipher, eight queens. If you know how a task looks in another language, these pages show how it reads in this one. Every block is a complete script, compiled and run when the site is built, with its output under it.

| Page | Tasks |
|------|-------|
| [Text](strings.html) | reverse, palindromes, word counts, a Caesar cipher, columns, split and join, case, patterns |
| [Numbers](numbers.html) | FizzBuzz, Fibonacci, big factorials, a prime sieve, GCD, Roman numerals, parsing, rounding, random numbers |
| [Collections](collections.html) | duplicates, sorting by key, grouping, sets, zip and flatten, largest by a measure, stacks and queues |
| [Algorithms](algorithms.html) | binary search, quicksort, Towers of Hanoi, permutations, eight queens, a shortest path, matrix products |
| [Files and data](files-and-data.html) | `wc`, CSV, a configuration file, JSON, walking a directory, environment variables, running a program |

For numerical and data work, the [science path](../science/index.html) has tutorials for the science packages. Each task links back to the guide only where it uses something new; the guide's [How Do I...](../20-cookbook.html) chapter has short answers to everyday system tasks.
