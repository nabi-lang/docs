# Rosetta: 흔한 문제들

[Rosetta Code](https://rosettacode.org)처럼, 잘 알려진 작은 프로그래밍 문제를 Nabi로 풉니다. FizzBuzz, 소수 체, 카이사르 암호, 여덟 퀸 같은 것들입니다. 다른 언어로 어떻게 푸는지 안다면, 이 페이지들에서 Nabi로는 어떻게 읽히는지 볼 수 있습니다. 모든 블록은 완전한 스크립트이고, 사이트를 빌드할 때 컴파일하고 실행하며, 그 출력이 아래에 있습니다.

| 페이지 | 문제 |
|------|-------|
| [텍스트](strings.html) | 뒤집기, 회문, 단어 세기, 카이사르 암호, 열 맞추기, 나누기와 잇기, 대소문자, 패턴 |
| [수](numbers.html) | FizzBuzz, 피보나치, 큰 팩토리얼, 소수 체, 최대공약수, 로마 숫자, 파싱, 반올림, 난수 |
| [컬렉션](collections.html) | 중복 없애기, 키로 정렬, 묶기, 집합, zip과 펼치기, 기준에 따른 최댓값, 스택과 큐 |
| [알고리즘](algorithms.html) | 이진 탐색, 퀵정렬, 하노이의 탑, 순열, 여덟 퀸, 최단 경로, 행렬 곱 |
| [파일과 데이터](files-and-data.html) | `wc`, CSV, 설정 파일, JSON, 디렉터리 순회, 환경 변수, 다른 프로그램 실행 |

수치 계산과 데이터 작업은 [Nabi로 하는 과학 계산](../22-science.html)에서 과학 패키지별 튜토리얼로 갈 수 있습니다. 각 문제는 새로운 것을 쓸 때만 가이드로 링크를 겁니다. 일상적인 시스템 작업의 짧은 답은 가이드의 [어떻게 하나요](../20-cookbook.html) 장에 있습니다.
