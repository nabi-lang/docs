# E0149: 실행 중인 프로그램이 받을 수 없는 변경

핫 리로드 빌드(`nabi dev`, 또는 `--hot-base`를 준 `nabic build --hot`)는 프로그램이 지금 돌리는 버전과 비교됩니다. 프로그램의 값은 변경 너머로 살아남아 필드 단위로 새 레이아웃에 옮겨지므로, 타입은 다음을 할 수 있습니다.

- 기본값이 있는 필드만 추가합니다(`mana: i32 = 0;`). 살아 있는 모든 값에 그 값이 채워집니다.
- 필드를 빼고, 순서를 바꾸고, 이름을 바꿉니다. 이름을 바꾼 필드는 `#[renamed_from("hp")]`로 옛 이름을 적습니다.
- enum variant를 추가하고, 순서를 바꾸고, 뺍니다.

필드의 타입을 바꾸거나, `#[renamed_from]`에 없던 옛 필드를 적거나, 타입 매개변수를 바꾸거나, struct를 enum으로(또는 그 반대로) 바꿀 수는 없습니다. 프로그램은 옛 코드를 계속 돌립니다. 메시지가 알려 주는 대로 고치거나 다시 시작하세요(`nabi dev`에서 `r`).

```text
error[E0149]: new field `mana` of `Player` needs a default while the program runs
  --> src/lib.nabi:1:12
   |
 1 | pub struct Player {
   |            ^^^^^^
   |
   = help: write `mana: i32 = 0;` (or restart with `r`)
```

필드에 기본값을 줍니다.

```nabi norun
pub struct Player {
    pub name: str;
    pub hp: i32 = 100;
    pub mana: i32 = 0;
}
```

타입이 바뀌는 필드는 새 필드입니다. 따로 이름과 기본값을 주고(`health: f64 = 100.0`) 옛 필드를 빼거나, 다시 시작하세요.
