# E0148: 토큰처럼 보이기만 하는 문자

코드에 ASCII 토큰처럼 보이지만 다른 문자가 있습니다. `-` 자리의 `−`(MINUS SIGN), `"` 자리의 둥근 따옴표, `(` 자리의 전각 `（` 같은 것입니다. 워드 프로세서나 웹 페이지에서 딸려 옵니다. 메시지가 알려 주는 ASCII 토큰을 쓰세요. 빠른 수정이 바꿔 줍니다.

```nabi norun
let d = 10 − 3;
println(f"{d}");
```

```text check=checks/E0148.nabi
error[E0148]: `−` (U+2212 MINUS SIGN) looks like `-` but is another character
  --> main.nabi:1:12
   |
 1 | let d = 10 − 3;
   |            ^
   |
   = help: write `-`
```

ASCII 토큰을 쓰세요.

```nabi
let d = 10 - 3;
println(f"{d}");
```

```output
7
```

닮은 문자는 그것이 닮은 토큰이 있는 곳에서만 알립니다. `−` 자체를 연산자로 등록하는 패키지가 있으면([6.7](../spec/refs-lang/006-meta-system/607-operator-magic.html)) 그 문자는 별개의 토큰이 되고, 아무도 등록하지 않은 연산자 기호는 [E0001](E0001.html)입니다.

관련 코드: [E0001](E0001.html) 소스에 예상치 못한 문자, [E0147](E0147.html) 코드 안의 보이지 않는 문자
