# E0114: 잘못된 리터럴 처리기

`#[literal(..)]` 처리기는 그 종류가 받는 매개변수를 가진 함수여야 하며, 접미사, 우선순위, 반환 타입마다 한 번만 등록합니다. 숫자 접미사와 문자열 접두사는 리터럴에 붙여 쓰는 이름(`95pct`, `date"2024-01-15"`)이며 `%`나 `°` 같은 기호일 수 없습니다. 접미사는 지수와 숫자 구분자로 읽히는 `e`나 `_`로 시작할 수 없습니다. 접미사나 접두사가 붙은 리터럴에는 범위 안에 그 처리기가 있어야 하며, 메시지가 가장 가까운 것을 알려 줍니다.

```nabi norun
let d = 5q;
```

```text check=checks/E0114.nabi
error[E0114]: unknown numeric literal suffix `q` - no `#[literal(number "q")]` handler is registered
  --> main.nabi:1:10
   |
 1 | let d = 5q;
   |          ^
   |
   = help: register one, `#[literal(number "q")] fn ..`, here or as a `pub fn` in a package this one depends on; the suffixes in scope are `i`
```

접미사의 처리기를 등록하세요. 리터럴은 그 처리기 호출이 됩니다([6.5](../spec/refs-lang/006-meta-system/605-literal-magic.html)).

```nabi
#[literal(number "q")]
fn quarter(n: f64) -> f64 { n / 4.0 }

let d = 5q;
println(f"{d}");
```

```output
1.25
```

범위 안의 접미사나 접두사와 조금 다르게 쓰면 "did you mean"과 빠른 수정이 함께 나옵니다. `signal`을 의존성으로 두었다면 `10Hz`에 ``did you mean `10hz`?``가, `table`이 있다면 `dat"2024-01-15"`에 ``did you mean `date`?``가 나옵니다. 백분율은 `%`가 아니라 접미사 이름입니다. `%`는 나머지 연산자입니다.

```nabi norun
let p = 95%;        // 오류: `95%`는 백분율이 아님, `95pct`로 쓰기
#[literal(number "°")]   // 오류: 숫자 접미사는 이름이어야 하고 `°`는 기호
const fn deg(n: f64) -> f64 { n }
```

대신 이름을 등록하세요. `#[literal(number "deg")]`로 등록하고 `90deg`로 씁니다.
