# E0147: 코드 안의 보이지 않는 문자

코드에 아무것도 보이지 않거나 평범한 공백처럼 보이는 문자가 있습니다. 폭 없는 공백이나 결합 문자(U+200B~U+200D), 파일 첫머리가 아닌 곳의 바이트 순서 표시(U+FEFF), 바꿀 문자가 없는 변형 선택자, 채움 문자(U+3164), U+00A0 NO-BREAK SPACE 같은 공백입니다. 똑같아 보이는 두 줄이 다른 뜻이 될 수 있으므로 Nabi는 이 문자들을 코드로도, 이름 안의 문자로도 읽지 않습니다. 문자를 지우거나 평범한 공백을 쓰세요. 문자열 안이라면 이스케이프 `"\u{200B}"`로 쓰세요.

아래 f-문자열 속 이름 가운데에는 폭 없는 공백이 있습니다. 웹 페이지나 채팅에서 복사할 때 흔히 딸려 옵니다.

```nabi norun
let count = 3;
println(f"{co​unt}");
```

```text check=checks/E0147.nabi
error[E0147]: identifier `count` holds the invisible character U+200B ZERO WIDTH SPACE: it reads as `count` but is another name
  --> main.nabi:2:12
   |
 2 | println(f"{co​unt}");
   |            ^^^^^^
   |
   = note: as written: `co\u{200B}unt`
   = help: write `count`
```

문자를 지우세요. 편집기의 빠른 수정이 지워 줍니다.

```nabi
let count = 3;
println(f"{count}");
```

```output
3
```

문자열이나 주석 안의 같은 문자는 오류가 아니라 `hidden_chars` 경고입니다. 읽는 사람이 볼 수 있게 `\u{..}` 이스케이프로 쓰세요. 이모지 시퀀스 안의 ZWJ와 페르시아 문자나 인도계 문자의 ZWNJ는 보이는 그대로이므로 알리지 않습니다.
