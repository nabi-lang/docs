# E0001: 소스에 예상치 못한 문자

어떤 토큰도 시작하지 않는 문자가 소스에 있습니다. 떨어져 있는 `#`나 `$`, 첫 줄이 아닌 곳의 `#!` 줄, 앞에 글자가 없는 결합 부호, 유니코드가 비워 둔 코드 포인트, 범위 안의 어떤 트레이트도 등록하지 않은 `⊛` 같은 연산자 기호입니다. 지우거나 문자열이나 주석 안에 쓰세요. 연산자 기호를 쓰려면 그것을 등록하는 패키지를 의존성으로 두거나, 직접 만든 트레이트 메서드에 `#[infix(..)]`를 붙이세요.

```nabi norun
let price = $5;
```

```text check=checks/E0001.nabi
error[E0001]: unexpected character(s) `$`
  --> main.nabi:1:13
   |
 1 | let price = $5;
   |             ^
```

문자를 지우거나 문자열 안에 넣으세요. 단위가 붙은 숫자는 기호가 아니라 숫자에 붙인 접미사 이름입니다(`5usd`, [E0114](E0114.html)).

```nabi
let price = 5;
println(f"${price}");
```

```output
$5
```
