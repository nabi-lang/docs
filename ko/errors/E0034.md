# E0034: 비공개 항목

항목, 필드, 메서드가 다른 모듈에 비공개(또는 다른 패키지에서 `pub(pkg)`)라서 여기서 쓸 수 없습니다. 비공개 항목은 자식 모듈에서도 보이지 않습니다. 정의한 곳에서 메시지가 알려 주는 공개 범위를 붙이세요. 패키지의 나머지에는 `pub(pkg)`, 다른 패키지에는 `pub`입니다. 아니면 공개 항목을 쓰세요.

```nabi norun
mod geo {
    fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```text check=checks/E0034.nabi
error[E0034]: function `geo::area` is private to module `geo` and cannot be used from `<root>` (add `pub(pkg)` to expose it)
  --> main.nabi:4:12
   |
 4 | println(f"{geo::area(2, 3)}");
   |            ^^^^^^^^^^^^^^^
```

`pub(pkg)`를 붙이세요.

```nabi
mod geo {
    pub(pkg) fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```output
6
```

`pub`을 붙이지 않은 항목은 자기 모듈에 비공개입니다([5.6 가시성](../spec/refs-lang/005-modules/506-visibility.html)).
