# E0127: 외부 도구 실패

nabic는 자체 링커로 링크하며, `NABI_CC`가 C 컴파일러 드라이버를 가리킬 때만 그 드라이버로 링크합니다. 그 드라이버가 시작하지 못했거나, 실행되었지만 실패했습니다. 메시지 뒤에 드라이버의 출력이 따라옵니다. 출력이 가리키는 문제를 고치거나, `NABI_CC`가 가리키는 프로그램이 설치되어 있고 `PATH`에 있는지 확인하거나, `NABI_CC`를 지워서 nabic의 링커로 링크하세요.

바깥 프로그램을 실행하는 단계는 빌드(`build`, `run`, `test`, `bench`)의 링크와 REPL의 호스트 링크뿐이고, 그것도 `NABI_CC`일 때만입니다. 시작하지 못하면 메시지는 ``cannot run the link: <reason>``이고, 실패하면 ``the link failed:``와 드라이버의 표준 에러입니다.
