# E0135: 메서드의 트레잇이 스코프에 없음

메서드는 있지만 여기서 가져오지 않은 트레잇의 것이며, 트레잇의 메서드는 그 트레잇이 스코프에 있을 때에만 닿습니다. help가 보여 주는 대로 `use path::Trait;`을 추가하거나, `Trait::method(x, ..)`로 부르세요.

```nabi norun
mod zoo {
    pub trait Wave { fn wave(self) -> str; }
    impl Wave for i32 { fn wave(self) -> str { "hi" } }
}

println(3.wave());
```

```text check=checks/E0135.nabi
error[E0135]: method `wave` comes from trait `zoo::Wave`, which is not in scope
  --> main.nabi:6:9
   |
 6 | println(3.wave());
   |         ^^^^^^^^
   |
   = help: add `use pkg::zoo::Wave;`
```

트레잇을 가져오세요.

```nabi
use pkg::zoo::Wave;

mod zoo {
    pub trait Wave { fn wave(self) -> str; }
    impl Wave for i32 { fn wave(self) -> str { "hi" } }
}

println(3.wave());
```

```output
hi
```
