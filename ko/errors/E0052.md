# E0052: 호출할 수 없는 값

함수, 클로저, `fn` 값, 그리고 타입이 `ops::Call`을 구현한 값을 호출할 수 있습니다. 이름이 같은 이름의 값이 아니라 함수를 가리키는지 확인하세요.

```nabi norun
let total = 3;
println(f"{total(1)}");
```

```text check=checks/E0052.nabi
error[E0052]: a value of type `i64` is not callable
  --> main.nabi:2:12
   |
 2 | println(f"{total(1)}");
   |            ^^^^^^^^
```

함수나 클로저를 호출하세요.

```nabi
let total = |x: i32| x + 3;
println(f"{total(1)}");
```

```output
4
```

직접 만든 타입은 `ops::Call`로 호출할 수 있게 됩니다. 에러의 도움말이 그 impl을 보여 줍니다. 인자가 하나면 그대로, 여럿이면 튜플로 넘어갑니다.

```nabi
struct Line { a: f64; b: f64; }

impl ops::Call<f64> for Line {
    type Output = f64;
    fn call(self, x: f64) -> f64 { self.a * x + self.b }
}

let l = Line { a: 2.0, b: 1.0 };
println(f"{l(3.0)}");
```

```output
7
```
