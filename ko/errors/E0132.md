# E0132: 잘못된 컴파일러 옵션

컴파일러 옵션에 그 옵션이 받지 않는 값을 주었습니다. 모르는 `-C` 옵션이나 `--emit` 종류, 값이 빠진 옵션, 모르는 `-C target-cpu`, 함께 쓸 수 없는 두 옵션(`--emit` 종류 여럿과 `-o`)이 그렇습니다. help가 무엇을 써야 하는지 알려 주고, `nabic help <command>`가 옵션과 그 값을 보여 줍니다. 옵션 이름의 오타는 가장 가까운 옵션을 알려 주는 사용법 오류입니다.

```text
$ nabi build -C overflow-check
error[E0132]: unknown codegen option `overflow-check`; did you mean `overflow-checks`?
   = help: `-C` takes `overflow-checks[=yes|no]`, `icf[=yes|no]`, `target-cpu=<cpu>`, `target-feature=+f1,-f2` or `subsystem=console|windows`
run `nabi help build` for usage
```

help가 보여 주는 대로 옵션을 쓰세요.

```text
$ nabi build -C overflow-checks=no
```

명령은 아무것도 컴파일하지 않고 멈추며, 사용법 오류처럼 종료 코드 2로 끝납니다. `--message-format=json`이면 그 옵션이 명령줄 어디에 있든 이 오류도 다른 진단처럼 표준 출력에 JSON 한 줄로 나옵니다.
