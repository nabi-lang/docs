# E0041: 타입이 다른 분기

`if`나 `match`의 분기, 루프의 `break`들, 또는 반환 타입을 적지 않은 함수의 반환 경로들이 서로 다른 타입의 값을 냅니다. Nabi는 이들을 위한 합 타입을 지어내지 않습니다. 자리에 합 타입을 적거나(`let v: i64 | str = if c { 1 } else { "a" };`), 반환 타입을 적거나(`-> i64 | str`), 분기의 타입을 맞추세요. 이미 합 타입인 분기는 그 멤버로 셉니다. 다른 분기가 모두 그 합 타입이거나 그 멤버이면 순서와 상관없이 결과는 그 합 타입입니다(`none`과 `i64 | none`은 `i64 | none`, `str`과 `i64 | str`은 `i64 | str`). 하지만 `none`과 `i64`는 여전히 다른 타입입니다. 접미사 없는 리터럴은 다른 분기의 타입을 따르지만(`if c { 1 } else { 2u8 }`은 `u8`, `i32 | none` 옆에서는 `i32`), 정수 리터럴은 실수가 되지 않습니다. `1.0`으로 쓰세요.

```nabi norun
let c = true;
let v = if c { 1 } else { "one" };
```

```text check=checks/E0041.nabi
error[E0041]: `if` branches have different types `i64` and `str` - Nabi does not infer a sum type; annotate the slot (`let v: i64 | str = if ...`)
  --> main.nabi:2:9
   |
 2 | let v = if c { 1 } else { "one" };
   |         ^^^^^^^^^^^^^^^^^^^^^^^^^
```

변수에 합 타입을 적으세요.

```nabi
let c = true;
let v: i64 | str = if c { 1 } else { "one" };
println(f"{v is i64}");
```

```output
true
```

이미 그 합 타입인 분기가 있으면 타입을 적지 않아도 됩니다.

```nabi
let c = false;
let r: i64? = 7;
let v = if c { none } else { r };
println(f"{v ?? 0}");
```

```output
7
```
