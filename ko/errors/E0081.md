# E0081: 잘못된 const 제네릭 인자

const 제네릭 인자의 타입이 틀렸거나 매개변수의 범위를 벗어났습니다. 매개변수 타입의 상수를 넘기세요.

```nabi norun
struct Sep<const C: char> {}

let s = Sep::<97> {};
```

```text check=checks/E0081.nabi
error[E0081]: const argument for `C: char` must be a `char`, found an integer
  --> main.nabi:3:9
   |
 3 | let s = Sep::<97> {};
   |         ^^^^^^^^^^^^
```

매개변수 타입의 상수를 넘기세요.

```nabi
struct Sep<const C: char> {}

let s = Sep::<'a'> {};
println("ok");
```

```output
ok
```

`{ .. }` 인자는 컴파일 시간에 실행됩니다. 실행이 panic하면 에러가 그 메시지와 함께 그렇다고 알립니다(`evaluating the const generic argument panicked: <메시지>`). `const fn`이 받아들이는 값이나 리터럴을 넘기세요.
