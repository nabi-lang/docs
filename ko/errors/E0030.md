# E0030: 풀리지 않는 import

`use`가 존재하지 않는 것을 가리킵니다. 경로를 확인하세요. 경로는 패키지(`pkg::`), 의존성, 표준 라이브러리 계층(`std::`, `core::`, `bare::`) 중 하나에서 시작합니다.

```nabi norun
use std::fss;
```

```text check=checks/E0030.nabi
error[E0030]: unresolved import: `std::fss` does not exist
  --> main.nabi:1:10
   |
 1 | use std::fss;
   |          ^^^
```

경로를 고치세요.

```nabi
use std::fs;

println(f"{fs::exists("no-such-file")}");
```

```output
false
```

관련 코드: [E0027](E0027.html) 값이나 함수를 찾을 수 없음, [E0035](E0035.html) 모듈 파일 문제
