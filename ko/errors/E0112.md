# E0112: 잘못된 연산자 선언

트레잇 메서드의 연산자 속성(`#[infix(..)]`, `#[prefix(..)]`, ..)이 규칙을 어깁니다. 연산자가 될 수 없는 토큰(`′`나 `ℱ` 같은 식별자 글자, 이항 `@`, `~`, `->`를 뺀, 형태가 없는 자리의 고정 토큰), 내장 토큰의 우선순위 지정, 서로 다른 수준의 별칭, `throws`가 붙은 메서드(연산자는 throw하지 않으니 대신 `Result`나 `T | E`를 반환합니다), 고정 연산자의 유니코드 표기(`≤`는 `<=`로 읽히니 대신 `ops::PartialOrd`를 구현합니다), `like` 없는 이항 `->`(`#[infix("->", like = "|")]`로 씁니다)가 그 예입니다. 새 토큰은 `like = "<기존 토큰>"`으로 우선순위를 정합니다.

```nabi norun
trait Before {
    #[infix(">>>", precedence = 3)]
    fn before(self, o: Self) -> bool;
}
```

```text check=checks/E0112.nabi
error[E0112]: `#[infix]` takes only an operator token, `like = ".."` and `swap`: precedence and associativity are fixed by the language
  --> main.nabi:2:5
   |
 2 |     #[infix(">>>", precedence = 3)]
   |     ^^
```

우선순위를 지우세요. 새 토큰은 `like`로 내장 토큰의 우선순위를 빌려 옵니다: `#[infix(">>>", like = ">>")]`([6.7](../spec/refs-lang/006-meta-system/607-operator-magic.html)).
