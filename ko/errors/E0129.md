# E0129: 이 백엔드가 지원하지 않음

코드 생성기가 아직 지원하지 않는 것을 코드가 쓰거나, 타깃이 코드 생성기가 코드를 만들지 않는 타깃입니다. 사양에 `native_backend: false`라고 적힌 사용자 정의 타깃이나, arm64가 아닌 Mach-O 타깃이 그렇습니다([0.6.5](../spec/refs-lang/000-meta/006-platform-targets.html#065-타깃-사양)). 메시지가 무엇이 빠졌는지 알립니다. 그 부분을 다시 쓰거나 내장 타깃으로 빌드하세요.

이것은 프로그램의 실수가 아니라 nabic의 빈틈입니다. 프로그램을 [github.com/nabi-lang/nabi/issues](https://github.com/nabi-lang/nabi/issues)에 알려 주세요.
