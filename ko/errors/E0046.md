# E0046: 없는 메서드나 연관 항목

타입에 이 이름의 메서드, 연관 함수, 연관 상수가 없거나, 이 타입들에 맞는 것이 없습니다. 철자, 그것을 제공하는 트레잇의 `use`, 그리고 바운드를 확인하세요.

```nabi norun
let s = "nabi";
println(s.size());
```

```text check=checks/E0046.nabi
error[E0046]: no method `size` found for type `str`
  --> main.nabi:2:9
   |
 2 | println(s.size());
   |         ^^^^^^^^
   |
   = help: did you mean `len`?
```

help가 제안하는 메서드를 쓰세요.

```nabi
let s = "nabi";
println(f"{s.len()}");
```

```output
4
```

함수나 호출할 수 있는 값을 담은 필드를 `r.f(x)`로 부르는 것도 E0046입니다. 메서드 호출은 필드를 보지 않습니다. help가 `(r.f)(x)`로 쓰라고 알려 줍니다.

다른 플랫폼에만 있는 메서드도 E0046이며, 어디에 있는지 알려 주는 note가 붙습니다([17장](../learn/17-conditional-compilation.html)). 가져오지 않은 트레잇의 메서드는 [E0135](E0135.html)입니다.
