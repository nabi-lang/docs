# E0002: bidirectional control character in source

The source has a Unicode bidirectional control character (U+202A to U+202E, U+2066 to U+2069). These reorder how text is shown, so code can read differently from what the compiler sees. Below, the string `"abcdef"` hides one between `abc` and `def`. Write it as an escape inside a string, `"\u{202E}"`, and delete it everywhere else; the quick fix deletes it. Comments are no exception.

```text check=checks/E0002.nabi
error[E0002]: bidirectional control character U+202E RIGHT-TO-LEFT OVERRIDE in source: it can make code read differently from what the compiler sees
  --> main.nabi:1:17
```

Write the character as an escape:

```nabi
let label = "abc\u{202E}def";
println(f"{label.len()}");
```

```output
9
```
