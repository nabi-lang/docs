# E0124: meta name cannot be resolved

The name of a macro or meta block does not lead to one definition:

- `dep::name!` (or `dep::name` for a meta block): package `dep` defines no such name.
- A bare `name!` that several packages define is ambiguous.
- A bare `name!` of another package that this file does not `use`. A bare name reaches this package's macros and meta blocks, the ones it imports, and the standard library's.
- `use name!;` without its package, or `pub use` of a macro, which cannot be re-exported.

Import the macro or meta block from the package that defines it, `use dep::name!;`, or call it by its path, `dep::name!(..)`.

Related: [E0030](E0030.html) unresolved import, [E0119](E0119.html) invalid meta block
