# E0030: unresolved import

A `use` names something that does not exist. Check the path: it starts at the package (`pkg::`), a dependency, or a standard library tier (`std::`, `core::`, `bare::`).

```nabi norun
use std::fss;
```

```text check=checks/E0030.nabi
error[E0030]: unresolved import: `std::fss` does not exist
  --> main.nabi:1:10
   |
 1 | use std::fss;
   |          ^^^
```

Fix the path:

```nabi
use std::fs;

println(f"{fs::exists("no-such-file")}");
```

```output
false
```
