# E0097: NABION value of the wrong shape

A NABION file (`nabi.nabion`, a config) parses, but a value does not fit what the reader expects: a missing field, a value of the wrong type, or a number out of range. Write the value the message names.

This `nabi.nabion` gives `version` as a number:

```nabion
Package {
    name: "pk",
    version: 1,
}
```

`nabi check` prints:

```text
error[E0097]: `version` must be a string, found an integer
  --> nabi.nabion:3:14
   |
 3 |     version: 1,
   |              ^
```

Give `version` as a string, `version: "0.1.0"`. The NABION format is described in [chapter 11](../learn/11-modules-packages.html).
