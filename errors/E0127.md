# E0127: external tool failed

nabic links with its own linker, unless `NABI_CC` names a C compiler driver to link with. That driver could not start, or it ran and failed; its output follows the message. Fix what the output names, check that `NABI_CC` names a program that is installed and on `PATH`, or unset `NABI_CC` to link with nabic's linker.

The link of a build (`build`, `run`, `test`, `bench`) and the REPL's host link are the only steps that run an outside program, and only under `NABI_CC`. When it could not start, the message is ``cannot run the link: <reason>``; when it failed, ``the link failed:`` and the driver's standard error.
