# E0130: internal compiler error

The compiler hit a state it should never reach. This is a compiler bug; please report it with the code that caused it.

It is always a bug in the compiler, never in your program, and no program is known to trigger it. If you see it, please report it at [github.com/nabi-lang/nabi/issues](https://github.com/nabi-lang/nabi/issues) with the program and the full output.
