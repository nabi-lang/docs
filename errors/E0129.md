# E0129: not supported by this backend

The code uses something the code generator does not support yet, or the target is one it does not generate code for: a custom target whose specification says `native_backend: false`, or a Mach-O target other than arm64 ([0.6.5](../spec/refs-lang/000-meta/006-platform-targets.html#065-target-specifications)). The message names what is missing. Rewrite that part, or build for a built-in target.

These are gaps in nabic, not mistakes in the program. Please report the program at [github.com/nabi-lang/nabi/issues](https://github.com/nabi-lang/nabi/issues).
