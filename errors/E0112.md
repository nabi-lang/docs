# E0112: invalid operator declaration

An operator attribute (`#[infix(..)]`, `#[prefix(..)]`, ..) on a trait method breaks a rule: a token that cannot be an operator (an identifier character such as `′` or `ℱ`, a fixed token at a position it has no form in, binary `@` and `~` aside), precedence on a built-in token, aliases at different levels, a method that `throws` (operators do not throw: return a `Result` or `T | E` instead), or a Unicode spelling of a fixed operator (`≤` is read as `<=`; implement `ops::PartialOrd` instead), or `->`, which between two values already spells `→` (register `→`). A new token gives `like = "<existing token>"` for its precedence.

```nabi norun
trait Before {
    #[infix(">>>", precedence = 3)]
    fn before(self, o: Self) -> bool;
}
```

```text check=checks/E0112.nabi
error[E0112]: `#[infix]` takes only an operator token, `like = ".."` and `swap`: precedence and associativity are fixed by the language
  --> main.nabi:2:5
   |
 2 |     #[infix(">>>", precedence = 3)]
   |     ^^
```

Remove the precedence. A new token borrows the precedence of a built-in one with `like`: `#[infix(">>>", like = ">>")]` ([6.7](../spec/refs-lang/006-meta-system/607-operator-magic.html)).
