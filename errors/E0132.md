# E0132: invalid compiler option

A compiler option has a value it does not take: an unknown `-C` option or `--emit` kind, an option without its value, an unknown `-C target-cpu`, or two options that do not go together (`-o` with several `--emit` kinds). The help says what to write; `nabic help <command>` lists the options and their values. A misspelt option name is a usage error that names the closest option.

```text
$ nabi build -C overflow-check
error[E0132]: unknown codegen option `overflow-check`; did you mean `overflow-checks`?
   = help: `-C` takes `overflow-checks[=yes|no]`, `icf[=yes|no]`, `target-cpu=<cpu>`, `target-feature=+f1,-f2` or `subsystem=console|windows`
run `nabi help build` for usage
```

Write the option as the help shows it:

```text
$ nabi build -C overflow-checks=no
```

The command stops before it compiles anything and exits with code 2, as for a usage error. With `--message-format=json` the error is a JSON line on stdout like any other diagnostic, wherever that option stands on the command line.
