# E0081: invalid const generic argument

A const generic argument has the wrong type or is out of range for its parameter. Pass a constant of the parameter's type.

```nabi norun
struct Sep<const C: char> {}

let s = Sep::<97> {};
```

```text check=checks/E0081.nabi
error[E0081]: const argument for `C: char` must be a `char`, found an integer
  --> main.nabi:3:9
   |
 3 | let s = Sep::<97> {};
   |         ^^^^^^^^^^^^
```

Pass a constant of the parameter's type:

```nabi
struct Sep<const C: char> {}

let s = Sep::<'a'> {};
println("ok");
```

```output
ok
```

A `{ .. }` argument runs at compile time. When it panics, the error says so and carries the message (`evaluating the const generic argument panicked: <message>`): pass a value the `const fn` accepts, or a literal.

Related: [E0082](E0082.html) wrong generic arguments, [E0079](E0079.html) cannot evaluate at compile time
