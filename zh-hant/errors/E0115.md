# E0115: 無效的 `#[intrinsic]`

`#[intrinsic("nabi.OP.TYPE")]` 是給標準函式庫用的，要放在符合該運算形式的函式上。

```nabi norun
#[intrinsic("nabi.add.i32")]
fn add(a: i32, b: i32) -> i32 { a + b }
```

```text check=checks/E0115.nabi
error[E0115]: `#[intrinsic]` on `add`: the intrinsic attribute is for the standard library only
  --> main.nabi:2:1
   |
 2 | fn add(a: i32, b: i32) -> i32 { a + b }
   | ^^
```

移除這個屬性，用 Nabi 寫出函式主體；編譯器會自行最佳化一般的算術運算。
