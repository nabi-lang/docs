# E0041: 分支的型別不同

`if` 或 `match` 的各分支、迴圈的各個 `break`，或沒有寫出回傳型別的函式的各條回傳路徑，產生了不同型別的值。Nabi 不會替它們自行造出和型別：在該位置標註和型別，例如 `let v: i64 | str = if c { 1 } else { "a" };`，或寫出回傳型別（`-> i64 | str`），或讓各分支的型別一致。本身已是和型別的分支以其成員計算：當其他每個分支都是該和型別或其成員之一時，不論順序，結果就是該和型別（`none` 與 `i64 | none` 得到 `i64 | none`，`str` 與 `i64 | str` 得到 `i64 | str`），但 `none` 與 `i64` 仍然不同。沒有後綴的字面值會採用其他分支的型別（`if c { 1 } else { 2u8 }` 是 `u8`；在 `i32 | none` 旁邊則是 `i32`），但整數字面值永遠不會成為浮點數：寫成 `1.0`。

```nabi norun
let c = true;
let v = if c { 1 } else { "one" };
```

```text check=checks/E0041.nabi
error[E0041]: `if` branches have different types `i64` and `str` - Nabi does not infer a sum type; annotate the slot (`let v: i64 | str = if ...`)
  --> main.nabi:2:9
   |
 2 | let v = if c { 1 } else { "one" };
   |         ^^^^^^^^^^^^^^^^^^^^^^^^^
```

以和型別標註變數：

```nabi
let c = true;
let v: i64 | str = if c { 1 } else { "one" };
println(f"{v is i64}");
```

```output
true
```

已經是該和型別的分支不需要標註：

```nabi
let c = false;
let r: i64? = 7;
let v = if c { none } else { r };
println(f"{v ?? 0}");
```

```output
7
```
