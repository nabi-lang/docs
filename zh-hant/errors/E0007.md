# E0007: 字元字面值只能容納一個字元

`'..'` 字面值剛好容納一個 Unicode 碼位，`c'..'` 字面值剛好容納一個位元組。任意長度的文字請用字串 `"ab"`；非 ASCII 的位元組請寫成 `\xHH`。

```nabi norun
let c = 'ab';
```

```text check=checks/E0007.nabi
error[E0007]: char literal must contain exactly one code point
  --> main.nabi:1:9
   |
 1 | let c = 'ab';
   |         ^^^^
```

超過一個字元時，請用字串：

```nabi
let s = "ab";
println(s);
```

```output
ab
```
