# E0038: 與巢狀函式同名的變數

同一個區塊中的變數與巢狀函式使用了相同的名稱。巢狀函式在整個區塊中都可見，因此這個名稱會同時指兩者：替其中一個改名。

```nabi norun
fn main() {
    fn step(x: i32) -> i32 { x + 1 }
    let step = 2;
    println(f"{step}");
}
```

```text check=checks/E0038.nabi
error[E0038]: `step` names both a variable and a nested function in this block
  --> main.nabi:3:5
   |
 3 |     let step = 2;
   |     ^^^
   |
   = help: a nested function is seen in its whole block, so rename one of them: `let step2 = ..` or `fn step2(..)`
```

讓變數或函式各有自己的名稱：

```nabi
fn main() {
    fn step(x: i32) -> i32 { x + 1 }
    let steps = 2;
    println(f"{step(steps)}");
}
```

```output
3
```

對變數的名稱再寫一次 `let` 是可以的：這會建立一個新變數（[5.1.4](../spec/refs-lang/005-modules/501-variable-declaration.html#514-在同一作用域中重新宣告)）。
