# E0119: 無效的元區塊

元區塊的定義或使用違反了規則：它佔用了內建屬性的名稱、它對另一個檔案是私有的、它的主體不是以正確的 `@` 區塊開頭，或它展開成項目以外的東西。請依照訊息的說明修正定義或使用方式。

```nabi norun
#[impl_derive(Clone)] @derive {
    impl Clone for @Self {}
}
```

```text check=checks/E0119.nabi
error[E0119]: `Clone` is a built-in derive; a meta block cannot redefine it
  --> main.nabi:1:1
   |
 1 | #[impl_derive(Clone)] @derive {
   | ^^
```

給這個 derive 一個自己的名稱，例如 `#[impl_derive(MyClone)]`，或使用內建的 `#[derive(Clone)]`。
