# E0144: 整數的負數次方

以整數為底的 `b ** e` 會得到整數，所以指數是 `u32`：`2 ** -1` 會是 `0.5`，沒有任何整數能表示它。改為對浮點數做次方運算（`2.0 ** -1.0`，或 `(x as f64) ** -1.0`），或讓指數保持非負。

```nabi norun
let half = 2 ** -1;
```

```text check=checks/E0144.nabi
error[E0144]: `i64` to a negative power is a fraction, not an integer
  --> main.nabi:1:17
   |
 1 | let half = 2 ** -1;
   |                 ^^
   |
   = help: raise a float instead: `2.0 ** -1.0`
```

對浮點數做次方運算：

```nabi
let half = 2.0 ** -1.0;
let n: i32 = 4;
println(f"{half} {(n as f64) ** -1.0}");
```

```output
0.5 0.25
```
