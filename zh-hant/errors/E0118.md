# E0118: 無效的元樣板

元區塊的樣板用錯了 `@` 記號，例如未知的記號、放在它所需的 `@for_fields` 或 `@for_variants` 之外的記號，或缺少 `(..)` 或 `{ .. }` 的記號。請依照訊息的說明寫出它。

```nabi norun
#[impl_derive(Names)] @derive {
    impl @Self {
        fn names() -> str { @fild }
    }
}
#[derive(Names)]
struct P { x: i32; }
```

```text check=checks/E0118.nabi
error[E0118]: unknown template token `@fild`
  --> main.nabi:3:29
   |
 3 |         fn names() -> str { @fild }
   |                             ^
 ...
 6 | #[derive(Names)]
   | -- in this `#[derive(Names)]`
```

依照 [6.9 樣板記號](../spec/refs-lang/006-meta-system/609-template-tokens.html)所列的拼法寫出記號：這裡是 `@for_fields { .. }` 區塊內的 `@field`。
