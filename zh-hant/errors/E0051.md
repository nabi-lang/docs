# E0051: 無效的展開引數

`f(..x)` 把元組、`List`、`Slice`、陣列或 `Dict<str, V>` 展開成引數，而且需要在編譯時期就能確定被呼叫者。展開上述其中一種，或逐一傳入引數。

```nabi norun
fn sum(xs: ...i32) -> i32 { 0 }

let n = 3;
println(f"{sum(..n)}");
```

```text check=checks/E0051.nabi
error[E0051]: spread into a variadic `...T` needs a tuple, a `List`, a `Slice` or an array, found `i64`
  --> main.nabi:4:12
   |
 4 | println(f"{sum(..n)}");
   |            ^^^^^^^^
```

展開一個集合：

```nabi
fn sum(xs: ...i32) -> i32 {
    let t = 0;
    for x in xs { t += x; }
    t
}

let ns = [1, 2, 3];
println(f"{sum(..ns)}");
```

```output
6
```
