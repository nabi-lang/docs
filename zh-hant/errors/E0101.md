# E0101: 模式中的欄位數量錯誤

元組或變體模式的部分比值多或少。請比對每一個部分，或用 `..` 代表其餘部分。

```nabi norun
let t = (1, 2, 3);
let (a, b) = t;
```

```text check=checks/E0101.nabi
error[E0101]: tuple destructure length mismatch: pattern has 2 elements, value has 3
  --> main.nabi:2:1
   |
 2 | let (a, b) = t;
   | ^^^
```

比對每一個部分，或用 `..` 代表其餘部分：

```nabi
let t = (1, 2, 3);
let (a, ..) = t;
println(f"{a}");
```

```output
1
```
