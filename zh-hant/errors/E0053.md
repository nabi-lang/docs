# E0053: 無效的強制轉型

`as` 在數字、`bool` 與 `char` 之間轉換，也能把沒有酬載的列舉轉成整數；其他轉換都是方法。只有 `u8` 能轉型為 `char`（較寬的值請用 `char::from_u32(n)`），而沒有任何型別能轉型為 `bool`（改用比較：`n != 0`）。使用訊息建議的轉換方法。

```nabi norun
let n = 98u32;
let c = n as char;
```

```text check=checks/E0053.nabi
error[E0053]: only `u8` can be cast as `char`, not `u32`; use `char::from_u32(n)` (`char | none`) for a wider value
  --> main.nabi:2:9
   |
 2 | let c = n as char;
   |         ^^^^^^^^^
```

用 `char::from_u32` 轉換，對於不是字元的值，它會回傳 `none`：

```nabi
let n = 98u32;
let c = char::from_u32(n) ?? '?';
println(f"{c}");
```

```output
b
```
