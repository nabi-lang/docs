# E0052: 值不可呼叫

可以呼叫的有函式、閉包、`fn` 值，以及型別實作了 `ops::Call` 的值。確認這個名稱指的是函式，而不是同名的值。

```nabi norun
let total = 3;
println(f"{total(1)}");
```

```text check=checks/E0052.nabi
error[E0052]: a value of type `i64` is not callable
  --> main.nabi:2:12
   |
 2 | println(f"{total(1)}");
   |            ^^^^^^^^
```

呼叫函式或閉包：

```nabi
let total = |x: i32| x + 3;
println(f"{total(1)}");
```

```output
4
```

你自己的型別可以透過 `ops::Call` 變成可呼叫；錯誤的 help 提示會列出該 impl。單一引數以原樣傳入，多個引數則以元組傳入：

```nabi
struct Line { a: f64; b: f64; }

impl ops::Call<f64> for Line {
    type Output = f64;
    fn call(self, x: f64) -> f64 { self.a * x + self.b }
}

let l = Line { a: 2.0, b: 1.0 };
println(f"{l(3.0)}");
```

```output
7
```
