# E0039: 巢狀項目使用了外層的區域變數

巢狀的 `fn`、`struct` 或 `impl` 不能使用外層函式的區域變數或泛型參數。把值當作參數傳入，或改用可以擷取它的閉包。

```nabi norun
fn wrap<T>(t: T) -> i32 {
    struct Holder { v: T; }
    0
}
```

```text check=checks/E0039.nabi
error[E0039]: `Holder` is declared inside `wrap` and can't use `T`, a generic parameter of `wrap`; declare its own instead: `struct Holder<T>`
  --> main.nabi:2:24
   |
 2 |     struct Holder { v: T; }
   |                        ^
```

讓巢狀項目有自己的參數，或把它宣告在函式之外：

```nabi
struct Holder<T> { v: T; }

fn wrap<T>(t: T) -> Holder<T> {
    Holder { v: t }
}
println(f"{wrap(5).v}");
```

```output
5
```

使用外層函式區域變數的巢狀 `fn` 也會得到同一個錯誤碼；閉包（`let add = |x: i32| x + base;`）則可以擷取區域變數。
