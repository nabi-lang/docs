# E0098: 不窮盡的 match

`match` 必須涵蓋所有值。請為訊息列出的情況加上分支，或加上 `_` 分支；其他套件中標為 `#[non_exhaustive]` 的列舉一律需要 `_`。

```nabi norun
enum Light { Red, Yellow, Green }

fn next(l: Light) -> Light {
    match l {
        Light::Red => Light::Green,
        Light::Green => Light::Yellow,
    }
}
```

```text check=checks/E0098.nabi
error[E0098]: non-exhaustive match on `Light`: `Light::Yellow` not covered
  --> main.nabi:4:5
   |
 4 |     match l {
   |     ^^^^^^^^^
   |
   = help: add `Light::Yellow => ..`
```

為缺少的情況加上分支：

```nabi
#[derive(PartialEq)]
enum Light { Red, Yellow, Green }

fn next(l: Light) -> Light {
    match l {
        Light::Red => Light::Green,
        Light::Green => Light::Yellow,
        Light::Yellow => Light::Red,
    }
}
println(f"{next(Light::Yellow) == Light::Red}");
```

```output
true
```

請見 [3.12.5 窮盡檢查](../spec/refs-lang/003-expressions/312-match-expression.html#3125-窮盡性檢查)。
