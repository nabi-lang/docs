# E0131: lint

lint 發現的問題：程式碼可以編譯，但很可能有錯。它的 note 會指出是哪一個 lint（`#[warn(name)]`、JSON 的 `lint` 欄位）。修正程式碼，或用 `#[allow(name)]` 或 `-A name` 允許該 lint；`nabi lint --list` 會說明每一個 lint。

```nabi norun
fn main() {
    let total = 10;
    let unused = 1;
    println(f"{total}");
}
```

```text check=checks/E0131.nabi
warning[E0131]: unused variable `unused`
  --> main.nabi:3:9
   |
 3 |     let unused = 1;
   |         ^^^^^^
   |
   = note: if this is intentional, prefix it with an underscore: `_unused`
   = note: `#[warn(unused_variables)]` on by default
```

移除這個變數；如果它是刻意留下的，就在名稱前加上 `_`：

```nabi
fn main() {
    let total = 10;
    let _unused = 1;
    println(f"{total}");
}
```

```output
10
```

所有 lint 共用這個錯誤碼。lint 預設是警告；用 `deny`（在 `nabi.nabion` 中、在命令列上用 `-D`，或在原始碼中用 `#[deny(..)]`）會讓它們變成錯誤。最後一則 note 會指出 lint 的名稱，以及它的等級是在哪裡設定的（[6.2.9](../spec/refs-lang/006-meta-system/602-built-in-attributes.html#629-allow--deny--warn-lint-控制)）。設定等級的方法請見[第 16 章](../learn/16-tools.html)。
