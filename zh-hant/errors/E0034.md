# E0034: 項目是私有的

這個項目、欄位或方法是另一個模組的私有項目（或在另一個套件中為 `pub(pkg)`），因此不能在這裡使用；私有項目對子模組也不可見。在定義它的地方加上訊息所指出的可見性：`pub(pkg)` 開放給所屬套件的其餘部分，`pub` 開放給其他套件。或者改用公開的項目。

```nabi norun
mod geo {
    fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```text check=checks/E0034.nabi
error[E0034]: function `geo::area` is private to module `geo` and cannot be used from `<root>` (add `pub(pkg)` to expose it)
  --> main.nabi:4:12
   |
 4 | println(f"{geo::area(2, 3)}");
   |            ^^^^^^^^^^^^^^^
```

加上 `pub(pkg)`：

```nabi
mod geo {
    pub(pkg) fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```output
6
```

沒有標記 `pub` 的項目是其模組私有的（[5.6 可見性](../spec/refs-lang/005-modules/506-visibility.html)）。
