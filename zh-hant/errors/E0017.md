# E0017: 項目放錯位置

項目或陳述式出現在不允許的地方：`impl` 中的 `static`、`extern` 區塊之外的 `static mut`、模組主體中的陳述式，或函式內的巨集匯入。請依照訊息把它移到正確的位置，通常是模組層級。

```nabi norun
mod inner {
    println("hi");
}
```

```text check=checks/E0017.nabi
error[E0017]: expected an item in `mod inner`: module bodies are definitions-only; statements belong in `main.nabi`
  --> main.nabi:2:5
   |
 2 |     println("hi");
   |     ^^^^^^^
```

模組主體只放定義；請把陳述式放進函式：

```nabi
mod inner {
    pub fn hi() { println("hi"); }
}
inner::hi();
```

```output
hi
```
