# E0023: 無效的函式簽章

函式的參數或回傳型別違反了規則：不在最後的可變參數 `...`、協程或 `fn` 值上的 `ref` 參數、沒有會擲回錯誤之參數的 `rethrows`，或測試屬性不允許的簽章。訊息會指出是哪條規則；請修改簽章以符合它。

```nabi norun
fn f(a: i32, ...) -> i32 { a }
```

```text check=checks/E0023.nabi
error[E0023]: `f`: a C variadic `...` parameter is only allowed on a declaration in an `extern "C" { .. }` block
  --> main.nabi:1:1
   |
 1 | fn f(a: i32, ...) -> i32 { a }
   | ^^
```

C 的可變參數只屬於 `extern` 宣告。Nabi 函式要接受任意數量的引數，請用 `...T`：

```nabi
fn sum(xs: ...i32) -> i32 {
    let t = 0;
    for x in xs { t += x; }
    t
}
println(f"{sum(1, 2, 3)}");
```

```output
6
```
