# E0141: 方法的泛型參數與其 impl 的同名

寫在 `impl` 區塊中的方法宣告了一個與 impl 的泛型參數同名的泛型參數（`impl<K> W<K> { fn f<K>(..) }`）：在方法內，這個名稱可能指其中任何一個。重新命名方法的參數（`fn f<K2>`），或移除它並改用 impl 的參數。

```nabi norun
struct Wrap<K> { k: K; }

impl<K> Wrap<K> {
    fn pick<K>(self, x: K) -> K { x }
}
```

```text check=checks/E0141.nabi
error[E0141]: generic parameter `K` of `pick` is already a parameter of its `impl`
  --> main.nabi:4:5
   |
 4 |     fn pick<K>(self, x: K) -> K { x }
   |     ^^
   |
   = help: rename the method's (`fn pick<K2>`), or drop it to use the impl's `K`
```

為方法的參數取一個自己的名稱：

```nabi
struct Wrap<K> { k: K; }

impl<K> Wrap<K> {
    fn pick<U>(self, x: U) -> U { x }
}

println(Wrap { k: "s" }.pick(5));
```

```output
5
```

trait 的預設方法寫在 trait 中，而不是 impl 中，所以它的參數會遮蔽實作該 trait 的 impl 中同名的參數，不會產生錯誤（[2.10.1](../spec/refs-lang/002-types/210-generics.html#2101-參數宣告的位置)）。
