# E0121: 無效的 `cfg` 述詞

`#[cfg(..)]` 或 `cfg!(..)` 的述詞格式不正確。述詞可以是一個旗標（`unix`）、一組 `key = "value"`，或是由這些組成的 `all(..)`、`any(..)` 和 `not(..)`。

```nabi norun
#[cfg(either(target_family = "unix", target_family = "windows"))]
println("desktop");
```

```text check=checks/E0121.nabi
error[E0121]: unknown cfg combinator `either` (`all`, `any`, `not`)
  --> main.nabi:1:1
   |
 1 | #[cfg(either(target_family = "unix", target_family = "windows"))]
   | ^^
```

改用 `all`、`any` 或 `not`：

```nabi
#[cfg(any(target_family = "unix", target_family = "windows"))]
println("desktop");
```

```output
desktop
```

[第 17 章](../learn/17-conditional-compilation.html)列出了所有的鍵。
