# E0140: 指派給不是位置的值

`=` 或複合指派（`+=`、`-=`……）的左側是一個值，而不是位置：呼叫的結果（`f()`、`d.entry(k).or_insert(0)`）、運算子的結果或元組。對它指派，只會修改一個隨即被丟棄的暫時值。請對變數、變數的欄位（`s.x += 1`）或元素（`xs[i] += 1`）指派。要保留呼叫的結果，先繫結它：`let v = f(); v += 1;`。要在字典中計數，使用帶預設值的索引：`d[k, default: 0] += 1;`。鎖守衛的 `get()` 也是複本：用 `g.update(|v| { v.x += 1; v })` 或 `g.set(v)` 修改儲存的值。

```nabi norun
let counts = Dict::new();
for w in ["a", "b", "a"] {
    counts.entry(w).or_insert(0) += 1;
}
```

```text check=checks/E0140.nabi
error[E0140]: cannot use `+=` on `counts.entry(w).or_insert(0)`: a call result is not a place, so the change would be lost
  --> main.nabi:3:5
   |
 3 |     counts.entry(w).or_insert(0) += 1;
   |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^
   |
   = help: index with a default: `counts[w, default: 0] += 1;`
```

`or_insert` 回傳的是計數，而不是字典中的槽位，所以 `+= 1` 只會加到複本上。改用帶預設值的索引；鍵不存在時，它會先存入 `0`：

```nabi
let counts = Dict::new();
for w in ["a", "b", "a"] {
    counts[w, default: 0] += 1;
}
println(f"a={counts["a"]} b={counts["b"]}");
```

```output
a=2 b=1
```

呼叫結果的欄位（`p().x += 1`）和呼叫所回傳的固定長度陣列的元素（`arr()[0] = 5`）也一樣：把值繫結到變數，再修改該變數。呼叫所回傳的 `List` 或 `Dict` 的元素則是位置，因為集合是共用的：`rows()[0] += 1` 會修改 `rows()` 回傳的串列（[3.4.1](../spec/refs-lang/003-expressions/304-assignment.html#341-簡單指派)）。
