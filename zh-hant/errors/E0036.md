# E0036: 無效的程式進入點

程式從 `main.nabi` 的頂層陳述式或 `fn main` 其中之一開始執行，不能兩者都有；其他檔案只放定義。`fn main` 不接受參數，不能是泛型或 `unsafe`，回傳 `()` 或 `i32`；它可以是 `async`，而 `throws` 的 `main` 回傳 `()`。

```nabi norun
fn main(args: List<str>) {}
```

```text check=checks/E0036.nabi
error[E0036]: `fn main`: takes no parameters; read arguments through `std::env`
  --> main.nabi:1:1
   |
 1 | fn main(args: List<str>) {}
   | ^^
```

透過 `std::env` 讀取引數：

```nabi
use std::env;

fn main() {
    println(f"{env::args().len() > 0}");
}
```

```output
true
```

回傳其他型別的 `fn main` 同樣是 E0036，訊息為 `` `fn main`: must return `()` or `i32` ``（[4.16](../spec/refs-lang/004-functions/416-entry-point.html)）。
