# E0006: 字面值中無效的跳脫序列

字串或字元字面值中的 `\` 跳脫序列不是 Nabi 認得的，或是位元組字串中有它無法容納的字元。可用的跳脫序列有 `\n`、`\r`、`\t`、`\0`、`\\`、`\'`、`\"`、`\xHH` 和 `\u{..}`；位元組字串只能容納 ASCII，其他位元組請寫成 `\xHH`（最大為 `\xFF`）。

```nabi norun
println("100\% done");
```

```text check=checks/E0006.nabi
error[E0006]: unknown escape sequence `\%`
  --> main.nabi:1:13
   |
 1 | println("100\% done");
   |             ^^
   |
   = help: the escapes are `\n` `\r` `\t` `\0` `\\` `\'` `\"` `\xHH` `\u{..}`; `%` needs no escape, so write `%` (or `\\%` for a backslash and `%`)
```

`%` 不需要跳脫。要寫出反斜線本身，請寫 `\\`。

```nabi
println("100% done");
```

```output
100% done
```
