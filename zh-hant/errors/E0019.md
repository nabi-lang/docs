# E0019: 需要括號的運算子

比較鏈的運算子必須來自同一組：`<` 與 `<=`（`0 <= i < n`）、`>` 與 `>=`（`a > b >= c`），或 `==`（`a == b == c`）；每一對之間以 `&&` 連接。其他的鏈都是錯誤：混用不同組（`a < b > c`、`a < b == c`）、`a != b != c`、`x ∈ s == y` 以及 `a..b..c`。請用 `&&` 連接各部分（`a < b && b > c`），或加上括號表明你的意思。（對只沿一個軸索引的型別使用多個部分的索引，例如 `xs[1:, 0]`，則是 [E0143](E0143.html)。）

```nabi norun
let a = 1;
let b = 2;
println(f"{a < b > 0}");
```

```text check=checks/E0019.nabi
error[E0019]: `<` and `>` cannot be chained
  --> main.nabi:3:18
   |
 3 | println(f"{a < b > 0}");
   |                  ^
   |
   = help: a chain compares in one direction (`a < b <= c`, `a > b >= c`, `a == b == c`); write `a < b && b > c`
```

用 `&&` 連接兩個比較；同一方向的比較鏈則沒有問題：

```nabi
let a = 1;
let b = 2;
println(f"{a < b && b > 0} {0 <= a < b}");
```

```output
true true
```
