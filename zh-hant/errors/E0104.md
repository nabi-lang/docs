# E0104: 無效的剩餘模式

一個模式最多只能有一個 `..`，而且剩餘模式只能放在訊息所說的位置。請移除多餘的 `..`。

```nabi norun
enum E { A(i32, i32, i32) }

let v = E::A(1, 2, 3);
match v {
    E::A(x, .., y, ..) => println(f"{x}"),
}
```

```text check=checks/E0104.nabi
error[E0104]: pattern `E::A` has more than one `..`
  --> main.nabi:4:1
   |
 4 | match v {
   | ^^^^^^^^^
```

只保留一個 `..`：

```nabi
enum E { A(i32, i32, i32) }

let v = E::A(1, 2, 3);
match v {
    E::A(x, .., y) => println(f"{x} {y}"),
}
```

```output
1 3
```
