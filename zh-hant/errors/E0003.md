# E0003: 格式錯誤的數字字面值

數字字面值的格式不正確：超出其進位的數字（`0b2`）、不在兩個數字之間的 `_`、沒有數字的指數、十進位數開頭的 `0`（`012`）、開頭沒有數字的浮點數（`.5`），或是種類不對的後綴（`1.5i32`）。請依照訊息的建議寫出數字，例如 `0.5`、`1_000` 或 `0o12`。

```nabi norun
let mode = 0755;
```

```text check=checks/E0003.nabi
error[E0003]: `0755`: a decimal literal can't start with `0`
  --> main.nabi:1:12
   |
 1 | let mode = 0755;
   |            ^^^^
   |
   = help: write `0o755` for an octal number, or `755` for decimal
```

依照 help 提示寫出數字，這裡用八進位：

```nabi
let mode = 0o755;
println(f"{mode}");
```

```output
493
```
