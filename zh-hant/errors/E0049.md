# E0049: 無效的具名引數

具名引數（`f(x: 1)`）指定的名稱不是函式的任何參數、把同一個參數指定了兩次、傳給了 `fn` 值（其型別沒有參數名稱），或出現在位置引數之前。使用函式定義中的參數名稱，每個只用一次，並放在位置引數之後。

```nabi norun
fn area(w: i32, h: i32 = 1) -> i32 { w * h }
println(f"{area(w: 2, height: 3)}");
```

```text check=checks/E0049.nabi
error[E0049]: `area` has no parameter named `height`
  --> main.nabi:2:12
   |
 2 | println(f"{area(w: 2, height: 3)}");
   |            ^^^^^^^^^^^^^^^^^^^^^
```

使用定義中的參數名稱：

```nabi
fn area(w: i32, h: i32 = 1) -> i32 { w * h }
println(f"{area(w: 2, h: 3)}");
```

```output
6
```
