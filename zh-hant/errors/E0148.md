# E0148: 只是看起來像語彙單元的字元

程式碼中有一個看起來像 ASCII 語彙單元、實際上卻是另一個字元的字元：用 `−`（MINUS SIGN）代替 `-`、用彎引號代替 `"`、用全形的 `（` 代替 `(`。這些字元來自文書處理器和網頁。寫出訊息指出的 ASCII 語彙單元；快速修正會替你換掉它。

```nabi norun
let d = 10 − 3;
println(f"{d}");
```

```text check=checks/E0148.nabi
error[E0148]: `−` (U+2212 MINUS SIGN) looks like `-` but is another character
  --> main.nabi:1:12
   |
 1 | let d = 10 − 3;
   |            ^
   |
   = help: write `-`
```

寫出 ASCII 語彙單元：

```nabi
let d = 10 - 3;
println(f"{d}");
```

```output
7
```

只有在它所模仿的語彙單元確實存在的地方，才會回報這種相似字元：自行把 `−` 註冊為運算子的套件（[6.7](../spec/refs-lang/006-meta-system/607-operator-magic.html)）會讓它成為獨立的語彙單元，而沒有任何東西註冊的運算子符號則是 [E0001](E0001.html)。
