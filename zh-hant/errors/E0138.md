# E0138: 未寫明的 `pub` 函式簽章

`pub` 或 `pub(pkg)` 函式會被其他模組呼叫，所以它的簽章要明確寫出，而不是從主體推論。為每個參數加上型別，例如 `x: i32`（要接受任何型別時，用型別參數 `fn f<T>(x: T)`）。沒有 `->` 時，函式回傳 `()`；主體產生值時，照 fix-it 的提示寫出它的型別 `-> i32`。例外：私有和 `pub(sub)` 函式仍然使用推論；trait impl 的方法沿用 trait 的型別；`self` 和可變參數 `...T` 不需要型別；`main` 和產生器可以省略 `->`；沒有主體的函式（`extern`）依照所寫的樣子宣告。

```nabi norun
pub fn double(x: i32) { x * 2 }

println(f"{double(4)}");
```

```text check=checks/E0138.nabi
error[E0138]: `pub fn double` has no `->`, so it returns `()`, but its body gives `i32`
  --> main.nabi:1:25
   |
 1 | pub fn double(x: i32) { x * 2 }
   |                         ^^^^^
   |
   = help: write `-> i32` before the body
```

寫出回傳型別：

```nabi
pub fn double(x: i32) -> i32 { x * 2 }

println(f"{double(4)}");
```

```output
8
```
