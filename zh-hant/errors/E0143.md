# E0143: 對只沿一個軸索引的型別使用多軸索引

由多個部分組成、且其中有切片的索引（`m[1:, 0]`）會為每個軸提供一個引數。`List`、`Slice`、固定長度陣列和 `str` 只有一個軸，所以只接受一個部分。把切片和索引分開寫在不同的方括號中（`m[1:][0]`），或把資料放在接受軸引數的 `Array<T, N>`（`core::array::Array`）中。自訂型別要接受軸引數，就要針對由 `isize` 和 `core::index::SliceArg` 組成的元組實作 `Index`。

```nabi norun
let xs = [10, 20, 30, 40];
let y = xs[1:, 0];
```

```text check=checks/E0143.nabi
error[E0143]: `List<i64>` is indexed along one axis, but this index has 2 parts with a slice among them
  --> main.nabi:2:9
   |
 2 | let y = xs[1:, 0];
   |         ^^^^^^^^^
   |
   = help: slice and index in separate brackets (`m[a:b][c]`), or keep the data in an `Array` (`core::array::Array`), which takes `m[a:b, c]`
```

先切片，再對切片做索引，或改用 `Array`：

```nabi
use core::array::Array;

let xs = [10, 20, 30, 40];
let y = xs[1:][0];
let m: Array<i64, 2> = [[1, 2], [3, 4]];
println(f"{y} {m[1:, 0]:?}");
```

```output
20 [3]
```
