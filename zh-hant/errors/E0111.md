# E0111: 無效的 `#[lang]` 項目

`#[lang("slot")]`（僅限標準函式庫）指名一個已知的槽位，只能用一次，而且要用在符合該槽位形式的項目上。

```nabi norun
#[lang("add_trait")]
trait BadAdd { fn plus(self, o: Self) -> Self; }
```

```text check=checks/E0111.nabi
error[E0111]: `BadAdd` does not match the form of lang slot `add_trait`: it needs `fn add(self, _)`
  --> main.nabi:1:1
   |
 1 | #[lang("add_trait")]
   | ^^
```

`#[lang]` 是給標準函式庫用的。程式應改為實作標準 trait：`impl ops::Add for Point` 讓 `Point` 擁有 `+` 運算子。
