# E0149: 執行中的程式無法接受的變更

熱重載建置（`nabi dev`，或搭配 `--hot-base` 的 `nabic build --hot`）會與程式目前執行的版本比對檢查。程式中的值會在變更後繼續存活，並逐欄位移到新的配置中，所以型別可以：

- 新增欄位，但必須有預設值（`mana: i32 = 0;`），預設值會填入每一個存活的值；
- 移除欄位、重新排序欄位或重新命名欄位（重新命名的欄位用 `#[renamed_from("hp")]` 註明舊名稱）；
- 新增、重新排序或移除列舉變體。

型別不能改變欄位的型別、在 `#[renamed_from]` 中指名從未存在過的舊欄位、改變它的型別參數，或從結構變成列舉（或反過來）。程式會繼續執行舊的程式碼；照訊息的建議寫出變更，或重新啟動程式（在 `nabi dev` 中按 `r`）。

```text
error[E0149]: new field `mana` of `Player` needs a default while the program runs
  --> src/lib.nabi:1:12
   |
 1 | pub struct Player {
   |            ^^^^^^
   |
   = help: write `mana: i32 = 0;` (or restart with `r`)
```

為欄位加上預設值：

```nabi norun
pub struct Player {
    pub name: str;
    pub hp: i32 = 100;
    pub mana: i32 = 0;
}
```

型別改變的欄位是一個新欄位：給它自己的名稱和預設值（`health: f64 = 100.0`）並移除舊欄位，或重新啟動。
