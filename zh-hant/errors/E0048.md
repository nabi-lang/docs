# E0048: 引數數量錯誤

呼叫傳入的引數比函式接受的多或少，或漏掉了一個沒有預設值的引數。每個參數各傳一次；有預設值的參數可以省略。

```nabi norun
fn add(a: i32, b: i32) -> i32 { a + b }
println(f"{add(1)}");
```

```text check=checks/E0048.nabi
error[E0048]: missing argument `b` in call to `add`
  --> main.nabi:2:12
   |
 2 | println(f"{add(1)}");
   |            ^^^^^^
   |
   = help: it is declared `add(a: i32, b: i32)`; pass `b` too
```

傳入每個參數，或替最後一個參數提供預設值：

```nabi
fn add(a: i32, b: i32 = 0) -> i32 { a + b }
println(f"{add(1)} {add(1, 2)}");
```

```output
1 3
```
