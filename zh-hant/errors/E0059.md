# E0059: 用在其語境之外的關鍵字

`break` 與 `continue` 只能用在迴圈中，`yield` 只能用在產生器中，`await` 只能用在非同步主體中，`self` 只能用在方法中；`return`、`break` 與 `continue` 不能離開 `finally` 區塊；`break value` 只能離開 `loop` 或帶標籤的區塊，不能離開 `while` / `for`。把程式碼移入這樣的主體中，或移出 `finally`。

```nabi norun
let n = 3;
if n > 2 { break; }
```

```text check=checks/E0059.nabi
error[E0059]: `break` outside of a loop
  --> main.nabi:2:12
   |
 2 | if n > 2 { break; }
   |            ^^^^^
```

在迴圈中使用 `break`：

```nabi
for n in 0..5 {
    if n > 2 { break; }
    println(f"{n}");
}
```

```output
0
1
2
```
