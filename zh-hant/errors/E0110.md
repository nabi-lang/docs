# E0110: 屬性用在錯誤的項目上

這個屬性不適用於這類項目，例如用在泛型函式或沒有主體之函式上的 `#[export_name]`、用在 `main` 上的 `#[track_caller]`，或用在只接受 `#[cfg]` 的陳述式上的屬性。請把它移到適用的項目上，或移除它。

```nabi norun
#[link_name("abs")]
fn my_abs(x: i32) -> i32 { x }
```

```text check=checks/E0110.nabi
error[E0110]: `#[link_name]` cannot be attached to a function; it goes on an extern function
  --> main.nabi:1:1
   |
 1 | #[link_name("abs")]
   | ^^
```

把屬性放在 `extern` 區塊中的函式上：

```nabi
extern "C" {
    #[link_name = "abs"]
    fn my_abs(x: i32) -> i32;
}
println(f"{unsafe { my_abs(-2) }}");
```

```output
2
```
