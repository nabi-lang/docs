# E0031: 有歧義的名稱

多個 glob 匯入（`use a::*;`）或套件都提供了這個名稱，因此無法確定指的是哪一個。用名稱匯入你要的那一個，或寫出它的路徑。

```nabi norun
use a::*;
use b::*;

mod a { pub fn item() -> i32 { 1 } }
mod b { pub fn item() -> i32 { 2 } }
println(f"{item()}");
```

```text check=checks/E0031.nabi
error[E0031]: name `item` is ambiguous in module `<root>` - multiple glob imports resolve it: a::item, b::item
  --> main.nabi:6:12
   |
 6 | println(f"{item()}");
   |            ^^^^^^
```

用名稱匯入你要的那一個：

```nabi
use a::item;

mod a { pub fn item() -> i32 { 1 } }
mod b { pub fn item() -> i32 { 2 } }
println(f"{item()}");
```

```output
1
```
