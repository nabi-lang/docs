# E0109: 格式錯誤的屬性

屬性的引數不是它所接受的形式，或者這個屬性不是 Nabi 認得的屬性。訊息會給出正確形式，例如 `#[path("file.nabi")]`。

```nabi norun
#[inlin]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```text check=checks/E0109.nabi
error[E0109]: unknown attribute `#[inlin]`: not built in and no meta block defines it
  --> main.nabi:1:1
   |
 1 | #[inlin]
   | ^^
```

依照 [6.2 內建屬性](../spec/refs-lang/006-meta-system/602-built-in-attributes.html)所列的拼法寫出屬性：

```nabi
#[inline]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```output
4
```

既不是內建、也不是由作用域中的元區塊定義的屬性，就是未知的屬性（[6.1.6](../spec/refs-lang/006-meta-system/601-attribute-syntax.html#616-未知的屬性)）。
