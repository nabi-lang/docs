# E0123: 重複註冊

同一個符號、運算子、lang 槽位、關鍵字或字面值處理器被兩個項目註冊。只保留一個。

```nabi norun
#[keyword("twice")]
fn twice_a(x: i32) -> i32 { x * 2 }
#[keyword("twice")]
fn twice_b(x: i32) -> i32 { x + x }
```

```text check=checks/E0123.nabi
error[E0123]: keyword `twice` is registered twice
  --> main.nabi:3:1
   |
 1 | #[keyword("twice")]
   | -- first registered here
 ...
 3 | #[keyword("twice")]
   | ^^
```

關鍵字只註冊一次。

相關錯誤碼：[E0111](E0111.html) 無效的 `#[lang]` 項目、[E0112](E0112.html) 無效的運算子宣告、[E0113](E0113.html) 無效的 `#[keyword]` 宣告
