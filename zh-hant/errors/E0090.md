# E0090: 無效的協程用法

協程（`async` 或 `yield`）違反了規則：對不是 future 的東西使用 `await`，或在暫停點之後使用指向協程框架的指標。請 await 一個 future，並在 `await` 或 `yield` 之後重新取得指標。

常見的原因是在 `async` 或 `yield` 主體中用 `addr_of` 取得指標，並在 `await` 或 `yield` 之後使用：框架可能已經移動，所以要在暫停點之後重新取得指標。await 一個不是 future 的值，通常會回報 [E0069](E0069.html)，因為 `await` 需要 `IntoFuture`。
