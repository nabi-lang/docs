# E0055: 符合多種型別的字面值

沒有後綴的字面值可以是呼叫或運算子所接受的多種型別中的任何一種。若其中一種是該字面值的預設型別（整數為 `i64`，浮點數為 `f64`），字面值就採用它；否則它的型別無法確定。加上後綴（`1i32`）或 `as`。

```nabi norun
struct X { v: i64; }
impl From<i32> for X { fn from(x: i32) -> X { X { v: x as i64 } } }
impl From<u8> for X { fn from(x: u8) -> X { X { v: x as i64 } } }

let x = X::from(5);
```

```text check=checks/E0055.nabi
error[E0055]: `X::from`: the literal fits several `From` impls of `X` (`i32`, `u8`); add a suffix or `as`
  --> main.nabi:5:9
   |
 5 | let x = X::from(5);
   |         ^^^^^^^^^^
```

加上後綴：

```nabi
struct X { v: i64; }
impl From<i32> for X { fn from(x: i32) -> X { X { v: x as i64 } } }
impl From<u8> for X { fn from(x: u8) -> X { X { v: x as i64 } } }

let x = X::from(5i32);
println(f"{x.v}");
```

```output
5
```
