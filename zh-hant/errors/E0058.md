# E0058: 無效的閉包擷取

閉包的擷取清單（`[ref x]`）指名了無法擷取的東西：沒有這個名稱的變數，或可能在另一個執行緒上執行的閉包中的 `ref` 擷取。擷取 `let` 變數或參數，跨執行緒共用則透過 `Mutex` 或原子型別。

```nabi norun
let total = 0;
let add = [ref totl] |x: i32| { total += x; };
```

```text check=checks/E0058.nabi
error[E0058]: `[ref totl]` names no variable in scope
  --> main.nabi:2:11
   |
 2 | let add = [ref totl] |x: i32| { total += x; };
   |           ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
```

以名稱擷取變數：

```nabi
let total = 0;
let add = [ref total] |x: i32| { total += x; };
add(2);
println(f"{total}");
```

```output
2
```
