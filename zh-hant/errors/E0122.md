# E0122: 檔案引入失敗

`include_str!` / `include_bytes!` 接受一個字串路徑，路徑相對於所在的檔案，且必須指向一個可以讀取的檔案。

```nabi norun
let s = include_str!("missing.txt");
```

```text check=checks/E0122.nabi
error[E0122]: `include_str!` cannot read "missing.txt": no such file
  --> main.nabi:1:9
   |
 1 | let s = include_str!("missing.txt");
   |         ^^^^^^^^^^^
```

在 `main.nabi` 旁建立 `missing.txt`，或修正路徑。路徑相對於含有 `include_str!` 的檔案。
