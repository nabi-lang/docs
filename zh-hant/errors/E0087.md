# E0087: 有歧義的關聯項目

有多個 trait、impl 或約束提供了這個名稱的方法、關聯型別或常數，所以 `T::name` 不明確。請指明 trait：`<T as Trait>::name`，或以 `Trait::name(x)` 呼叫方法。

```nabi norun
trait A { const N: i32; }
trait B { const N: i32; }
struct S {}
impl A for S { const N: i32 = 1; }
impl B for S { const N: i32 = 2; }

println(f"{S::N}");
```

```text check=checks/E0087.nabi
error[E0087]: associated const `N` of `S` is ambiguous: `A` and `B` define it - name the trait (`<T as Tr>::N`)
  --> main.nabi:7:12
   |
 7 | println(f"{S::N}");
   |            ^^^^
```

指明 trait：

```nabi
trait A { const N: i32; }
trait B { const N: i32; }
struct S {}
impl A for S { const N: i32 = 1; }
impl B for S { const N: i32 = 2; }

println(f"{<S as B>::N}");
```

```output
2
```
