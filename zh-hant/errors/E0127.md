# E0127: 外部工具失敗

nabic 使用自己的連結器進行連結，除非 `NABI_CC` 指定了用來連結的 C 編譯器驅動程式。該驅動程式無法啟動，或執行後失敗；它的輸出接在訊息之後。修正輸出中指出的問題、確認 `NABI_CC` 指定的程式已安裝且位於 `PATH` 中，或取消設定 `NABI_CC`，改用 nabic 的連結器連結。

建置（`build`、`run`、`test`、`bench`）的連結步驟和 REPL 的主機連結，是唯一會執行外部程式的步驟，而且只在設定了 `NABI_CC` 時才會。無法啟動時，訊息是 ``cannot run the link: <reason>``；失敗時，訊息是 ``the link failed:`` 加上驅動程式的標準錯誤輸出。
