# E0088: 無效的格式

f-string 的插值位置格式化了一個不支援該格式的值（`{}` 需要 `Display`，`{:?}` 需要 `Debug`），或它的格式規範無效。實作或衍生該 trait，或修改格式規範。

```nabi norun
let name = "nabi";
println(f"{name:x}");
```

```text check=checks/E0088.nabi
error[E0088]: format type `x` needs an integer, found `str`
  --> main.nabi:2:12
   |
 2 | println(f"{name:x}");
   |            ^^^^
```

使用適合這個值的格式：

```nabi
let n = 255;
println(f"{n:x}");
```

```output
ff
```
