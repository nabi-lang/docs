# E0046: 沒有這個方法或關聯項目

型別沒有這個名稱的方法、關聯函式或關聯常數，或沒有適用於這些型別的項目。檢查拼字、提供它的 trait 是否已 `use`，以及它的約束。

```nabi norun
let s = "nabi";
println(s.size());
```

```text check=checks/E0046.nabi
error[E0046]: no method `size` found for type `str`
  --> main.nabi:2:9
   |
 2 | println(s.size());
   |         ^^^^^^^^
   |
   = help: did you mean `len`?
```

使用 help 提示建議的方法：

```nabi
let s = "nabi";
println(f"{s.len()}");
```

```output
4
```

透過存放函式或可呼叫值的欄位寫成 `r.f(x)` 的呼叫同樣是 E0046：方法呼叫從不考慮欄位。help 提示會告訴你寫成 `(r.f)(x)`。

只存在於其他平台的方法也是 E0046，並附有一則 note 說明它存在於哪裡（[第 17 章](../learn/17-conditional-compilation.html)）。未匯入的 trait 的方法則是 [E0135](E0135.html)。
