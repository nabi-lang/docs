# E0147: 程式碼中的不可見字元

程式碼中有一個什麼都不顯示、或看起來像普通空白的字元：零寬空白或零寬連接字元（U+200B 到 U+200D）、不在檔案開頭的位元組順序標記（U+FEFF）、前面沒有可修飾字元的變體選擇器、填充字元（U+3164），或 U+00A0 NO-BREAK SPACE 之類的空白。這樣一來，兩行看起來相同的程式碼可能代表不同的意思，所以 Nabi 不會把它們當作程式碼的一部分，也不接受它們出現在名稱中。刪除該字元，或改寫成普通空白；在字串中則寫成跳脫序列 `"\u{200B}"`。

下面的 f-string 中，名稱中間有一個零寬空白，這通常是從網頁或聊天訊息複製時留下的：

```nabi norun
let count = 3;
println(f"{co​unt}");
```

```text check=checks/E0147.nabi
error[E0147]: identifier `count` holds the invisible character U+200B ZERO WIDTH SPACE: it reads as `count` but is another name
  --> main.nabi:2:12
   |
 2 | println(f"{co​unt}");
   |            ^^^^^^
   |
   = note: as written: `co\u{200B}unt`
   = help: write `count`
```

刪除該字元；編輯器中的快速修正可以替你完成：

```nabi
let count = 3;
println(f"{count}");
```

```output
3
```

在字串或註解中，同樣的字元改為產生 `hidden_chars` 警告：把它們寫成 `\u{..}` 跳脫序列，讓讀者看得到。emoji 序列中的 ZWJ，以及波斯文或印度系文字中的 ZWNJ，就是它們看起來的樣子，不會被回報。
