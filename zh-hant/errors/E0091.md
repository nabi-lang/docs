# E0091: 無效的廣播

廣播呼叫 `f.(xs)` 會對 `List`、`Slice` 或陣列逐一對應，一起傳入的陣列長度必須相同。請傳入長度相符的集合。一個點運算式只能接受 core 集合或 `Broadcastable` 型別（`Array`）其中一種，不能兩者混用：用 `Array::from_list(xs, [xs.len()])` 把串列轉成陣列。`.=`／`.+=` 等寫入 `List`、固定長度陣列或 `Array`（包括其檢視），運算元必須符合其形狀；`.??` 需要一個容器運算元。

```nabi norun
fn add(a: i32, b: i32) -> i32 { a + b }

let xs: [i32; 3] = [1, 2, 3];
let ys: [i32; 4] = [10, 20, 30, 40];
println(f"{add.(xs, ys):?}");
```

```text check=checks/E0091.nabi
error[E0091]: broadcast over arrays of lengths 3 and 4
  --> main.nabi:5:12
   |
 5 | println(f"{add.(xs, ys):?}");
   |            ^^^^^^^^^^^^
```

傳入長度相同的陣列：

```nabi
fn add(a: i32, b: i32) -> i32 { a + b }

let xs: [i32; 3] = [1, 2, 3];
let ys: [i32; 3] = [10, 20, 30];
println(f"{add.(xs, ys):?}");
```

```output
[11, 22, 33]
```

同一個錯誤碼也涵蓋點語法的其他誤用，每一種都有寫出修正方式的 help 提示。一個點運算式只能接受 core 集合（`List`、`Slice`、固定長度陣列）或 `Array` 這類 `Broadcastable` 型別其中一種，不能兩者混用：

```nabi
use core::array::Array;

let xs = [1.0, 2.0];
let a = Array::from_list(xs, [xs.len()]);
let b: Array<f64, 1> = [10.0, 20.0];
println(f"{a .+ b:?}");
```

```output
[11.0, 22.0]
```

`.=` 和 `.+=` 等寫入 `List`、固定長度陣列或 `Array`（包括其檢視），運算元必須符合其形狀；`Slice` 是唯讀的，其他目標則把運算完整寫出（`x = x .+ ..;`）。`.??` 需要一個容器運算元；單一值請寫 `x ?? y`。
