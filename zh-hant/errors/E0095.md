# E0095: 型別過大

某個值型別大於編譯器能處理的大小。請透過 `List` 這類參考型別來存放較大的部分。

```nabi norun
struct W<T> { a: T; b: T; }

let x: W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<i64>>>>>>>>>>>>>>>>>>>>>>>>>>> = panic("unreachable");
```

```text check=checks/E0095.nabi
error[E0095]: value type `W<..>` is too large (131071 scalar slots, ~1048568 bytes; the limit is 65536 slots / 4294967296 bytes)
  --> main.nabi:3:30
   |
 3 | let x: W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<i64>>>>>>>>>>>>>>>>>>>>>>>>>>> = panic("unreachable");
   |                              ^
```

透過參考型別來存放較大的部分，例如存放內層值的 `List`，或你自己定義、存放這類值的結構。
