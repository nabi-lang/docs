# E0089: 無效的編譯器內建函式呼叫

呼叫編譯器內建函式（`size_of::<T>()`、`atomic_*` 與指標操作、`addr_of`、`GcBuf` 函式）時引數錯誤：需要位置的地方給了值、記憶體順序不是常數，或缺少型別引數。請依照訊息所示的方式呼叫。

```nabi norun
use bare::mem::size_of;

let n = size_of();
```

```text check=checks/E0089.nabi
error[E0089]: `size_of` is called as `size_of::<T>()`
  --> main.nabi:3:9
   |
 3 | let n = size_of();
   |         ^^^^^^^^^
```

給出型別引數：

```nabi
use bare::mem::size_of;

println(f"{size_of::<i64>()}");
```

```output
8
```
