# E0117: 沒有符合的巨集規則

巨集的規則沒有一條符合這次呼叫的引數。請對照巨集的 matcher 檢查這次呼叫。

```nabi norun
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!();
```

```text check=checks/E0117.nabi
error[E0117]: no rule of macro `twice!` matches this call
  --> main.nabi:4:9
   |
 4 | let p = twice!();
   |         ^^^^^
```

用某條規則符合的引數呼叫它：

```nabi
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!(3);
println(f"{p.0}");
```

```output
3
```
