# E0097: 形狀不對的 NABION 值

NABION 檔案（`nabi.nabion` 或設定檔）可以剖析，但其中某個值不符合讀取端的預期，例如缺少欄位、值的型別錯誤，或數字超出範圍。請寫出訊息所指出的值。

這個 `nabi.nabion` 把 `version` 寫成數字：

```nabion
Package {
    name: "pk",
    version: 1,
}
```

`nabi check` 會印出：

```text
error[E0097]: `version` must be a string, found an integer
  --> nabi.nabion:3:14
   |
 3 |     version: 1,
   |              ^
```

把 `version` 寫成字串：`version: "0.1.0"`。NABION 格式的說明請見[第 11 章](../learn/11-modules-packages.html)。
