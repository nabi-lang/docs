# 錯誤碼

nabic 的每一則診斷都以錯誤碼開頭，例如 `error[E0040]: mismatched types: ...`。每一種錯誤對應一個錯誤碼，所以一個錯誤碼涵蓋許多訊息；訊息本身會說明哪裡出錯，通常也會告訴你該改寫成什麼。`nabic --explain E0040`（或 `nabi --explain E0040`）會印出錯誤碼的簡短說明；這裡的頁面說明相同的內容，並附上範例。使用 `--message-format=json` 時，錯誤碼放在 `code` 欄位，所屬領域放在 `kind` 欄位（[9.9.4 診斷](../spec/refs-lang/009-tools/909-debug-tools.html#994-診斷--錯誤訊息)）。

錯誤碼依加入的順序編號，從 E0001 開始，中間沒有空號。本索引對應這個文件版本的 nabic。大多數頁面都有一個範例及其修正方式，範例會在建置文件時與實際的編譯器輸出比對。
