# E0100: 模式與值的型別不符

模式無法比對這個型別的值，例如用另一個結構的結構模式、對不是元組的值使用元組模式，或在只允許不可反駁模式的地方（`let`、參數、`for`）使用可反駁模式。請寫出符合值型別的模式；可反駁的模式請用 `match` 或 `let .. else`。

```nabi norun
let n = 5;
let (a, b) = n;
```

```text check=checks/E0100.nabi
error[E0100]: tuple destructure of a non-tuple value of type `i64`
  --> main.nabi:2:1
   |
 2 | let (a, b) = n;
   | ^^^
```

解構符合模式型別的值：

```nabi
let pair = (5, 6);
let (a, b) = pair;
println(f"{a} {b}");
```

```output
5 6
```
