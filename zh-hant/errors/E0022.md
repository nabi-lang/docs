# E0022: 沒有值的 `let`

每個 `let` 都要給變數一個值。請寫出值，例如 `let n: i32 = 0;`，或用可選型別讓它從空值開始：`let n: i32 | none = none;`。

```nabi norun
let n: i32;
```

```text check=checks/E0022.nabi
error[E0022]: `let n` needs a value
  --> main.nabi:1:11
   |
 1 | let n: i32;
   |           ^
   |
   = help: give it one, `let n: i32 = ..;`, or start it empty: `let n: i32 | none = none;`
```

給它一個初始值，或用 `none` 搭配可選型別：

```nabi
let n: i32 | none = none;
println(f"{n ?? 0}");
```

```output
0
```
