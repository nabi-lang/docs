# E0028: 找不到型別或 trait

作用域中沒有這個名稱的型別或 trait。請檢查拼字，或用 `use` 匯入它；help 提示會列出同名的項目。

```nabi norun
let xs: Lst<i32> = [1];
```

```text check=checks/E0028.nabi
error[E0028]: cannot find type `Lst` in this scope
  --> main.nabi:1:9
   |
 1 | let xs: Lst<i32> = [1];
   |         ^^^
   |
   = help: did you mean `List`?
```

修正拼字：

```nabi
let xs: List<i32> = [1];
println(f"{xs.len()}");
```

```output
1
```
