# E0112: 無效的運算子宣告

trait 方法上的運算子屬性（`#[infix(..)]`、`#[prefix(..)]` 等）違反了規則，例如：不能作為運算子的語彙單元（`′` 或 `ℱ` 這類識別字字元，或放在沒有對應形式之位置的固定語彙單元，二元 `@`、`~` 和 `->` 除外）、為內建語彙單元指定優先順序、不同層級的別名、會 `throws` 的方法（運算子不擲回錯誤：請改為回傳 `Result` 或 `T | E`），或固定運算子的 Unicode 寫法（`≤` 會讀作 `<=`；請改為實作 `ops::PartialOrd`），或沒有 `like` 的二元 `->`（請寫成 `#[infix("->", like = "|")]`）。新的語彙單元以 `like = "<existing token>"` 指定其優先順序。

```nabi norun
trait Before {
    #[infix(">>>", precedence = 3)]
    fn before(self, o: Self) -> bool;
}
```

```text check=checks/E0112.nabi
error[E0112]: `#[infix]` takes only an operator token, `like = ".."` and `swap`: precedence and associativity are fixed by the language
  --> main.nabi:2:5
   |
 2 |     #[infix(">>>", precedence = 3)]
   |     ^^
```

移除優先順序。新的語彙單元用 `like` 借用內建語彙單元的優先順序：`#[infix(">>>", like = ">>")]`（[6.7](../spec/refs-lang/006-meta-system/607-operator-magic.html)）。
