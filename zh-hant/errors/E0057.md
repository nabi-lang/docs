# E0057: 無效的指派

`=` 的左邊無法被指派：常數、static、不是以 `let` 宣告的變數，或閉包沒有用 `[ref name]` 擷取的值。指派給 `let` 變數、其欄位或其元素。左邊是值（例如呼叫結果）時是 E0140。在副本上設定欄位、之後卻沒有任何地方讀取（以值傳入的 `self` 或參數、閉包的引數、`for` 繫結、取得 `xs[i]` 的 `let`），變更就會遺失，這也是錯誤：改用 `ref self` 或 `ref` 參數、從閉包回傳引數並使用結果、寫成 `for ref x in xs`，或把元素寫回去。

```nabi norun
let count = 0;
coutn = count + 1;
```

```text check=checks/E0057.nabi
error[E0057]: `coutn` is not declared; a variable is created only by `let`
  --> main.nabi:2:1
   |
 2 | coutn = count + 1;
   | ^^^^^
   |
   = help: did you mean `count`? To declare a new variable, write `let coutn = count + 1;`
```

指派給你宣告的變數，或用 `let` 宣告一個新變數：

```nabi
let count = 0;
count = count + 1;
println(f"{count}");
```

```output
1
```

Nabi 沒有以指派進行的宣告：變數只能由 `let` 建立（[5.1](../spec/refs-lang/005-modules/501-variable-declaration.html)）。解構指派（例如 `(a, b) = (b, a);`）中的每個名稱也一樣：先用 `let` 宣告它們，或用 `let (a, b) = ..;` 一次宣告。

在副本上設定欄位、之後卻沒有任何地方讀取，也是這個錯誤：變更會遺失。結構是值，所以以值傳入的 `self` 或參數、閉包的引數（`m.with(|a| { a.n += 1; })`）、`for` 繫結，以及取得元素的 `let`（`let q = xs[i];`）存放的都是副本（[2.3.8](../spec/refs-lang/002-types/203-struct.html#238-值語意)）。

```nabi norun
struct Point { x: i32; y: i32; }

let ps = [Point { x: 1, y: 0 }, Point { x: 2, y: 0 }];
for p in ps { p.x = 7; }
```

```text check=checks/E0057-copy.nabi
error[E0057]: `p.x` is set on a copy of the element, so `ps` does not change
  --> main.nabi:4:15
   |
 4 | for p in ps { p.x = 7; }
   |               ^^^
   |
   = help: bind each element as a place with `for ref`: `for ref p in ps { p.x = 7; }`
```

`for ref` 把每個元素繫結為位置，所以寫入會反映到串列上（[3.13.3](../spec/refs-lang/003-expressions/313-loop-expressions.html#for-ref元素作為位置)）。在方法中改用 `ref self`；參數改用 `ref p`；在閉包中回傳引數並使用結果；對於取得元素的 `let`，把它寫回去（`xs[i] = q;`）。

```nabi
struct Point { x: i32; y: i32; }

let ps = [Point { x: 1, y: 0 }, Point { x: 2, y: 0 }];
for ref p in ps { p.x = 7; }
println(f"{ps[0].x} {ps[1].x}");
```

```output
7 7
```
