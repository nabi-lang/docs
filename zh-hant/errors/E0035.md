# E0035: 模組檔案有問題

無法載入 `mod name;`：它的檔案 `name.nabi` 不存在或無法讀取、模組宣告了兩次，或模組既是內嵌的又是檔案。模組的檔案以模組命名（Nabi 沒有 `mod.nabi`），放在宣告它的檔案旁邊。

```nabi norun
mod geo;
```

```text check=checks/E0035.nabi
error[E0035]: module `geo` body not found at `geo.nabi`
   = help: create `geo.nabi`, or write `mod geo { .. }` in place of `mod geo;`
```

在 `main.nabi` 旁邊建立 `geo.nabi`，或把模組直接寫在原處：`mod geo { .. }`（[5.4 模組](../spec/refs-lang/005-modules/504-modules.html)）。
