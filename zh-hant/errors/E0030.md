# E0030: 無法解析的匯入

`use` 指定了不存在的東西。請檢查路徑：路徑的開頭是套件（`pkg::`）、相依套件，或標準函式庫層級（`std::`、`core::`、`bare::`）。

```nabi norun
use std::fss;
```

```text check=checks/E0030.nabi
error[E0030]: unresolved import: `std::fss` does not exist
  --> main.nabi:1:10
   |
 1 | use std::fss;
   |          ^^^
```

修正路徑：

```nabi
use std::fs;

println(f"{fs::exists("no-such-file")}");
```

```output
false
```
