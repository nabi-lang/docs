# E0128: 無效的 WIT

`ffi::wit::import { .. }` 或 `ffi::wit::export { .. }` 指定的 `.wit` 檔案無法讀取、剖析或解析。建立該檔案或修正它的路徑（相對於原始檔），或在訊息指出的位置修正 WIT 檔案（[標準函式庫 1.8](../spec/refs-standard-libraries/100-bare/108-wit.html)）。

```nabi norun
ffi::wit::import { "calc.wit" }
```

```text check=checks/E0128.nabi
error[E0128]: WIT: calc.wit:0:0: cannot read: No such file or directory (os error 2)
  --> main.nabi:1:1
   |
 1 | ffi::wit::import { "calc.wit" }
   | ^^^
```

建立 WIT 檔案，或修正路徑；路徑相對於原始檔。檔案存在但無法剖析時，訊息會指出所在的行和列。

相關錯誤碼：[E0084](E0084.html) 無效的外部函式用法、[E0125](E0125.html) 無法讀寫檔案
