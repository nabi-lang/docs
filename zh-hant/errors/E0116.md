# E0116: 格式錯誤的巨集定義

巨集的規則格式不正確。每條規則是 `( matcher ) => { template }`，元變數是 `@name: fragment`，重複是 `@rep[sep = ","] { .. }`。

```nabi norun
#[impl_macro(twice)] @macro {
    @e: expr => { (@e, @e) }
}
let p = twice!(3);
```

```text check=checks/E0116.nabi
error[E0116]: a macro rule starts with `( matcher )`
  --> main.nabi:2:5
   |
 2 |     @e: expr => { (@e, @e) }
   |     ^
```

用括號包住 matcher：

```nabi
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!(3);
println(f"{p.0 + p.1}");
```

```output
6
```

請見 [6.8.12 macro 形式](../spec/refs-lang/006-meta-system/608-meta-blocks.html#6812-巨集形式)。
