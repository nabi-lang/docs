# E0084: 無效的外部函式用法

C 函式、`extern` 宣告或 `extern "C" fn` 違反了 FFI 的規則：使用了 C 無法容納的型別（可能被回收器移動的型別、元組、Unicode `char`、一般的列舉、`str` 結果）、把閉包當作 C 回呼傳入、兩個宣告的簽章不同，或使用了 C 無法接受的可變引數。型別會在解析之後，經由別名和欄位逐層檢查，help 提示會說明該改寫成什麼。請傳入與 C 相容的型別，並以具名函式作為回呼。

```nabi norun
extern "C" {
    fn abs(x: i32) -> i32;
    fn abs(x: i64) -> i64;
}
```

```text check=checks/E0084.nabi
error[E0084]: extern function `abs` is declared twice with different signatures: `fn(i64) -> i64` here, `fn(i32) -> i32` elsewhere
  --> main.nabi:3:5
   |
 2 |     fn abs(x: i32) -> i32;
   |     -- declared as `fn(i32) -> i32` here
 3 |     fn abs(x: i64) -> i64;
   |     ^^
   |
   = help: a C symbol has one signature: declare `abs` as `fn(i32) -> i32` here too, or drop this declaration
```

每個 C 函式只宣告一次，並使用它的 C 簽章：

```nabi
extern "C" {
    fn abs(x: c_int) -> c_int;
    fn labs(x: c_long) -> c_long;
}
println(f"{unsafe { labs(-5) }}");
```

```output
5
```
