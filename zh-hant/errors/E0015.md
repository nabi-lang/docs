# E0015: 沒有說明任何項目的文件註解

文件註解（`///` 或 `/** */`）要緊接在它所說明的項目之前。請把它移到那裡，或改成一般註解（`//`）。

```nabi norun
fn f() {}
/// The answer.
```

```text check=checks/E0015.nabi
error[E0015]: doc comment documents nothing: it must come before an item; use `//` for a plain comment
  --> main.nabi:2:1
   |
 2 | /// The answer.
   | ^^^^^^^^^^^^^^^
```

把文件註解移到它所描述的項目上：

```nabi
/// The answer.
fn answer() -> i32 { 42 }
println(f"{answer()}");
```

```output
42
```
