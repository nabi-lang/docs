# E0025: 不支援的 ABI

`extern` 指定了 Nabi 不支援的 ABI，或是沒有指定。請寫 `extern "C"`（呼叫平台的系統呼叫時用 `"system"`）。

```nabi norun
extern "fastcall" {
    fn abs(x: i32) -> i32;
}
```

```text check=checks/E0025.nabi
error[E0025]: unsupported ABI `"fastcall"` (`"C"`, `"system"`, `"objc"`, or `"nabi"` for the runtime)
  --> main.nabi:1:1
   |
 1 | extern "fastcall" {
   | ^^^^^^
```

寫成 `"C"`：

```nabi
extern "C" {
    fn abs(x: i32) -> i32;
}
println(f"{unsafe { abs(-3) }}");
```

```output
3
```
