# E0040: 型別不符

某個型別的值用在預期為另一個型別的地方：引數、標註了型別的 `let`、回傳值，或函式主體以 `;` 丟棄了值的函式的值。轉換這個值（`as i32`、`.to_str()`）、修改預期的型別，或刪掉 `;`。

```nabi norun
fn half(x: i32) -> i32 { x / 2 }
println(f"{half(3.0)}");
```

```text check=checks/E0040.nabi
error[E0040]: mismatched types: argument `x` of `half` expects `i32`, found `f64`
  --> main.nabi:2:17
   |
 2 | println(f"{half(3.0)}");
   |                 ^^^
   |
   = help: convert it with `as`: `3.0 as i32`
```

傳入 `i32`，或用 `as` 明確轉換：

```nabi
fn half(x: i32) -> i32 { x / 2 }
println(f"{half(3)}");
```

```output
1
```

Nabi 沒有隱含的數值轉換，所以在預期為 `i32` 的地方不接受 `f64`（[2.14 強制轉型與轉換](../spec/refs-lang/002-types/214-cast-and-conversion.html)）。大多數訊息都會附上一行 `help:`，告訴你該改寫成什麼。
