# E0082: 錯誤的泛型引數

泛型項目收到的型別引數數量錯誤，或引數不符合它的定義。每個參數傳一個引數（有預設值的參數可以省略）。

```nabi norun
let xs: List<i32, str> = [];
```

```text check=checks/E0082.nabi
error[E0082]: `List` takes 1 generic argument but 2 were given
  --> main.nabi:1:9
   |
 1 | let xs: List<i32, str> = [];
   |         ^^^^
   |
   = help: `List` is declared `List<T>`; remove the last argument
```

每個參數傳一個引數：

```nabi
let xs: List<i32> = [];
println(f"{xs.len()}");
```

```output
0
```
