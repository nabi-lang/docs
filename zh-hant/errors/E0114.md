# E0114: 無效的字面值處理器

`#[literal(..)]` 處理器必須是一個函式，參數符合其種類所接受的參數，而且每個後綴、優先順序和回傳型別只能註冊一次。數字後綴或字串前綴是緊接在字面值上的名稱（`95pct`、`date"2024-01-15"`），絕不是 `%` 或 `°` 這類符號；後綴也不能以 `e` 或 `_` 開頭，因為它們會被讀作指數和數字分隔符號。帶後綴或前綴的字面值需要作用域中有對應的處理器；訊息會指出現有最接近的那一個。

```nabi norun
let d = 5q;
```

```text check=checks/E0114.nabi
error[E0114]: unknown numeric literal suffix `q` - no `#[literal(number "q")]` handler is registered
  --> main.nabi:1:10
   |
 1 | let d = 5q;
   |          ^
   |
   = help: register one, `#[literal(number "q")] fn ..`, here or as a `pub fn` in a package this one depends on; the suffixes in scope are `i`
```

為這個後綴註冊處理器；字面值會變成對它的呼叫（[6.5](../spec/refs-lang/006-meta-system/605-literal-magic.html)）：

```nabi
#[literal(number "q")]
fn quarter(n: f64) -> f64 { n / 4.0 }

let d = 5q;
println(f"{d}");
```

```output
1.25
```

與作用域中某個後綴或前綴只差一點的寫法，會得到「did you mean」和快速修正：以 `signal` 為相依套件時，`10Hz` 會提示 ``did you mean `10hz`?``；有 `table` 時，`dat"2024-01-15"` 會提示 ``did you mean `date`?``。百分比是一個後綴名稱，而不是 `%`；`%` 是取餘數運算子：

```nabi norun
let p = 95%;        // 錯誤：`95%` 不是百分比，請寫 `95pct`
#[literal(number "°")]   // 錯誤：數字後綴必須是名稱，而 `°` 是符號
const fn deg(n: f64) -> f64 { n }
```

改為註冊一個名稱：`#[literal(number "deg")]`，然後寫 `90deg`。
