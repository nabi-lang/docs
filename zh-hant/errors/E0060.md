# E0060: 不會發散的 `let .. else`

`let .. else` 的 `else` 區塊在模式不符合時執行，所以它必須離開作用域：以 `return`、`break`、`continue` 或 `throw` 結束它。

```nabi norun
fn first(xs: List<i32>) -> i32 {
    let n = xs.first() else {
        println("empty");
    };
    n
}
```

```text check=checks/E0060.nabi
error[E0060]: the `else` block of `let ... else` must diverge (end in `return`, `break`, `continue` or `throw`)
  --> main.nabi:2:13
   |
 2 |     let n = xs.first() else {
   |             ^^^^^^^^^^
```

在 `else` 區塊中離開函式：

```nabi
fn first(xs: List<i32>) -> i32 {
    let n = xs.first() else {
        return 0;
    };
    n
}
println(f"{first([])} {first([4])}");
```

```output
0 4
```
