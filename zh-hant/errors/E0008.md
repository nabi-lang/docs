# E0008: 格式錯誤的 f-string

f-string 中的 `{..}` 插值位置格式不正確：沒有對應 `}` 的 `{`、單獨的 `}`、空的 `{}`、格式規範裡又有格式規範，或是在 `f""".."""` 之外跨行的插值位置。要寫出大括號本身，請寫 `{{` 或 `}}`，並在每個插值位置放入一個值：`f"{x}"`。

```nabi norun
let n = 3;
println(f"n = {}");
```

```text check=checks/E0008.nabi
error[E0008]: empty `{}` in f-string
  --> main.nabi:2:15
   |
 2 | println(f"n = {}");
   |               ^
```

在插值位置放入一個值：

```nabi
let n = 3;
println(f"{n}");
```

```output
3
```
