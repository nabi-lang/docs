# E0096: 沒有作用的 `try` 或 `catch`

`try` 沒有涵蓋任何會擲回錯誤的呼叫，或者沒有任何錯誤會到達 `catch`。請移除它。

```nabi norun
let n = try 1 + 2;
println(f"{n}");
```

```text check=checks/E0096.nabi
warning[E0096]: this `try` covers no throwing call
  --> main.nabi:1:9
   |
 1 | let n = try 1 + 2;
   |         ^^^^^^^^^
```

移除 `try`：

```nabi
let n = 1 + 2;
println(f"{n}");
```

```output
3
```

這是警告：程式仍然可以建置。
