# E0120: 遞迴展開

巨集或元區塊直接或經由其他巨集無止盡地展開成自己。請打斷這個循環。

```nabi norun
#[impl_macro(again)] @macro {
    ( @e: expr ) => { again!(@e) }
}
let x = again!(1);
```

```text check=checks/E0120.nabi
error[E0120]: `again!` expands too deeply or cyclically
  --> main.nabi:4:9
   |
 4 | let x = again!(1);
   |         ^^^^^
```

讓樣板展開成不會再次呼叫該巨集的程式碼：

```nabi
#[impl_macro(again)] @macro {
    ( @e: expr ) => { (@e, @e) }
}
let x = again!(1);
println(f"{x.0}");
```

```output
1
```
