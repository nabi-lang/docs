# E0108: 無法衍生

`#[derive(..)]` 無法為這個型別實作該 trait：某個欄位沒有實作它、它還需要另一個衍生的 trait，或者型別屬於 derive 不支援的種類。請手動實作該 trait，或修正訊息指出的欄位。

```nabi norun
struct NoClone { n: i32; }
#[derive(Clone)]
struct Holder { n: NoClone; }
```

```text check=checks/E0108.nabi
error[E0108]: cannot derive `Clone` for `Holder`: `n` has type `NoClone`, which does not implement `Clone`
  --> main.nabi:2:1
   |
 2 | #[derive(Clone)]
   | ^^
```

也為欄位的型別衍生該 trait，或手動實作它：

```nabi
#[derive(Clone)]
struct NoClone { n: i32; }
#[derive(Clone)]
struct Holder { n: NoClone; }
let h = Holder { n: NoClone { n: 1 } };
println(f"{h.clone().n.n}");
```

```output
1
```

完全無法衍生的 trait（例如 `Display`）也是 E0108；訊息會說明原因。
