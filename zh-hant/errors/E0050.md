# E0050: `ref` 參數與引數不符

`ref` 參數接受寫成 `ref x` 的引數，它指名一個變數或變數的欄位；一般參數接受一般引數。同一個變數不能在一次呼叫中傳給兩個 `ref` 參數。只在參數有 `ref` 的地方寫上 `ref`。

```nabi norun
fn inc(ref n: i32) { n += 1; }

let c = 0;
inc(c);
```

```text check=checks/E0050.nabi
error[E0050]: parameter `n` of `inc` is `ref` - pass `ref c` at the call site
  --> main.nabi:4:1
   |
 4 | inc(c);
   | ^^^^^^
```

在呼叫處也寫上 `ref`：

```nabi
fn inc(ref n: i32) { n += 1; }

let c = 0;
inc(ref c);
println(f"{c}");
```

```output
1
```
