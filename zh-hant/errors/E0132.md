# E0132: 無效的編譯器選項

編譯器選項的值不是它接受的值：不認得的 `-C` 選項或 `--emit` 種類、缺少值的選項、不認得的 `-C target-cpu`，或兩個不能一起使用的選項（`-o` 搭配多個 `--emit` 種類）。help 提示會告訴你該怎麼寫；`nabic help <command>` 會列出所有選項及其值。拼錯的選項名稱屬於用法錯誤，會指出最接近的選項。

```text
$ nabi build -C overflow-check
error[E0132]: unknown codegen option `overflow-check`; did you mean `overflow-checks`?
   = help: `-C` takes `overflow-checks[=yes|no]`, `icf[=yes|no]`, `target-cpu=<cpu>`, `target-feature=+f1,-f2` or `subsystem=console|windows`
run `nabi help build` for usage
```

照 help 提示寫出選項：

```text
$ nabi build -C overflow-checks=no
```

指令會在編譯任何東西之前停止，並以結束碼 2 結束，與用法錯誤相同。使用 `--message-format=json` 時，不論該選項在命令列上的位置為何，這個錯誤都會和其他診斷一樣，以一行 JSON 輸出到 stdout。
