# E0004: 字面值超出其型別的範圍

字面值無法放進它的型別：`300u8`、在預期無號型別的地方寫 `-1`，或是對 `f32` 來說過大的浮點數。請改用更寬的型別（`300u16`）、放得下的值，或用 `int` 表示任意大小的數字。

```nabi norun
let b: u8 = 300;
```

```text check=checks/E0004.nabi
error[E0004]: integer literal `300` out of range for `u8`
  --> main.nabi:1:13
   |
 1 | let b: u8 = 300;
   |             ^^^
```

改用足以容納這個值的型別：

```nabi
let b: u16 = 300;
println(f"{b}");
```

```output
300
```
