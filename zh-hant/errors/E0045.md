# E0045: 重複指定的欄位

結構字面值把同一個欄位寫了兩次。刪掉其中一個。

```nabi norun
struct P { x: i32 }

let p = P { x: 1, x: 2 };
```

```text check=checks/E0045.nabi
error[E0045]: field `x` specified more than once in `P` literal
  --> main.nabi:3:9
   |
 3 | let p = P { x: 1, x: 2 };
   |         ^^^^^^^^^^^^^^^^
```

每個欄位只指定一次：

```nabi
struct P { x: i32 }

let p = P { x: 2 };
println(f"{p.x}");
```

```output
2
```
