# E0010: 非預期的語彙單元

剖析器預期某個東西，卻遇到另一個：缺少 `;`、`,`、`)` 或 `}`，在該放名稱的地方放了關鍵字，或在該放項目的地方放了運算式。訊息會說明預期的是什麼；請照著寫，或檢查前一行有沒有東西沒有閉合。

```nabi norun
let x = (1 + 2;
println(f"{x}");
```

```text check=checks/E0010.nabi
error[E0010]: expected `)`, found `;`
  --> main.nabi:1:15
   |
 1 | let x = (1 + 2;
   |         - unclosed delimiter
   |               ^ expected `)`
```

閉合括號：

```nabi
let x = (1 + 2);
println(f"{x}");
```

```output
3
```

缺少 `;` 時會回報 ``expected `;` ``，並附上 ``help: add `;` at the end of the statement``。有分隔符號沒有閉合時，會有第二個標記指向它。
