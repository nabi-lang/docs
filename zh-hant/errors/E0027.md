# E0027: 找不到值或函式

作用域中沒有這個名稱的值或函式。請檢查拼字，用 `use` 匯入它（help 提示會列出同名的項目），或先用 `let` 宣告它。

```nabi norun
let count = 1;
println(f"{coun}");
```

```text check=checks/E0027.nabi
error[E0027]: cannot find value `coun` in this scope
  --> main.nabi:2:12
   |
 2 | println(f"{coun}");
   |            ^^^^
   |
   = help: did you mean `count`?
```

修正拼字，或匯入該項目：

```nabi
let count = 1;
println(f"{count}");
```

```output
1
```

其他模組中有同名的項目時，help 提示會給出匯入它的 `use` 行。指派給從未用 `let` 宣告過的名稱，則是 [E0057](E0057.html)。
