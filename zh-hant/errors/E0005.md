# E0005: 未結束的字面值或註解

字串、字元、位元組字串、f-string、原始字串或區塊註解有開頭卻沒有結尾。請補上結尾的引號或 `*/`。原始字串結尾的 `#` 數量必須與開頭相同。

```nabi norun
/* the greeting
println("hi");
```

```text check=checks/E0005.nabi
error[E0005]: unterminated block comment
  --> main.nabi:1:1
   |
 1 | /* the greeting
   | ^^^^^^^^^^^^^^^
```

結束這個註解：

```nabi
/* the greeting */
println("hi");
```

```output
hi
```
