# E0113: 無效的 `#[keyword]` 宣告

`#[keyword("name")]` 要放在作為其處理器的自由函式上，而且 `name` 必須是尚未成為關鍵字的識別字。

```nabi norun
#[keyword("if")]
fn my_if(c: bool) -> bool { c }
```

```text check=checks/E0113.nabi
error[E0113]: `#[keyword("if")]`: `if` is already a keyword
  --> main.nabi:1:1
   |
 1 | #[keyword("if")]
   | ^^
```

選一個還不是關鍵字的名稱，例如 `#[keyword("unless")]`。
