# E0068: 無法迭代的值

`for` 可以迭代有起點的整數範圍（`0..n`、`0..`）、陣列，或實作了 `IntoIterator` 或 `Iterator`（其 `next` 回傳 `T | none`）的型別；`try for` 迭代 `TryIterator`。迭代上述其中一種，或呼叫會產生迭代器的方法。

```nabi norun
struct Bag { n: i32; }

let b = Bag { n: 3 };
for x in b {
    println(f"{x}");
}
```

```text check=checks/E0068.nabi
error[E0068]: cannot iterate over a value of type `Bag` - `for` needs an integer range, an array, an `IntoIterator` / `Iterator` impl, or a `TryIterator` (`try for`)
  --> main.nabi:4:1
   |
 4 | for x in b {
   | ^^^^^^^^^^^^
```

迭代範圍、集合或迭代器：

```nabi
struct Bag { n: i32; }

let b = Bag { n: 3 };
for x in 0..b.n {
    println(f"{x}");
}
```

```output
0
1
2
```
