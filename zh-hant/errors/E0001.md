# E0001: 原始碼中有非預期的字元

原始碼中有一個無法作為任何語彙單元開頭的字元：零散的 `#` 或 `$`、不在第一行的 `#!` 行、前面沒有字母的組合符號、Unicode 尚未指派的碼位，或是作用域中沒有任何 trait 註冊的運算子符號，例如 `⊛`。請刪除它，或把它寫在字串或註解裡。要使用運算子符號，必須把註冊該符號的套件加為相依套件，或在你自己的 trait 方法上加上 `#[infix(..)]`。

```nabi norun
let price = $5;
```

```text check=checks/E0001.nabi
error[E0001]: unexpected character(s) `$`
  --> main.nabi:1:13
   |
 1 | let price = $5;
   |             ^
```

刪除這個零散的字元，或把它放進字串。帶單位的數字是緊接在數字後面的後綴名稱（`5usd`），而不是符號（[E0114](E0114.html)）：

```nabi
let price = 5;
println(f"${price}");
```

```output
$5
```
