# E0099: 無法到達的 match 分支

前面的分支已經比對了這個分支會比對的所有值，所以它永遠不會執行。請移除它，或把它移到涵蓋它的分支之前。

```nabi norun
let n = 1;
let r = match n {
    _ => 0,
    1 => 1,
};
```

```text check=checks/E0099.nabi
error[E0099]: unreachable match arm 2: earlier arms already match every value it matches
  --> main.nabi:4:10
   |
 4 |     1 => 1,
   |          ^
```

把萬用分支移到最後：

```nabi
let n = 1;
let r = match n {
    1 => 1,
    _ => 0,
};
println(f"{r}");
```

```output
1
```
