# E0086: 無效的聯集

聯集至少要宣告一個欄位，它的字面值必須恰好設定其中一個欄位，且不能使用 `..base`。聯集只接受 `#[repr(C)]`。

```nabi norun
#[repr(C)]
union Empty {}
```

```text check=checks/E0086.nabi
error[E0086]: union `Empty` declares no fields
  --> main.nabi:2:1
   |
 2 | union Empty {}
   | ^^^^^
```

至少宣告一個欄位。聯集是為了對應 C 的 union 而存在，所以它是 `#[repr(C)]`，並在 `unsafe` 程式碼中讀取（[第 14 章](../learn/14-ffi.html)）。
