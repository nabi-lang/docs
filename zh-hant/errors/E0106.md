# E0106: 值在其鎖釋放後被使用

這個值取自 `Mutex` 或 `RwLock`，而持有鎖的 `using` 區塊已經結束，所以鎖不再保護它。請在 `using` 區塊內使用它，或用 `.clone()` 取得複本。

```nabi norun
let m = Mutex::new([1, 2, 3]);
let xs = using g = m.lock() { g.get() };
xs.push(4);
```

```text check=checks/E0106.nabi
error[E0106]: the value of `g`'s `using` block is what the `Mutex` protects, and the block releases the lock before it is used
  --> main.nabi:2:10
   |
 2 | let xs = using g = m.lock() { g.get() };
   |          ^^^^^
   |                               ------- taken out of the lock here
   |
   = help: use it inside the `using` block, or make the block's value `g.get_clone()`
```

用 `get_clone()` 把深層複本帶出區塊：

```nabi
let m = Mutex::new([1, 2, 3]);
let xs = using g = m.lock() { g.get_clone() };
xs.push(4);
println(f"{xs.len()}");
```

```output
4
```

值以任何形式離開區塊都一樣：迴圈的 `break` 值、帶標籤的區塊、`if` 或 `match` 的分支、`catch`，或閉包的結果。每一種都是 E0106，修正方式也相同。

鎖守衛的 `get()` 回傳的是受保護值的檢視：把它傳給會保留它的函式，也是 E0106。
