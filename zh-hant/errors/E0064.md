# E0064: 對非可選的值使用可選運算子

`?`、`??` 和 `?.` 用於可選值（`T | none`），`try?` / `try!` 用於會擲回錯誤的呼叫。對一般的值使用 `.`；要把錯誤往外傳，就用 `throws` 搭配 `try`。

```nabi norun
let xs = [1, 2, 3];
let n = xs.len()?;
```

```text check=checks/E0064.nabi
error[E0064]: `?` only works on `T | none`, found `usize` - to propagate errors use `throws` and `try`
  --> main.nabi:2:9
   |
 2 | let n = xs.len()?;
   |         ^^^^^^^^^
```

直接使用這個值：

```nabi
let xs = [1, 2, 3];
let n = xs.len();
println(f"{n}");
```

```output
3
```
