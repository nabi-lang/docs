# E0021: 把保留字當作名稱

關鍵字或保留名稱（例如路徑根 `pkg`，或用 `#[keyword]` 註冊的關鍵字）被當作名稱使用。請換一個名稱，或寫成 `r#name`，讓關鍵字保留為名稱。

```nabi norun
let gen = 1;
```

```text check=checks/E0021.nabi
error[E0021]: `gen` is a reserved keyword, not a name
  --> main.nabi:1:5
   |
 1 | let gen = 1;
   |     ^^^
   |
   = help: write `r#gen` to keep this name, or rename it; a generator is `yield fn`, `yield { .. }` or `yield || ..`
```

寫成 `r#gen` 保留這個名稱，或換一個名稱：

```nabi
let r#gen = 1;
println(f"{r#gen}");
```

```output
1
```
