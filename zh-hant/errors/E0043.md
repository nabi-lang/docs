# E0043: 沒有這個欄位

型別沒有這個名稱的欄位（或元組在這個索引沒有元素）。對照型別的定義檢查拼字。

```nabi norun
struct P { x: i32; y: i32; }

let p = P { x: 1, y: 2 };
println(f"{p.z}");
```

```text check=checks/E0043.nabi
error[E0043]: struct `P` has no field `z`
  --> main.nabi:4:12
   |
 4 | println(f"{p.z}");
   |            ^^^
   |
   = help: available fields: `x`, `y`
```

使用型別擁有的欄位；help 提示會列出它們：

```nabi
struct P { x: i32; y: i32; }

let p = P { x: 1, y: 2 };
println(f"{p.y}");
```

```output
2
```
