# Rosetta：常見題目

用 Nabi 解決一些知名的小型程式設計題目，精神上類似 [Rosetta Code](https://rosettacode.org)：FizzBuzz、質數篩法、凱撒密碼、八皇后。如果你知道某個題目在其他語言中的寫法，這些頁面會讓你看到它在 Nabi 中的樣子。每個區塊都是完整的指令碼，建置網站時會編譯並執行，輸出列在下方。

| 頁面 | 題目 |
|------|-------|
| [文字](strings.html) | 反轉、迴文、單字計數、凱撒密碼、對齊欄位、分割與合併、大小寫、模式 |
| [數字](numbers.html) | FizzBuzz、費氏數列、大數階乘、質數篩法、最大公因數、羅馬數字、剖析、四捨五入、亂數 |
| [集合型別](collections.html) | 重複項目、依鍵排序、分組、集合、zip 與 flatten、依某個量度找最大值、堆疊與佇列 |
| [演算法](algorithms.html) | 二分搜尋、快速排序、河內塔、排列、八皇后、最短路徑、矩陣乘法 |
| [檔案與資料](files-and-data.html) | `wc`、CSV、設定檔、JSON、走訪目錄、環境變數、執行程式 |

數值與資料方面的工作，[用 Nabi 做科學計算](../22-science.html)為每個科學計算套件指出一份教學。每個題目只在用到新東西時才連回本指南；本指南的[怎麼做……](../20-cookbook.html)一章收錄了日常系統工作的簡短解答。
