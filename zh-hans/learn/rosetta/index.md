# Rosetta：常见任务

用 Nabi 解决的一些广为人知的小编程任务，风格与 [Rosetta Code](https://rosettacode.org) 相同：FizzBuzz、素数筛、凯撒密码、八皇后。如果你知道某个任务在另一种语言中怎么写，这些页面会告诉你它在 Nabi 中是什么样子。每个代码块都是完整的脚本，在构建网站时编译并运行，输出列在其下方。

| 页面 | 任务 |
|------|-------|
| [文本](strings.html) | 反转、回文、单词计数、凯撒密码、分列、拆分与连接、大小写、模式 |
| [数字](numbers.html) | FizzBuzz、斐波那契数列、大数阶乘、素数筛、最大公约数、罗马数字、解析、舍入、随机数 |
| [集合](collections.html) | 重复项、按键排序、分组、集合、zip 与 flatten、按某个度量取最大、栈与队列 |
| [算法](algorithms.html) | 二分查找、快速排序、汉诺塔、排列、八皇后、最短路径、矩阵乘积 |
| [文件与数据](files-and-data.html) | `wc`、CSV、配置文件、JSON、遍历目录、环境变量、运行程序 |

数值计算和数据处理方面，[用 Nabi 做科学计算](../22-science.html)为每个科学计算包提供了一篇教程的入口。每个任务只在用到新东西时才链接回指南；指南中的[怎么做……](../20-cookbook.html)一章对日常系统任务给出了简短的解答。
