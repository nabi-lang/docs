# E0113: 无效的 `#[keyword]` 声明

`#[keyword("name")]` 用在作为其处理函数的自由函数上，`name` 必须是尚未成为关键字的标识符。

```nabi norun
#[keyword("if")]
fn my_if(c: bool) -> bool { c }
```

```text check=checks/E0113.nabi
error[E0113]: `#[keyword("if")]`: `if` is already a keyword
  --> main.nabi:1:1
   |
 1 | #[keyword("if")]
   | ^^
```

选一个还不是关键字的名称，例如 `#[keyword("unless")]`。
