# E0019: 需要括号的运算符

比较链中的运算符只能来自同一组：`<` 和 `<=`（`0 <= i < n`）、`>` 和 `>=`（`a > b >= c`），或者 `==`（`a == b == c`）；每一对之间以 `&&` 连接。其他的链都是错误：混用不同的组（`a < b > c`、`a < b == c`）、`a != b != c`、`x ∈ s == y` 和 `a..b..c`。用 `&&` 把各部分连起来（`a < b && b > c`），或者加括号表明你的意思。（在单轴类型上使用多个部分的索引 `xs[1:, 0]` 是 [E0143](E0143.html)。）

```nabi norun
let a = 1;
let b = 2;
println(f"{a < b > 0}");
```

```text check=checks/E0019.nabi
error[E0019]: `<` and `>` cannot be chained
  --> main.nabi:3:18
   |
 3 | println(f"{a < b > 0}");
   |                  ^
   |
   = help: a chain compares in one direction (`a < b <= c`, `a > b >= c`, `a == b == c`); write `a < b && b > c`
```

用 `&&` 连接两个比较；同一方向的链没有问题：

```nabi
let a = 1;
let b = 2;
println(f"{a < b && b > 0} {0 <= a < b}");
```

```output
true true
```
