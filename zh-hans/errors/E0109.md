# E0109: 格式错误的属性

属性的实参不是它所接受的形式，或者这个属性不是 Nabi 认识的。消息会给出正确的形式，例如 `#[path("file.nabi")]`。

```nabi norun
#[inlin]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```text check=checks/E0109.nabi
error[E0109]: unknown attribute `#[inlin]`: not built in and no meta block defines it
  --> main.nabi:1:1
   |
 1 | #[inlin]
   | ^^
```

按 [6.2 内置属性](../spec/refs-lang/006-meta-system/602-built-in-attributes.html)中列出的拼写书写属性：

```nabi
#[inline]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```output
4
```

既不是内置的、也不是由作用域中的元块定义的属性，是未知属性（[6.1.6](../spec/refs-lang/006-meta-system/601-attribute-syntax.html#616-未知属性)）。
