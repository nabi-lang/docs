# E0003: 格式错误的数字字面量

数字字面量的格式不对：数字超出了进制范围（`0b2`）、`_` 不在两个数字之间、指数没有数字、十进制数以 `0` 开头（`012`）、浮点数没有前导数字（`.5`），或者后缀的种类不对（`1.5i32`）。按消息的建议改写数字，例如 `0.5`、`1_000` 或 `0o12`。

```nabi norun
let mode = 0755;
```

```text check=checks/E0003.nabi
error[E0003]: `0755`: a decimal literal can't start with `0`
  --> main.nabi:1:12
   |
 1 | let mode = 0755;
   |            ^^^^
   |
   = help: write `0o755` for an octal number, or `755` for decimal
```

按 help 的提示改写数字，这里写成八进制：

```nabi
let mode = 0o755;
println(f"{mode}");
```

```output
493
```
