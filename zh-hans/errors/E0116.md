# E0116: 格式错误的宏定义

宏的规则格式不对。每条规则是 `( matcher ) => { template }`，元变量是 `@name: fragment`，重复是 `@rep[sep = ","] { .. }`。

```nabi norun
#[impl_macro(twice)] @macro {
    @e: expr => { (@e, @e) }
}
let p = twice!(3);
```

```text check=checks/E0116.nabi
error[E0116]: a macro rule starts with `( matcher )`
  --> main.nabi:2:5
   |
 2 |     @e: expr => { (@e, @e) }
   |     ^
```

用括号把匹配器括起来：

```nabi
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!(3);
println(f"{p.0 + p.1}");
```

```output
6
```

请见 [6.8.12 宏形式](../spec/refs-lang/006-meta-system/608-meta-blocks.html#6812-the-macro-form)。
