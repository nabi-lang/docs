# E0127: 外部工具失败

nabic 用自己的链接器链接，除非 `NABI_CC` 指定了用来链接的 C 编译器驱动程序。这个驱动程序无法启动，或者运行后失败了；它的输出跟在消息之后。修正输出中指出的问题，检查 `NABI_CC` 指定的程序已经安装并且在 `PATH` 上，或者取消设置 `NABI_CC`，用 nabic 的链接器链接。

只有构建（`build`、`run`、`test`、`bench`）中的链接和 REPL 的主机链接这两个步骤会运行外部程序，而且只在设置了 `NABI_CC` 时。无法启动时，消息是 ``cannot run the link: <reason>``；失败时，消息是 ``the link failed:``，后面是驱动程序的标准错误输出。
