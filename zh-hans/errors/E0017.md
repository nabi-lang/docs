# E0017: 位置错误的项

项或语句出现在不允许的位置：`impl` 中的 `static`、`extern` 块之外的 `static mut`、模块体中的语句，或者函数中的宏导入。按消息所说的移动它，通常是移到模块层级。

```nabi norun
mod inner {
    println("hi");
}
```

```text check=checks/E0017.nabi
error[E0017]: expected an item in `mod inner`: module bodies are definitions-only; statements belong in `main.nabi`
  --> main.nabi:2:5
   |
 2 |     println("hi");
   |     ^^^^^^^
```

模块体只放定义；把语句放进函数里：

```nabi
mod inner {
    pub fn hi() { println("hi"); }
}
inner::hi();
```

```output
hi
```
