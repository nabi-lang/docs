# E0004: 字面量超出其类型的范围

字面量放不进它的类型：`300u8`、在需要无符号类型的地方写了 `-1`，或者浮点数对 `f32` 来说太大。改用更宽的类型（`300u16`）、改成放得下的值，或者用 `int` 表示任意大小的数。

```nabi norun
let b: u8 = 300;
```

```text check=checks/E0004.nabi
error[E0004]: integer literal `300` out of range for `u8`
  --> main.nabi:1:13
   |
 1 | let b: u8 = 300;
   |             ^^^
```

使用足够容纳这个值的类型：

```nabi
let b: u16 = 300;
println(f"{b}");
```

```output
300
```
