# E0022: 没有值的 `let`

每个 `let` 都要给变量一个值。写上一个值 `let n: i32 = 0;`，或者用可选类型让它从空开始：`let n: i32 | none = none;`。

```nabi norun
let n: i32;
```

```text check=checks/E0022.nabi
error[E0022]: `let n` needs a value
  --> main.nabi:1:11
   |
 1 | let n: i32;
   |           ^
   |
   = help: give it one, `let n: i32 = ..;`, or start it empty: `let n: i32 | none = none;`
```

让它从一个值开始，或者用 `none` 加可选类型：

```nabi
let n: i32 | none = none;
println(f"{n ?? 0}");
```

```output
0
```
