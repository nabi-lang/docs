# E0029: 找不到枚举变体

枚举没有这个名称的变体。对照枚举的定义检查拼写。

```nabi norun
enum Light { Red, Green }

let l = Light::Yellow;
```

```text check=checks/E0029.nabi
error[E0029]: enum `Light` has no variant `Yellow`
  --> main.nabi:3:9
   |
 3 | let l = Light::Yellow;
   |         ^^^^^^^^^^^^^
```

使用枚举中已有的变体，或者把它加到枚举里：

```nabi
#[derive(PartialEq)]
enum Light { Red, Green, Yellow }

let l = Light::Yellow;
println(f"{l == Light::Yellow}");
```

```output
true
```
