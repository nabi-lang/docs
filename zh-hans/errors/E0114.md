# E0114: 无效的字面量处理器

`#[literal(..)]` 处理器必须是一个函数，参数符合其种类的要求，并且每个后缀、优先级和返回类型只注册一次。数字后缀或字符串前缀是紧贴在字面量上的名称（`95pct`、`date"2024-01-15"`），绝不是 `%` 或 `°` 这样的符号；后缀不能以 `e` 或 `_` 开头，它们会被读作指数和数字分隔符。带后缀或前缀的字面量需要作用域中有对应的处理器；消息会指出最接近的那个。

```nabi norun
let d = 5q;
```

```text check=checks/E0114.nabi
error[E0114]: unknown numeric literal suffix `q` - no `#[literal(number "q")]` handler is registered
  --> main.nabi:1:10
   |
 1 | let d = 5q;
   |          ^
   |
   = help: register one, `#[literal(number "q")] fn ..`, here or as a `pub fn` in a package this one depends on; the suffixes in scope are `i`
```

为这个后缀注册处理器；字面量会变成对它的调用（[6.5](../spec/refs-lang/006-meta-system/605-literal-magic.html)）：

```nabi
#[literal(number "q")]
fn quarter(n: f64) -> f64 { n / 4.0 }

let d = 5q;
println(f"{d}");
```

```output
1.25
```

与作用域中的某个后缀或前缀只差一点的写法会得到“did you mean”和快速修复：以 `signal` 为依赖时，`10Hz` 会提示 ``did you mean `10hz`?``；以 `table` 为依赖时，`dat"2024-01-15"` 会提示 ``did you mean `date`?``。百分数是后缀名，而不是 `%`，`%` 是取余运算符：

```nabi norun
let p = 95%;        // 错误：`95%` 不是百分数，写成 `95pct`
#[literal(number "°")]   // 错误：数字后缀是名称，而 `°` 是符号
const fn deg(n: f64) -> f64 { n }
```

改为注册一个名称：`#[literal(number "deg")]`，然后写 `90deg`。
