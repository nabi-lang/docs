# E0008: 格式错误的 f-string

f-string 的 `{..}` 占位格式不对：`{` 没有对应的 `}`、单独的 `}`、空的 `{}`、格式说明符里又带格式说明符，或者在 `f""".."""` 之外跨行的占位。字面的花括号写成 `{{` 或 `}}`，每个占位里都要放一个值：`f"{x}"`。

```nabi norun
let n = 3;
println(f"n = {}");
```

```text check=checks/E0008.nabi
error[E0008]: empty `{}` in f-string
  --> main.nabi:2:15
   |
 2 | println(f"n = {}");
   |               ^
```

在占位里放一个值：

```nabi
let n = 3;
println(f"{n}");
```

```output
3
```
