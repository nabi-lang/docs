# E0068: 值不可迭代

`for` 可以迭代有起点的整数区间（`0..n`、`0..`）、数组，或者实现了 `IntoIterator` 或 `Iterator`（其 `next` 返回 `T | none`）的类型；`try for` 迭代 `TryIterator`。迭代上述之一，或者调用返回迭代器的方法。

```nabi norun
struct Bag { n: i32; }

let b = Bag { n: 3 };
for x in b {
    println(f"{x}");
}
```

```text check=checks/E0068.nabi
error[E0068]: cannot iterate over a value of type `Bag` - `for` needs an integer range, an array, an `IntoIterator` / `Iterator` impl, or a `TryIterator` (`try for`)
  --> main.nabi:4:1
   |
 4 | for x in b {
   | ^^^^^^^^^^^^
```

迭代区间、集合或迭代器：

```nabi
struct Bag { n: i32; }

let b = Bag { n: 3 };
for x in 0..b.n {
    println(f"{x}");
}
```

```output
0
1
2
```
