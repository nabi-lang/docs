# E0100: 模式与值的类型不符

模式无法匹配这个类型的值：另一个结构体的结构体模式、用在非元组值上的元组模式，或者在只允许不可反驳模式的地方（`let`、参数、`for`）使用了可反驳模式。写出与值的类型相符的模式；可反驳模式用 `match` 或 `let .. else`。

```nabi norun
let n = 5;
let (a, b) = n;
```

```text check=checks/E0100.nabi
error[E0100]: tuple destructure of a non-tuple value of type `i64`
  --> main.nabi:2:1
   |
 2 | let (a, b) = n;
   | ^^^
```

解构与模式类型相符的值：

```nabi
let pair = (5, 6);
let (a, b) = pair;
println(f"{a} {b}");
```

```output
5 6
```
