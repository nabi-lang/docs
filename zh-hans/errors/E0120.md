# E0120: 递归展开

宏或元块直接或间接地展开成自身，没有尽头。打破这个循环。

```nabi norun
#[impl_macro(again)] @macro {
    ( @e: expr ) => { again!(@e) }
}
let x = again!(1);
```

```text check=checks/E0120.nabi
error[E0120]: `again!` expands too deeply or cyclically
  --> main.nabi:4:9
   |
 4 | let x = again!(1);
   |         ^^^^^
```

让模板展开成不再调用该宏的代码：

```nabi
#[impl_macro(again)] @macro {
    ( @e: expr ) => { (@e, @e) }
}
let x = again!(1);
println(f"{x.0}");
```

```output
1
```
