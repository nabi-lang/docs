# E0143: 对只沿一个轴索引的类型使用多轴索引

由多个部分组成、其中含有切片的索引（`m[1:, 0]`）为每个轴给出一个实参。`List`、`Slice`、定长数组和 `str` 只有一个轴，所以只接受一个部分。在不同的方括号中分别切片和索引（`m[1:][0]`），或者把数据放在接受轴实参的 `Array<T, N>`（`core::array::Array`）中。自定义类型要接受轴实参，可以对由 `isize` 和 `core::index::SliceArg` 组成的元组实现 `Index`。

```nabi norun
let xs = [10, 20, 30, 40];
let y = xs[1:, 0];
```

```text check=checks/E0143.nabi
error[E0143]: `List<i64>` is indexed along one axis, but this index has 2 parts with a slice among them
  --> main.nabi:2:9
   |
 2 | let y = xs[1:, 0];
   |         ^^^^^^^^^
   |
   = help: slice and index in separate brackets (`m[a:b][c]`), or keep the data in an `Array` (`core::array::Array`), which takes `m[a:b, c]`
```

先切片，再索引切片，或者使用 `Array`：

```nabi
use core::array::Array;

let xs = [10, 20, 30, 40];
let y = xs[1:][0];
let m: Array<i64, 2> = [[1, 2], [3, 4]];
println(f"{y} {m[1:, 0]:?}");
```

```output
20 [3]
```
