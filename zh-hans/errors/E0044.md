# E0044: 字面量缺少字段

结构体或变体字面量省略了一个没有默认值的字段。给每个字段一个值，或者在结构体中声明默认值（`n: i32 = 0`）。

```nabi norun
struct P { x: i32; y: i32; }

let p = P { x: 1 };
```

```text check=checks/E0044.nabi
error[E0044]: struct `P` is missing field `y` and no default is declared
  --> main.nabi:3:9
   |
 3 | let p = P { x: 1 };
   |         ^^^^^^^^^^
```

给这个字段一个值，或者在结构体中声明默认值：

```nabi
struct P { x: i32; y: i32 = 0; }

let p = P { x: 1 };
println(f"{p.y}");
```

```output
0
```
