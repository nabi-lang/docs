# E0034: 项是私有的

该项、字段或方法是另一个模块私有的（或者是另一个包中的 `pub(pkg)`），所以不能在这里使用；私有项对子模块也不可见。在定义它的地方加上消息指出的可见性：`pub(pkg)` 让它对所在包的其余部分可见，`pub` 让它对其他包可见。或者改用公开的项。

```nabi norun
mod geo {
    fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```text check=checks/E0034.nabi
error[E0034]: function `geo::area` is private to module `geo` and cannot be used from `<root>` (add `pub(pkg)` to expose it)
  --> main.nabi:4:12
   |
 4 | println(f"{geo::area(2, 3)}");
   |            ^^^^^^^^^^^^^^^
```

加上 `pub(pkg)`：

```nabi
mod geo {
    pub(pkg) fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```output
6
```

项在没有标 `pub` 时是其模块私有的（[5.6 可见性](../spec/refs-lang/005-modules/506-visibility.html)）。
