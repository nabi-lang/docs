# E0028: 找不到类型或 trait

作用域中没有这个名称的类型或 trait。检查拼写，或者用 `use` 导入它；help 会列出同名的项。

```nabi norun
let xs: Lst<i32> = [1];
```

```text check=checks/E0028.nabi
error[E0028]: cannot find type `Lst` in this scope
  --> main.nabi:1:9
   |
 1 | let xs: Lst<i32> = [1];
   |         ^^^
   |
   = help: did you mean `List`?
```

修正拼写：

```nabi
let xs: List<i32> = [1];
println(f"{xs.len()}");
```

```output
1
```
