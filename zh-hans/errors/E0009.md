# E0009: 不能用作原始标识符的名称

`r#name` 让关键字也能用作名称，但有几个名称（`self`、`Self`、`crate`、`super`、`_`）不能这样写。换一个名称。

```nabi norun
let r#self = 1;
```

```text check=checks/E0009.nabi
error[E0009]: `r#self` is not allowed: `self` can't be a raw identifier; write `self` or pick another name
  --> main.nabi:1:5
   |
 1 | let r#self = 1;
   |     ^^^^^^
```

换一个名称：

```nabi
let me = 1;
println(f"{me}");
```

```output
1
```
