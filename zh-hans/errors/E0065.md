# E0065: 锁守卫没有由 `using` 释放

锁守卫只在 `using` 块结束时释放。用 `using g = m.lock() { .. }` 而不是 `let` 绑定守卫，也不要丢弃它。

```nabi norun
let m = Mutex::new(0);
let g = m.lock();
```

```text check=checks/E0065.nabi
error[E0065]: `g` holds a `MutexGuard` that is never released: only `using` releases a lock guard, so bind it with `using g = .. { .. }`
  --> main.nabi:2:1
   |
 2 | let g = m.lock();
   | ^^^
```

用 `using` 绑定守卫：

```nabi
let m = Mutex::new(0);
using g = m.lock() { g.set(g.get() + 1) }
using g = m.lock() { println(f"{g.get()}") }
```

```output
1
```
