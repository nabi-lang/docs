# E0087: 有歧义的关联项

多个 trait、impl 或约束都提供了这个名称的方法、关联类型或常量，所以 `T::name` 不明确。写明 trait：`<T as Trait>::name`，或者以 `Trait::name(x)` 的形式调用方法。

```nabi norun
trait A { const N: i32; }
trait B { const N: i32; }
struct S {}
impl A for S { const N: i32 = 1; }
impl B for S { const N: i32 = 2; }

println(f"{S::N}");
```

```text check=checks/E0087.nabi
error[E0087]: associated const `N` of `S` is ambiguous: `A` and `B` define it - name the trait (`<T as Tr>::N`)
  --> main.nabi:7:12
   |
 7 | println(f"{S::N}");
   |            ^^^^
```

写明 trait：

```nabi
trait A { const N: i32; }
trait B { const N: i32; }
struct S {}
impl A for S { const N: i32 = 1; }
impl B for S { const N: i32 = 2; }

println(f"{<S as B>::N}");
```

```output
2
```
