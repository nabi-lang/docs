# E0084: 无效的外部函数用法

C 函数、`extern` 声明或 `extern "C" fn` 违反了 FFI 规则：C 无法容纳的类型（垃圾回收器可能移动的类型、元组、Unicode `char`、普通枚举、`str` 结果）、作为 C 回调传入的闭包、签名不同的两个声明，或者 C 不能接受的可变参数实参。类型按解析后的结果检查，会穿过别名和字段，help 会说明应该改写成什么。传入与 C 兼容的类型，回调使用具名函数。

```nabi norun
extern "C" {
    fn abs(x: i32) -> i32;
    fn abs(x: i64) -> i64;
}
```

```text check=checks/E0084.nabi
error[E0084]: extern function `abs` is declared twice with different signatures: `fn(i64) -> i64` here, `fn(i32) -> i32` elsewhere
  --> main.nabi:3:5
   |
 2 |     fn abs(x: i32) -> i32;
   |     -- declared as `fn(i32) -> i32` here
 3 |     fn abs(x: i64) -> i64;
   |     ^^
   |
   = help: a C symbol has one signature: declare `abs` as `fn(i32) -> i32` here too, or drop this declaration
```

每个 C 函数只声明一次，使用它的 C 签名：

```nabi
extern "C" {
    fn abs(x: c_int) -> c_int;
    fn labs(x: c_long) -> c_long;
}
println(f"{unsafe { labs(-5) }}");
```

```output
5
```
