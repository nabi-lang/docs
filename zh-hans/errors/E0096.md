# E0096: 不起作用的 `try` 或 `catch`

`try` 没有覆盖任何会抛出错误的调用，或者没有错误能到达 `catch`。删除它。

```nabi norun
let n = try 1 + 2;
println(f"{n}");
```

```text check=checks/E0096.nabi
warning[E0096]: this `try` covers no throwing call
  --> main.nabi:1:9
   |
 1 | let n = try 1 + 2;
   |         ^^^^^^^^^
```

删除 `try`：

```nabi
let n = 1 + 2;
println(f"{n}");
```

```output
3
```

这是警告：程序仍然可以构建。
