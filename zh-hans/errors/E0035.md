# E0035: 模块文件有问题

无法加载 `mod name;`：它的文件 `name.nabi` 不存在或不可读、模块声明了两次，或者它既是内联模块又是文件。模块的文件以模块命名（Nabi 没有 `mod.nabi`），放在声明它的文件旁边。

```nabi norun
mod geo;
```

```text check=checks/E0035.nabi
error[E0035]: module `geo` body not found at `geo.nabi`
   = help: create `geo.nabi`, or write `mod geo { .. }` in place of `mod geo;`
```

在 `main.nabi` 旁边创建 `geo.nabi`，或者把模块写成内联的：`mod geo { .. }`（[5.4 模块](../spec/refs-lang/005-modules/504-modules.html)）。

相关错误码：[E0030](E0030.html) 无法解析的导入、[E0036](E0036.html) 无效的程序入口点
