# E0118: 无效的元模板

元块的模板错误地使用了 `@` 记号：未知的记号、在它所需的 `@for_fields` 或 `@for_variants` 之外使用的记号，或者缺少 `(..)` 或 `{ .. }` 的记号。按消息所说书写。

```nabi norun
#[impl_derive(Names)] @derive {
    impl @Self {
        fn names() -> str { @fild }
    }
}
#[derive(Names)]
struct P { x: i32; }
```

```text check=checks/E0118.nabi
error[E0118]: unknown template token `@fild`
  --> main.nabi:3:29
   |
 3 |         fn names() -> str { @fild }
   |                             ^
 ...
 6 | #[derive(Names)]
   | -- in this `#[derive(Names)]`
```

按 [6.9 模板记号](../spec/refs-lang/006-meta-system/609-template-tokens.html)中列出的拼写书写记号：这里是 `@field`，写在 `@for_fields { .. }` 块中。
