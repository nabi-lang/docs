# E0079: 无法在编译时求值

常量、数组长度、常量泛型实参或 `const fn` 的主体使用了在编译时没有值的东西：调用普通 `fn`、堆分配或运行时的值。使用字面量、其他常量和 `const fn` 调用。

```nabi norun
fn three() -> i32 { 3 }
const N: i32 = three();
```

```text check=checks/E0079.nabi
error[E0079]: const `N` cannot be evaluated at compile time: calls `three`, which is not a `const fn`
  --> main.nabi:2:16
   |
 2 | const N: i32 = three();
   |                ^^^^^^^
```

把函数改为 `const fn`：

```nabi
const fn three() -> i32 { 3 }
const N: i32 = three();
println(f"{N}");
```

```output
3
```
