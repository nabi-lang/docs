# E0104: 无效的剩余模式

一个模式最多只有一个 `..`，剩余模式只能出现在消息所说的位置。删除多余的 `..`。

```nabi norun
enum E { A(i32, i32, i32) }

let v = E::A(1, 2, 3);
match v {
    E::A(x, .., y, ..) => println(f"{x}"),
}
```

```text check=checks/E0104.nabi
error[E0104]: pattern `E::A` has more than one `..`
  --> main.nabi:4:1
   |
 4 | match v {
   | ^^^^^^^^^
```

只保留一个 `..`：

```nabi
enum E { A(i32, i32, i32) }

let v = E::A(1, 2, 3);
match v {
    E::A(x, .., y) => println(f"{x} {y}"),
}
```

```output
1 3
```
