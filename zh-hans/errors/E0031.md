# E0031: 有歧义的名称

有多个 glob 导入（`use a::*;`）或包提供了这个名称，因此不清楚指的是哪一个。按名称导入你想要的那个，或者写出它的路径。

```nabi norun
use a::*;
use b::*;

mod a { pub fn item() -> i32 { 1 } }
mod b { pub fn item() -> i32 { 2 } }
println(f"{item()}");
```

```text check=checks/E0031.nabi
error[E0031]: name `item` is ambiguous in module `<root>` - multiple glob imports resolve it: a::item, b::item
  --> main.nabi:6:12
   |
 6 | println(f"{item()}");
   |            ^^^^^^
```

按名称导入你指的那个：

```nabi
use a::item;

mod a { pub fn item() -> i32 { 1 } }
mod b { pub fn item() -> i32 { 2 } }
println(f"{item()}");
```

```output
1
```
