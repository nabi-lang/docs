# E0053: 无效的强制转换

`as` 在数字、`bool` 和 `char` 之间转换，也能把不带载荷的枚举转换为整数；其他转换都是方法。只有 `u8` 能强制转换为 `char`（更宽的值用 `char::from_u32(n)`），任何类型都不能强制转换为 `bool`（改用比较：`n != 0`）。使用消息建议的转换方法。

```nabi norun
let n = 98u32;
let c = n as char;
```

```text check=checks/E0053.nabi
error[E0053]: only `u8` can be cast as `char`, not `u32`; use `char::from_u32(n)` (`char | none`) for a wider value
  --> main.nabi:2:9
   |
 2 | let c = n as char;
   |         ^^^^^^^^^
```

用 `char::from_u32` 转换，对不是字符的值它会给出 `none`：

```nabi
let n = 98u32;
let c = char::from_u32(n) ?? '?';
println(f"{c}");
```

```output
b
```
