# E0140: 对不是位置的值赋值

`=` 或复合赋值（`+=`、`-=` 等）的左边是一个值，而不是位置：调用结果（`f()`、`d.entry(k).or_insert(0)`）、运算结果或元组。对它赋值只会修改一个随即被丢弃的临时值。对变量、变量的字段（`s.x += 1`）或元素（`xs[i] += 1`）赋值。要保留调用的结果，先绑定它：`let v = f(); v += 1;`。要在字典中计数，用带默认值的索引：`d[k, default: 0] += 1;`。锁守卫的 `get()` 返回的也是副本：用 `g.update(|v| { v.x += 1; v })` 或 `g.set(v)` 修改存储的值。

```nabi norun
let counts = Dict::new();
for w in ["a", "b", "a"] {
    counts.entry(w).or_insert(0) += 1;
}
```

```text check=checks/E0140.nabi
error[E0140]: cannot use `+=` on `counts.entry(w).or_insert(0)`: a call result is not a place, so the change would be lost
  --> main.nabi:3:5
   |
 3 |     counts.entry(w).or_insert(0) += 1;
   |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^
   |
   = help: index with a default: `counts[w, default: 0] += 1;`
```

`or_insert` 返回的是计数，而不是字典中的槽，所以 `+= 1` 只会加到副本上。改用带默认值的索引，键不存在时它会先存入 `0`：

```nabi
let counts = Dict::new();
for w in ["a", "b", "a"] {
    counts[w, default: 0] += 1;
}
println(f"a={counts["a"]} b={counts["b"]}");
```

```output
a=2 b=1
```

调用结果的字段（`p().x += 1`）和调用返回的定长数组的元素（`arr()[0] = 5`）也是如此：把值绑定到变量上，再修改变量。调用返回的 `List` 或 `Dict` 的元素是位置，因为集合是共享的：`rows()[0] += 1` 会修改 `rows()` 返回的列表（[3.4.1](../spec/refs-lang/003-expressions/304-assignment.html#341-simple-assignment)）。
