# E0112: 无效的运算符声明

trait 方法上的运算符属性（`#[infix(..)]`、`#[prefix(..)]` 等）违反了规则：不能作为运算符的词法单元（`′` 或 `ℱ` 这样的标识符字符，或者在没有对应形式的位置上使用固定词法单元，二元的 `@` 和 `~` 除外）、为内置词法单元指定优先级、别名位于不同的层级、会抛出错误的方法（运算符不抛出错误：改为返回 `Result` 或 `T | E`），或者固定运算符的 Unicode 写法（`≤` 被读作 `<=`；改为实现 `ops::PartialOrd`）。新的词法单元用 `like = "<existing token>"` 指定它的优先级。

```nabi norun
trait Before {
    #[infix(">>>", precedence = 3)]
    fn before(self, o: Self) -> bool;
}
```

```text check=checks/E0112.nabi
error[E0112]: `#[infix]` takes only an operator token, `like = ".."` and `swap`: precedence and associativity are fixed by the language
  --> main.nabi:2:5
   |
 2 |     #[infix(">>>", precedence = 3)]
   |     ^^
```

删除优先级。新的词法单元用 `like` 借用内置词法单元的优先级：`#[infix(">>>", like = ">>")]`（[6.7](../spec/refs-lang/006-meta-system/607-operator-magic.html)）。
