# E0148: 只是看起来像词法单元的字符

代码中有一个看起来像 ASCII 词法单元、实际上却是另一个字符的字符：用 `−`（MINUS SIGN）代替 `-`、用弯引号代替 `"`、用全角的 `（` 代替 `(`。这些字符来自文字处理软件和网页。写出消息指出的 ASCII 词法单元；快速修复会替换它。

```nabi norun
let d = 10 − 3;
println(f"{d}");
```

```text check=checks/E0148.nabi
error[E0148]: `−` (U+2212 MINUS SIGN) looks like `-` but is another character
  --> main.nabi:1:12
   |
 1 | let d = 10 − 3;
   |            ^
   |
   = help: write `-`
```

写出 ASCII 词法单元：

```nabi
let d = 10 - 3;
println(f"{d}");
```

```output
7
```

只有在它所模仿的词法单元存在的地方，相似字符才会被报告：如果某个包自己把 `−` 注册为运算符（[6.7](../spec/refs-lang/006-meta-system/607-operator-magic.html)），它就成了一个独立的词法单元；没有任何东西注册的运算符符号是 [E0001](E0001.html)。
