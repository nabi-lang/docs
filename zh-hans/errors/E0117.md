# E0117: 没有匹配的宏规则

宏的所有规则都不匹配这次调用的实参。对照宏的匹配器检查调用。

```nabi norun
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!();
```

```text check=checks/E0117.nabi
error[E0117]: no rule of macro `twice!` matches this call
  --> main.nabi:4:9
   |
 4 | let p = twice!();
   |         ^^^^^
```

用某条规则能匹配的实参调用它：

```nabi
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!(3);
println(f"{p.0}");
```

```output
3
```
