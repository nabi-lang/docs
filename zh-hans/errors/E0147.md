# E0147: 代码中有不可见字符

代码中有一个什么也不显示或者看起来像普通空格的字符：零宽空格或连接符（U+200B 到 U+200D）、不在文件开头的字节顺序标记（U+FEFF）、没有可修饰对象的变体选择符、填充字符（U+3164），或者 U+00A0 NO-BREAK SPACE 这样的空格。这样一来，两行看起来相同的代码可能意思不同，所以 Nabi 不会把它们当作代码，也不会当作名称的一部分。删除这个字符，或者写一个普通空格；在字符串中把它写成转义 `"\u{200B}"`。

下面 f-string 中的名称中间有一个零宽空格，这通常是从网页或聊天中复制时留下的：

```nabi norun
let count = 3;
println(f"{co​unt}");
```

```text check=checks/E0147.nabi
error[E0147]: identifier `count` holds the invisible character U+200B ZERO WIDTH SPACE: it reads as `count` but is another name
  --> main.nabi:2:12
   |
 2 | println(f"{co​unt}");
   |            ^^^^^^
   |
   = note: as written: `co\u{200B}unt`
   = help: write `count`
```

删除这个字符；编辑器中的快速修复会替你删除：

```nabi
let count = 3;
println(f"{count}");
```

```output
3
```

在字符串或注释中，同样的字符会改为触发 `hidden_chars` 警告：把它们写成 `\u{..}` 转义，让读者能看到。emoji 序列中的 ZWJ，以及波斯文或印度系文字中的 ZWNJ，看起来就是它们本来的样子，不会被报告。
