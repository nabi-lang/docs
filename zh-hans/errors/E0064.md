# E0064: 对非可选值使用可选运算符

`?`、`??` 和 `?.` 用于可选值（`T | none`），`try?` / `try!` 用于会抛出错误的调用。对普通值使用 `.`；要把错误向外传递，使用 `throws` 和 `try`。

```nabi norun
let xs = [1, 2, 3];
let n = xs.len()?;
```

```text check=checks/E0064.nabi
error[E0064]: `?` only works on `T | none`, found `usize` - to propagate errors use `throws` and `try`
  --> main.nabi:2:9
   |
 2 | let n = xs.len()?;
   |         ^^^^^^^^^
```

直接使用这个值：

```nabi
let xs = [1, 2, 3];
let n = xs.len();
println(f"{n}");
```

```output
3
```
