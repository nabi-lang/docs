# E0051: 无效的展开实参

`f(..x)` 把元组、`List`、`Slice`、数组或 `Dict<str, V>` 展开为实参，并且要求被调用者在编译时已知。展开上述类型之一，或者逐个传入实参。

```nabi norun
fn sum(xs: ...i32) -> i32 { 0 }

let n = 3;
println(f"{sum(..n)}");
```

```text check=checks/E0051.nabi
error[E0051]: spread into a variadic `...T` needs a tuple, a `List`, a `Slice` or an array, found `i64`
  --> main.nabi:4:12
   |
 4 | println(f"{sum(..n)}");
   |            ^^^^^^^^
```

展开一个集合：

```nabi
fn sum(xs: ...i32) -> i32 {
    let t = 0;
    for x in xs { t += x; }
    t
}

let ns = [1, 2, 3];
println(f"{sum(..ns)}");
```

```output
6
```
