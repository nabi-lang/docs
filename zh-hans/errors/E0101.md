# E0101: 模式中的字段个数不对

元组模式或变体模式的部分比值多或少。匹配每个部分，或者用 `..` 表示其余部分。

```nabi norun
let t = (1, 2, 3);
let (a, b) = t;
```

```text check=checks/E0101.nabi
error[E0101]: tuple destructure length mismatch: pattern has 2 elements, value has 3
  --> main.nabi:2:1
   |
 2 | let (a, b) = t;
   | ^^^
```

匹配每个部分，或者用 `..` 表示其余部分：

```nabi
let t = (1, 2, 3);
let (a, ..) = t;
println(f"{a}");
```

```output
1
```

相关错误码：[E0100](E0100.html) 模式与值的类型不符、[E0104](E0104.html) 无效的剩余模式
