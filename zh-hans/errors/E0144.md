# E0144: 整数的负数次幂

整数底数的 `b ** e` 给出整数，所以指数是 `u32`：`2 ** -1` 会是 `0.5`，没有任何整数能容纳它。对浮点数求幂（`2.0 ** -1.0` 或 `(x as f64) ** -1.0`），或者让指数保持非负。

```nabi norun
let half = 2 ** -1;
```

```text check=checks/E0144.nabi
error[E0144]: `i64` to a negative power is a fraction, not an integer
  --> main.nabi:1:17
   |
 1 | let half = 2 ** -1;
   |                 ^^
   |
   = help: raise a float instead: `2.0 ** -1.0`
```

对浮点数求幂：

```nabi
let half = 2.0 ** -1.0;
let n: i32 = 4;
println(f"{half} {(n as f64) ** -1.0}");
```

```output
0.5 0.25
```
