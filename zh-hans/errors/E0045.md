# E0045: 字段给出了多次

结构体字面量两次写了同一个字段。删除其中一个。

```nabi norun
struct P { x: i32 }

let p = P { x: 1, x: 2 };
```

```text check=checks/E0045.nabi
error[E0045]: field `x` specified more than once in `P` literal
  --> main.nabi:3:9
   |
 3 | let p = P { x: 1, x: 2 };
   |         ^^^^^^^^^^^^^^^^
```

字段只写一次：

```nabi
struct P { x: i32 }

let p = P { x: 2 };
println(f"{p.x}");
```

```output
2
```
