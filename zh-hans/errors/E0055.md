# E0055: 字面量适合多种类型

没有后缀的字面量可能是调用或运算符所接受的多种类型中的任意一种。如果其中之一是字面量的默认类型（整数为 `i64`，浮点数为 `f64`），字面量就采用它；否则它的类型不明确。加上后缀（`1i32`）或 `as`。

```nabi norun
struct X { v: i64; }
impl From<i32> for X { fn from(x: i32) -> X { X { v: x as i64 } } }
impl From<u8> for X { fn from(x: u8) -> X { X { v: x as i64 } } }

let x = X::from(5);
```

```text check=checks/E0055.nabi
error[E0055]: `X::from`: the literal fits several `From` impls of `X` (`i32`, `u8`); add a suffix or `as`
  --> main.nabi:5:9
   |
 5 | let x = X::from(5);
   |         ^^^^^^^^^^
```

加上后缀：

```nabi
struct X { v: i64; }
impl From<i32> for X { fn from(x: i32) -> X { X { v: x as i64 } } }
impl From<u8> for X { fn from(x: u8) -> X { X { v: x as i64 } } }

let x = X::from(5i32);
println(f"{x.v}");
```

```output
5
```
