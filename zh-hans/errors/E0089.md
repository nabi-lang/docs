# E0089: 无效的编译器内建调用

对编译器内建（`size_of::<T>()`、`atomic_*` 和指针操作、`addr_of`、`GcBuf` 函数）的调用实参不对：在需要位置的地方传了值、内存顺序不是常量，或者缺少类型实参。按消息所示调用它。

```nabi norun
use bare::mem::size_of;

let n = size_of();
```

```text check=checks/E0089.nabi
error[E0089]: `size_of` is called as `size_of::<T>()`
  --> main.nabi:3:9
   |
 3 | let n = size_of();
   |         ^^^^^^^^^
```

给出类型实参：

```nabi
use bare::mem::size_of;

println(f"{size_of::<i64>()}");
```

```output
8
```
