# E0010: 意外的词法单元

解析器期望一样东西，却遇到了另一样：缺少 `;`、`,`、`)` 或 `}`，在该写名称的地方写了关键字，或者在该写项的地方写了表达式。消息会说明期望的是什么。按它写，或者检查前一行有没有没闭合的地方。

```nabi norun
let x = (1 + 2;
println(f"{x}");
```

```text check=checks/E0010.nabi
error[E0010]: expected `)`, found `;`
  --> main.nabi:1:15
   |
 1 | let x = (1 + 2;
   |         - unclosed delimiter
   |               ^ expected `)`
```

闭合括号：

```nabi
let x = (1 + 2);
println(f"{x}");
```

```output
3
```

缺少 `;` 时报告 ``expected `;` ``，并附有 ``help: add `;` at the end of the statement``。分隔符没有闭合时，第二个标记会指向它。
