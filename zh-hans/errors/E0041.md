# E0041: 分支的类型不同

`if` 或 `match` 的各个分支、循环的各个 `break`，或者没有写返回类型的函数的各条返回路径，给出了不同类型的值。Nabi 不会替它们构造一个和类型：给接收的位置标注和类型 `let v: i64 | str = if c { 1 } else { "a" };`，写出返回类型（`-> i64 | str`），或者让各分支的类型一致。本身已是和类型的分支按其成员计算：当其他每个分支都是这个和类型或它的某个成员时，无论顺序如何，结果都是这个和类型（`none` 和 `i64 | none` 得到 `i64 | none`，`str` 和 `i64 | str` 得到 `i64 | str`），但 `none` 和 `i64` 仍然不同。没有后缀的字面量采用其他分支的类型（`if c { 1 } else { 2u8 }` 是 `u8`；与 `i32 | none` 并列时是 `i32`），但整数字面量永远不会是浮点数：写 `1.0`。

```nabi norun
let c = true;
let v = if c { 1 } else { "one" };
```

```text check=checks/E0041.nabi
error[E0041]: `if` branches have different types `i64` and `str` - Nabi does not infer a sum type; annotate the slot (`let v: i64 | str = if ...`)
  --> main.nabi:2:9
   |
 2 | let v = if c { 1 } else { "one" };
   |         ^^^^^^^^^^^^^^^^^^^^^^^^^
```

给变量标注和类型：

```nabi
let c = true;
let v: i64 | str = if c { 1 } else { "one" };
println(f"{v is i64}");
```

```output
true
```

本身已是和类型的分支不需要标注：

```nabi
let c = false;
let r: i64? = 7;
let v = if c { none } else { r };
println(f"{v ?? 0}");
```

```output
7
```
