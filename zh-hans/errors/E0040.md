# E0040: 类型不匹配

在需要一种类型的地方使用了另一种类型的值：实参、带类型的 `let`、返回值，或者函数体用 `;` 丢弃了的函数值。转换这个值（`as i32`、`.to_str()`），修改期望的类型，或者去掉 `;`。

```nabi norun
fn half(x: i32) -> i32 { x / 2 }
println(f"{half(3.0)}");
```

```text check=checks/E0040.nabi
error[E0040]: mismatched types: argument `x` of `half` expects `i32`, found `f64`
  --> main.nabi:2:17
   |
 2 | println(f"{half(3.0)}");
   |                 ^^^
   |
   = help: convert it with `as`: `3.0 as i32`
```

传入 `i32`，或者用 `as` 显式转换：

```nabi
fn half(x: i32) -> i32 { x / 2 }
println(f"{half(3)}");
```

```output
1
```

Nabi 没有隐式数值转换，所以在需要 `i32` 的地方不接受 `f64`（[2.14 强制转换与类型转换](../spec/refs-lang/002-types/214-cast-and-conversion.html)）。大多数消息都会加一行 `help:`，说明应该改写成什么。
