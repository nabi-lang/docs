# E0081: 无效的常量泛型实参

常量泛型实参的类型不对，或者超出了其参数的范围。传入参数类型的常量。

```nabi norun
struct Sep<const C: char> {}

let s = Sep::<97> {};
```

```text check=checks/E0081.nabi
error[E0081]: const argument for `C: char` must be a `char`, found an integer
  --> main.nabi:3:9
   |
 3 | let s = Sep::<97> {};
   |         ^^^^^^^^^^^^
```

传入参数类型的常量：

```nabi
struct Sep<const C: char> {}

let s = Sep::<'a'> {};
println("ok");
```

```output
ok
```

`{ .. }` 实参在编译时运行。它触发 panic 时，错误会说明这一点并附上消息（`evaluating the const generic argument panicked: <message>`）：传入该 `const fn` 接受的值，或者传入字面量。

相关错误码：[E0082](E0082.html) 泛型实参不对，[E0079](E0079.html) 无法在编译时求值
