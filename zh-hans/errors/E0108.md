# E0108: 无法派生

`#[derive(..)]` 无法为这个类型实现该 trait：某个字段没有实现它、它还需要派生另一个 trait，或者 derive 不支持这种类型。手动实现这个 trait，或者修正消息指出的字段。

```nabi norun
struct NoClone { n: i32; }
#[derive(Clone)]
struct Holder { n: NoClone; }
```

```text check=checks/E0108.nabi
error[E0108]: cannot derive `Clone` for `Holder`: `n` has type `NoClone`, which does not implement `Clone`
  --> main.nabi:2:1
   |
 2 | #[derive(Clone)]
   | ^^
```

也为字段的类型派生这个 trait，或者手动实现它：

```nabi
#[derive(Clone)]
struct NoClone { n: i32; }
#[derive(Clone)]
struct Holder { n: NoClone; }
let h = Holder { n: NoClone { n: 1 } };
println(f"{h.clone().n.n}");
```

```output
1
```

根本不能派生的 trait，例如 `Display`，也是 E0108；消息会说明原因。
