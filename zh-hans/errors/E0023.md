# E0023: 无效的函数签名

函数的参数或返回类型违反了规则：可变参数 `...` 不在最后、协程或 `fn` 值上的 `ref` 参数、没有会抛出错误的参数却写了 `rethrows`，或者测试属性不允许的签名。消息会指出违反的规则；按规则修改签名。

```nabi norun
fn f(a: i32, ...) -> i32 { a }
```

```text check=checks/E0023.nabi
error[E0023]: `f`: a C variadic `...` parameter is only allowed on a declaration in an `extern "C" { .. }` block
  --> main.nabi:1:1
   |
 1 | fn f(a: i32, ...) -> i32 { a }
   | ^^
```

C 可变参数只用于 `extern` 声明。Nabi 函数用 `...T` 接受任意个实参：

```nabi
fn sum(xs: ...i32) -> i32 {
    let t = 0;
    for x in xs { t += x; }
    t
}
println(f"{sum(1, 2, 3)}");
```

```output
6
```
