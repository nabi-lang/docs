# E0058: 无效的闭包捕获

闭包的捕获列表（`[ref x]`）指定了它不能捕获的东西：没有这个名称的变量，或者在可能运行于另一个线程的闭包中使用 `ref` 捕获。捕获 `let` 变量或参数；跨线程共享则通过 `Mutex` 或原子类型。

```nabi norun
let total = 0;
let add = [ref totl] |x: i32| { total += x; };
```

```text check=checks/E0058.nabi
error[E0058]: `[ref totl]` names no variable in scope
  --> main.nabi:2:11
   |
 2 | let add = [ref totl] |x: i32| { total += x; };
   |           ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
```

按名称捕获变量：

```nabi
let total = 0;
let add = [ref total] |x: i32| { total += x; };
add(2);
println(f"{total}");
```

```output
2
```
