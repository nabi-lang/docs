# E0139: 流视图在其流之后仍被使用

`r.lines()`、`bytes`、`split`、`take`、它们的异步流以及 `incoming` 都通过 `r` 读取，并停留在 `r` 的所有者的作用域中：其中一个被返回、被存储到该作用域之外、被被调用者保留，或者在 `r` 关闭或移动之后被使用。在作用域中使用它，并收集你需要的东西（`try r.lines().collect()`），或者采用拥有所有权的形式（`r.into_lines()`），它拥有 `r`，在自身关闭时一并关闭 `r`，并且可以被返回或移入任务。

```nabi norun
use std::fs::File;
use core::io::{BufReader, IoError, Lines};

fn lines_of(path: str) throws (IoError) -> Lines<BufReader<File>> {
    using r = BufReader::new(try File::open(path)) {
        return r.lines();
    }
}
```

```text check=checks/E0139.nabi
error[E0139]: this returns a view of `r` out of `r`'s scope
  --> main.nabi:6:9
   |
 6 |         return r.lines();
   |         ^^^^^^
   |                --------- a view of `r` made here
   |
   = help: `r.lines()` reads through `r` and stays in its scope; use it there (`try r.lines().collect()`), or take the owning form `r.into_lines()`, which owns `r` and closes it with itself
```

返回拥有所有权的形式。它是一个 `io::Owned`：它拥有读取器，关闭它就会关闭读取器：

```nabi
use std::env;
use std::fs;
use std::fs::File;
use std::process;
use core::io::{BufReader, IoError, Lines, Owned};

fn lines_of(path: str) throws (IoError) -> Owned<Lines<BufReader<File>>, BufReader<File>> {
    BufReader::new(try File::open(path)).into_lines()
}

fn main() throws (IoError) {
    let p = env::temp_dir() / f"nabi_e0139_{process::id()}.txt";
    try fs::write(p, "one\ntwo\n");
    let ls = try lines_of(p.as_str());
    try for l in ls {
        println(l);
    }
    try ls.close();
    try fs::remove_file(p);
}
```

```output
one
two
```

移动 `r` 也会结束它的视图。在 `let kept = r;`、按值传递 `r`、用 `[move r]` 捕获它或者把它存入结构体之后，之前由 `r` 创建的视图就不能再使用：

```nabi norun
use std::fs::File;
use core::io::{BufReader, IoError};

fn count(path: str) throws (IoError) -> usize {
    let r = BufReader::new(try File::open(path));
    let ls = r.lines();
    let kept = r;
    let n = 0usize;
    try for l in ls { n += 1; }
    try kept.close();
    n
}
```

```text check=checks/E0139-moved.nabi
  --> main.nabi:9:18
   |
 6 |     let ls = r.lines();
   |              --------- a view of `r` made here
 7 |     let kept = r;
   |                - `r` moved here
 ...
 9 |     try for l in ls { n += 1; }
   |                  ^^
   |
   = help: `ls` reads through `r`, so it ends where `r` moves; finish with `ls` before moving `r`, or take the owning form `r.into_lines()` and move that instead
```

在 `r` 移动之前用完视图，或者采用拥有所有权的形式并移动它：

```nabi
use std::env;
use std::fs;
use std::fs::File;
use std::process;
use core::io::{BufReader, IoError};

fn count(path: str) throws (IoError) -> usize {
    let r = BufReader::new(try File::open(path));
    let n = 0usize;
    try for l in r.lines() { n += 1; }
    let kept = r;
    try kept.close();
    n
}

fn main() throws (IoError) {
    let p = env::temp_dir() / f"nabi_e0139m_{process::id()}.txt";
    try fs::write(p, "one\ntwo\n");
    println(f"{try count(p.as_str())}");
    try fs::remove_file(p);
}
```

```output
2
```
