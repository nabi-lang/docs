# E0015: 没有描述任何内容的文档注释

文档注释（`///` 或 `/** */`）要紧接在它所描述的项之前。把它移到那里，或者改成普通注释（`//`）。

```nabi norun
fn f() {}
/// The answer.
```

```text check=checks/E0015.nabi
error[E0015]: doc comment documents nothing: it must come before an item; use `//` for a plain comment
  --> main.nabi:2:1
   |
 2 | /// The answer.
   | ^^^^^^^^^^^^^^^
```

把文档注释移到它所描述的项上：

```nabi
/// The answer.
fn answer() -> i32 { 42 }
println(f"{answer()}");
```

```output
42
```
