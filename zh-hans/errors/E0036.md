# E0036: 无效的程序入口点

程序要么从 `main.nabi` 的顶层语句开始，要么从 `fn main` 开始，二者不能并存；其他文件只放定义。`fn main` 不接受参数，不能是泛型或 `unsafe`，返回 `()` 或 `i32`；它可以是 `async`，带 `throws` 的 `main` 返回 `()`。

```nabi norun
fn main(args: List<str>) {}
```

```text check=checks/E0036.nabi
error[E0036]: `fn main`: takes no parameters; read arguments through `std::env`
  --> main.nabi:1:1
   |
 1 | fn main(args: List<str>) {}
   | ^^
```

通过 `std::env` 读取实参：

```nabi
use std::env;

fn main() {
    println(f"{env::args().len() > 0}");
}
```

```output
true
```

返回其他类型的 `fn main` 也是 E0036，消息是 `` `fn main`: must return `()` or `i32` ``（[4.16](../spec/refs-lang/004-functions/416-entry-point.html)）。

相关错误码：[E0018](E0018.html) 顶层语句中带值的 `return`，[E0023](E0023.html) 无效的函数签名
