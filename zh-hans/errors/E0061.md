# E0061: 操作需要 `unsafe`

这个操作可能破坏内存安全：调用 `unsafe` 或 `extern` 函数、读取联合体字段，或者不经检查地索引 `GcBuf`。把它包在 `unsafe { .. }` 中；如果它是一个基础构件，则放在 `unsafe fn` 中。

```nabi norun
unsafe fn danger() -> i32 { 1 }
println(f"{danger()}");
```

```text check=checks/E0061.nabi
error[E0061]: call to unsafe function `danger` outside an `unsafe` block or `unsafe fn`
  --> main.nabi:2:12
   |
 2 | println(f"{danger()}");
   |            ^^^^^^^^
   |
   = help: wrap the call in `unsafe { .. }`; every `extern` function, `extern "nabi"` included, is unsafe to call
```

把调用包在 `unsafe { .. }` 中：

```nabi
unsafe fn danger() -> i32 { 1 }
println(f"{unsafe { danger() }}");
```

```output
1
```
