# E0046: 没有这个方法或关联项

该类型没有这个名称的方法、关联函数或关联常量，或者没有适用于这些类型的。检查拼写、提供它的 trait 的 `use`，以及它的约束。

```nabi norun
let s = "nabi";
println(s.size());
```

```text check=checks/E0046.nabi
error[E0046]: no method `size` found for type `str`
  --> main.nabi:2:9
   |
 2 | println(s.size());
   |         ^^^^^^^^
   |
   = help: did you mean `len`?
```

使用 help 建议的方法：

```nabi
let s = "nabi";
println(f"{s.len()}");
```

```output
4
```

通过存放函数或可调用值的字段进行的调用 `r.f(x)` 也是 E0046：方法调用从不查找字段。help 会提示写成 `(r.f)(x)`。

只在其他平台上存在的方法也是 E0046，并附有一条说明它在哪里存在的 note（[第 17 章](../learn/17-conditional-compilation.html)）。未导入的 trait 的方法是 [E0135](E0135.html)。
