# E0050: `ref` 参数与实参不匹配

`ref` 参数接受写成 `ref x` 的实参，它指向一个变量或变量的字段；普通参数接受普通实参。同一个变量不能在一次调用中传给两个 `ref` 参数。只在参数带 `ref` 的地方写 `ref`。

```nabi norun
fn inc(ref n: i32) { n += 1; }

let c = 0;
inc(c);
```

```text check=checks/E0050.nabi
error[E0050]: parameter `n` of `inc` is `ref` - pass `ref c` at the call site
  --> main.nabi:4:1
   |
 4 | inc(c);
   | ^^^^^^
```

在调用处也写上 `ref`：

```nabi
fn inc(ref n: i32) { n += 1; }

let c = 0;
inc(ref c);
println(f"{c}");
```

```output
1
```
