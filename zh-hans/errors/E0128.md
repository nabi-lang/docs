# E0128: 无效的 WIT

`ffi::wit::import { .. }` 或 `ffi::wit::export { .. }` 指定的 `.wit` 文件无法读取、解析或解析其引用。创建这个文件或修正它的路径（相对于源文件），或者在消息指出的位置修正 WIT 文件（[标准库 1.8](../spec/refs-standard-libraries/100-bare/108-wit.html)）。

```nabi norun
ffi::wit::import { "calc.wit" }
```

```text check=checks/E0128.nabi
error[E0128]: WIT: calc.wit:0:0: cannot read: No such file or directory (os error 2)
  --> main.nabi:1:1
   |
 1 | ffi::wit::import { "calc.wit" }
   | ^^^
```

创建 WIT 文件，或者修正路径；路径相对于源文件。文件存在但无法解析时，消息会给出行号和列号。

相关错误码：[E0084](E0084.html) 无效的外部函数用法、[E0125](E0125.html) 无法读取或写入文件
