# E0119: 无效的元块

元块的定义或使用违反了规则：它占用了内置属性的名称、它是另一个文件私有的、它的主体没有以正确的 `@` 块开始，或者它展开成了项以外的东西。按消息所说修正定义或使用。

```nabi norun
#[impl_derive(Clone)] @derive {
    impl Clone for @Self {}
}
```

```text check=checks/E0119.nabi
error[E0119]: `Clone` is a built-in derive; a meta block cannot redefine it
  --> main.nabi:1:1
   |
 1 | #[impl_derive(Clone)] @derive {
   | ^^
```

给这个 derive 取一个自己的名称，例如 `#[impl_derive(MyClone)]`，或者使用内置的 `#[derive(Clone)]`。
