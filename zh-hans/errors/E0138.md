# E0138: `pub` 函数的签名没有写全

`pub` 或 `pub(pkg)` 函数会被其他模块调用，所以它的签名要写出来，而不是从函数体推断。给每个参数一个类型 `x: i32`（或者用类型参数 `fn f<T>(x: T)` 表示任意类型）。没有 `->` 时它返回 `()`；函数体给出值时，按快速修复所示写出它的类型 `-> i32`。例外：私有函数和 `pub(sub)` 函数仍然可以推断；trait impl 的方法采用 trait 的类型；`self` 和可变参数 `...T` 参数不需要类型；`main` 和生成器可以省略 `->`；没有函数体的函数（`extern`）按所写的声明。

```nabi norun
pub fn double(x: i32) { x * 2 }

println(f"{double(4)}");
```

```text check=checks/E0138.nabi
error[E0138]: `pub fn double` has no `->`, so it returns `()`, but its body gives `i32`
  --> main.nabi:1:25
   |
 1 | pub fn double(x: i32) { x * 2 }
   |                         ^^^^^
   |
   = help: write `-> i32` before the body
```

写出返回类型：

```nabi
pub fn double(x: i32) -> i32 { x * 2 }

println(f"{double(4)}");
```

```output
8
```
