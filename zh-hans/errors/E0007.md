# E0007: 字符字面量只能包含一个字符

`'..'` 字面量恰好包含一个 Unicode 码位，`c'..'` 字面量恰好包含一个字节。任意长度的文本用字符串 `"ab"`；非 ASCII 字节写成 `\xHH`。

```nabi norun
let c = 'ab';
```

```text check=checks/E0007.nabi
error[E0007]: char literal must contain exactly one code point
  --> main.nabi:1:9
   |
 1 | let c = 'ab';
   |         ^^^^
```

多于一个字符时，使用字符串：

```nabi
let s = "ab";
println(s);
```

```output
ab
```
