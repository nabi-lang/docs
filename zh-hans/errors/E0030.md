# E0030: 无法解析的导入

`use` 指向了不存在的东西。检查路径：它从包（`pkg::`）、依赖或标准库层级（`std::`、`core::`、`bare::`）开始。

```nabi norun
use std::fss;
```

```text check=checks/E0030.nabi
error[E0030]: unresolved import: `std::fss` does not exist
  --> main.nabi:1:10
   |
 1 | use std::fss;
   |          ^^^
```

修正路径：

```nabi
use std::fs;

println(f"{fs::exists("no-such-file")}");
```

```output
false
```
