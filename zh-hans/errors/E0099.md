# E0099: 不可达的 match 分支

前面的分支已经匹配了这个分支能匹配的所有值，所以它永远不会运行。删除它，或者把它移到覆盖它的分支之前。

```nabi norun
let n = 1;
let r = match n {
    _ => 0,
    1 => 1,
};
```

```text check=checks/E0099.nabi
error[E0099]: unreachable match arm 2: earlier arms already match every value it matches
  --> main.nabi:4:10
   |
 4 |     1 => 1,
   |          ^
```

把兜底分支移到最后：

```nabi
let n = 1;
let r = match n {
    1 => 1,
    _ => 0,
};
println(f"{r}");
```

```output
1
```
