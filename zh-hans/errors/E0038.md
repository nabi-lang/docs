# E0038: 变量与嵌套函数同名

同一个块中的变量和嵌套函数同名。嵌套函数在整个块中都可见，所以这个名称会同时指两者：给其中一个改名。

```nabi norun
fn main() {
    fn step(x: i32) -> i32 { x + 1 }
    let step = 2;
    println(f"{step}");
}
```

```text check=checks/E0038.nabi
error[E0038]: `step` names both a variable and a nested function in this block
  --> main.nabi:3:5
   |
 3 |     let step = 2;
   |     ^^^
   |
   = help: a nested function is seen in its whole block, so rename one of them: `let step2 = ..` or `fn step2(..)`
```

给变量或函数取一个自己的名称：

```nabi
fn main() {
    fn step(x: i32) -> i32 { x + 1 }
    let steps = 2;
    println(f"{step(steps)}");
}
```

```output
3
```

对变量名再写一次 `let` 没有问题：它会创建一个新变量（[5.1.4](../spec/refs-lang/005-modules/501-variable-declaration.html#514-redeclaration-in-the-same-scope)）。
