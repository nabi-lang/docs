# E0103: 看起来像变体的绑定

模式中单独的名称是一个匹配所有值的新变量，除非它恰好是被匹配枚举的变体。这个名称是常量或静态变量，或者与某个变体的名称相近，因此它会绑定所有值。写出变体的路径 `Color::Red`，或者在守卫中比较：`x if x == LIMIT`。

```nabi norun
const LIMIT: i32 = 10;

let n = 3;
match n {
    LIMIT => println("at the limit"),
    _ => println("below"),
}
```

```text check=checks/E0103.nabi
error[E0103]: `LIMIT` here would be a new variable that matches every value, not the const `LIMIT`
  --> main.nabi:5:5
   |
 5 |     LIMIT => println("at the limit"),
   |     ^^^^^
   |
   = help: to compare with the const, write `x if x == LIMIT`
```

在守卫中与常量比较：

```nabi
const LIMIT: i32 = 10;

let n = 3;
match n {
    m if m == LIMIT => println("at the limit"),
    _ => println("below"),
}
```

```output
below
```
