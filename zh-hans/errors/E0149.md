# E0149: 运行中的程序无法接受的修改

热重载构建（`nabi dev`，或者带 `--hot-base` 的 `nabic build --hot`）会与程序当前运行的版本对照检查。程序中的值在修改前后保持存活，并逐个字段地移入新的布局，所以类型可以：

- 增加字段，但必须带默认值（`mana: i32 = 0;`），它会填入每个存活的值中；
- 删除字段、调整字段顺序或重命名字段（重命名的字段用 `#[renamed_from("hp")]` 说明它的旧名称）；
- 增加、调整顺序或删除枚举变体。

类型不能改变字段的类型，不能在 `#[renamed_from]` 中写一个从未存在过的旧字段，不能改变它的类型参数，也不能从结构体变成枚举（或者反过来）。程序会继续运行旧代码；按消息的建议修改，或者重新启动它（在 `nabi dev` 中按 `r`）。

```text
error[E0149]: new field `mana` of `Player` needs a default while the program runs
  --> src/lib.nabi:1:12
   |
 1 | pub struct Player {
   |            ^^^^^^
   |
   = help: write `mana: i32 = 0;` (or restart with `r`)
```

给这个字段一个默认值：

```nabi norun
pub struct Player {
    pub name: str;
    pub hp: i32 = 100;
    pub mana: i32 = 0;
}
```

类型改变了的字段是一个新字段：给它取一个自己的名称并加上默认值（`health: f64 = 100.0`），然后删除旧字段，或者重新启动。
