# E0027: 找不到值或函数

作用域中没有这个名称的值或函数。检查拼写，用 `use` 导入它（help 会列出同名的项），或者先用 `let` 声明它。

```nabi norun
let count = 1;
println(f"{coun}");
```

```text check=checks/E0027.nabi
error[E0027]: cannot find value `coun` in this scope
  --> main.nabi:2:12
   |
 2 | println(f"{coun}");
   |            ^^^^
   |
   = help: did you mean `count`?
```

修正拼写，或者导入该项：

```nabi
let count = 1;
println(f"{count}");
```

```output
1
```

如果其他模块中有同名的项，help 会给出导入它的 `use` 行。对从未用 `let` 声明过的名称赋值是 [E0057](E0057.html)。

相关错误码：[E0028](E0028.html) 找不到类型或 trait，[E0057](E0057.html) 无效的赋值，[E0135](E0135.html) 方法所属的 trait 不在作用域中
