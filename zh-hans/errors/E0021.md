# E0021: 用作名称的保留字

关键字或保留的名称（例如路径根 `pkg`，或者用 `#[keyword]` 注册的关键字）被用作名称。换一个名称，或者写 `r#name` 把关键字保留为名称。

```nabi norun
let gen = 1;
```

```text check=checks/E0021.nabi
error[E0021]: `gen` is a reserved keyword, not a name
  --> main.nabi:1:5
   |
 1 | let gen = 1;
   |     ^^^
   |
   = help: write `r#gen` to keep this name, or rename it; a generator is `yield fn`, `yield { .. }` or `yield || ..`
```

写 `r#gen` 保留这个名称，或者换一个：

```nabi
let r#gen = 1;
println(f"{r#gen}");
```

```output
1
```
