# E0006: 字面量中有无效的转义

字符串或字符字面量中的 `\` 转义不是 Nabi 认识的转义，或者字节串中有它不能容纳的字符。可用的转义有 `\n`、`\r`、`\t`、`\0`、`\\`、`\'`、`\"`、`\xHH` 和 `\u{..}`。字节串只能容纳 ASCII，其他字节写成 `\xHH`（最大 `\xFF`）。

```nabi norun
println("100\% done");
```

```text check=checks/E0006.nabi
error[E0006]: unknown escape sequence `\%`
  --> main.nabi:1:13
   |
 1 | println("100\% done");
   |             ^^
   |
   = help: the escapes are `\n` `\r` `\t` `\0` `\\` `\'` `\"` `\xHH` `\u{..}`; `%` needs no escape, so write `%` (or `\\%` for a backslash and `%`)
```

`%` 不需要转义。要写字面的反斜杠，写 `\\`。

```nabi
println("100% done");
```

```output
100% done
```
