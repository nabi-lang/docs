# E0018: 顶层语句中带值的 `return`

在程序的顶层语句中，单独的 `return;` 会以退出码 0 结束程序。但顶层语句不返回任何值，所以 `return v;` 在那里没有意义。写 `return;`；要用别的退出码，用 `process::exit(code)` 结束程序；或者写 `fn main() -> i32` 并从中返回。

```nabi norun
let code = 2;
if code > 0 { return code; }
```

```text check=checks/E0018.nabi
error[E0018]: top-level `return` takes no value: the program's statements return nothing
  --> main.nabi:2:15
   |
 2 | if code > 0 { return code; }
   |               ^^^^^^
   |
   = help: write `return;` to end the program, or `process::exit(code);` for an exit code (`use std::process;`)
```

写 `return;` 来停止，或者用 `process::exit` 给出退出码：

```nabi
let code = 2;
if code > 0 { return; }    // or process::exit(code) for exit code 2
println("unreached");
```
