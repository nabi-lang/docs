# E0002: 源代码中有双向控制字符

源代码中有 Unicode 双向控制字符（U+202A 到 U+202E，U+2066 到 U+2069）。这些字符会改变文本的显示顺序，使代码读起来与编译器看到的不同。下面的字符串 `"abcdef"` 在 `abc` 和 `def` 之间藏了一个。在字符串里把它写成转义 `"\u{202E}"`，在其他地方一律删除；快速修复会删除它。注释也不例外。

```text check=checks/E0002.nabi
error[E0002]: bidirectional control character U+202E RIGHT-TO-LEFT OVERRIDE in source: it can make code read differently from what the compiler sees
  --> main.nabi:1:17
```

把这个字符写成转义：

```nabi
let label = "abc\u{202E}def";
println(f"{label.len()}");
```

```output
9
```
