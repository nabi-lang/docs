# E0086: 无效的联合体

联合体至少声明一个字段，它的字面量恰好设置其中一个字段，并且不带 `..base`。联合体只接受 `#[repr(C)]`。

```nabi norun
#[repr(C)]
union Empty {}
```

```text check=checks/E0086.nabi
error[E0086]: union `Empty` declares no fields
  --> main.nabi:2:1
   |
 2 | union Empty {}
   | ^^^^^
```

至少声明一个字段。联合体是为了对应 C 的联合体而存在的，所以它是 `#[repr(C)]`，并在 `unsafe` 代码中读取（[第 14 章](../learn/14-ffi.html)）。
