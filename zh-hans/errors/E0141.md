# E0141: 方法的泛型参数与所在 impl 的同名

写在 `impl` 块中的方法声明了一个与 impl 的某个泛型参数同名的泛型参数（`impl<K> W<K> { fn f<K>(..) }`）：在方法中，这个名称可能指其中任何一个。给方法的参数改名（`fn f<K2>`），或者去掉它，使用 impl 的参数。

```nabi norun
struct Wrap<K> { k: K; }

impl<K> Wrap<K> {
    fn pick<K>(self, x: K) -> K { x }
}
```

```text check=checks/E0141.nabi
error[E0141]: generic parameter `K` of `pick` is already a parameter of its `impl`
  --> main.nabi:4:5
   |
 4 |     fn pick<K>(self, x: K) -> K { x }
   |     ^^
   |
   = help: rename the method's (`fn pick<K2>`), or drop it to use the impl's `K`
```

给方法的参数取一个自己的名称：

```nabi
struct Wrap<K> { k: K; }

impl<K> Wrap<K> {
    fn pick<U>(self, x: U) -> U { x }
}

println(Wrap { k: "s" }.pick(5));
```

```output
5
```

trait 的默认方法写在 trait 中，而不是 impl 中，所以它的参数会遮蔽实现它的 impl 中的同名参数，而不会报错（[2.10.1](../spec/refs-lang/002-types/210-generics.html#2101-where-parameters-are-declared)）。
