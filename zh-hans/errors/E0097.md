# E0097: 形状不对的 NABION 值

NABION 文件（`nabi.nabion` 或配置文件）可以解析，但某个值不符合读取方的期望：缺少字段、值的类型不对，或者数字超出范围。按消息指出的写出这个值。

下面的 `nabi.nabion` 把 `version` 写成了数字：

```nabion
Package {
    name: "pk",
    version: 1,
}
```

`nabi check` 输出：

```text
error[E0097]: `version` must be a string, found an integer
  --> nabi.nabion:3:14
   |
 3 |     version: 1,
   |              ^
```

把 `version` 写成字符串 `version: "0.1.0"`。NABION 格式见[第 11 章](../learn/11-modules-packages.html)。
