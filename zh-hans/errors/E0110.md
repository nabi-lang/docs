# E0110: 属性用在了错误的项上

该属性不适用于这种项：用在泛型函数或没有主体的函数上的 `#[export_name]`、用在 `main` 上的 `#[track_caller]`、用在只能带 `#[cfg]` 的语句上的属性。把它移到适用的项上，或者删除它。

```nabi norun
#[link_name("abs")]
fn my_abs(x: i32) -> i32 { x }
```

```text check=checks/E0110.nabi
error[E0110]: `#[link_name]` cannot be attached to a function; it goes on an extern function
  --> main.nabi:1:1
   |
 1 | #[link_name("abs")]
   | ^^
```

把属性放在 `extern` 块中的函数上：

```nabi
extern "C" {
    #[link_name = "abs"]
    fn my_abs(x: i32) -> i32;
}
println(f"{unsafe { my_abs(-2) }}");
```

```output
2
```
