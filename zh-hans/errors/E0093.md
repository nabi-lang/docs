# E0093: 泛型实例化过深

实例化一个泛型函数时，它又用越来越大的类型实例化自身。打破这个递归，例如使用 `any` 参数。

```nabi norun
fn nest<T>(x: T, n: i32) -> i32 {
    if n == 0 { return 0; }
    nest((x, x), n - 1)
}
println(f"{nest(1, 3)}");
```

```text check=checks/E0093.nabi
error[E0093]: instantiating generic function `nest` recursed past the limit (depth 64) - the instantiation never reaches a fixed point
  --> main.nabi:3:5
   |
 3 |     nest((x, x), n - 1)
   |     ^^^^^^^^^^^^^^^^^^^
```

用 `any` 代替类型参数，接受任意类型的值：

```nabi
fn nest(x: any Debug, n: i32) -> i32 {
    if n == 0 { return 0; }
    nest(x, n - 1)
}
println(f"{nest(1, 3)}");
```

```output
0
```
