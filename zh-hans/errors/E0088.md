# E0088: 无效的格式

f-string 的占位格式化了一个不支持该格式的值（`{}` 需要 `Display`，`{:?}` 需要 `Debug`），或者它的格式说明符无效。实现或派生这个 trait，或者修改格式说明符。

```nabi norun
let name = "nabi";
println(f"{name:x}");
```

```text check=checks/E0088.nabi
error[E0088]: format type `x` needs an integer, found `str`
  --> main.nabi:2:12
   |
 2 | println(f"{name:x}");
   |            ^^^^
```

使用适合这个值的格式：

```nabi
let n = 255;
println(f"{n:x}");
```

```output
ff
```
