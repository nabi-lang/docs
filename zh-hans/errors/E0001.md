# E0001: 源代码中有意外的字符

源代码中有一个不能开始任何词法单元的字符：孤立的 `#` 或 `$`、不在第一行的 `#!` 行、前面没有字母的组合符号、Unicode 尚未分配的码位，或者作用域中没有任何 trait 注册的运算符符号，例如 `⊛`。删除它，或者把它写在字符串或注释里。要使用运算符符号，需要把注册它的包加为依赖，或者在你自己的 trait 方法上加 `#[infix(..)]`。

```nabi norun
let price = $5;
```

```text check=checks/E0001.nabi
error[E0001]: unexpected character(s) `$`
  --> main.nabi:1:13
   |
 1 | let price = $5;
   |             ^
```

删除这个字符，或者把它放进字符串。带单位的数字是紧贴在数字后面的后缀名，而不是符号（`5usd`，[E0114](E0114.html)）：

```nabi
let price = 5;
println(f"${price}");
```

```output
$5
```
