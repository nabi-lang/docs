# E0043: 没有这个字段

该类型没有这个名称的字段（或者元组在这个索引处没有元素）。对照类型的定义检查拼写。

```nabi norun
struct P { x: i32; y: i32; }

let p = P { x: 1, y: 2 };
println(f"{p.z}");
```

```text check=checks/E0043.nabi
error[E0043]: struct `P` has no field `z`
  --> main.nabi:4:12
   |
 4 | println(f"{p.z}");
   |            ^^^
   |
   = help: available fields: `x`, `y`
```

使用该类型拥有的字段；help 会列出它们：

```nabi
struct P { x: i32; y: i32; }

let p = P { x: 1, y: 2 };
println(f"{p.y}");
```

```output
2
```
