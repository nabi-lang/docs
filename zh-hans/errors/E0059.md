# E0059: 关键字在其上下文之外

`break` 和 `continue` 只能用在循环中，`yield` 只能用在生成器中，`await` 只能用在异步主体中，`self` 只能用在方法中；`return`、`break` 和 `continue` 不能离开 `finally` 块；`break value` 只能离开 `loop` 或带标签的块，不能离开 `while` / `for`。把代码移到这样的主体中，或者移出 `finally`。

```nabi norun
let n = 3;
if n > 2 { break; }
```

```text check=checks/E0059.nabi
error[E0059]: `break` outside of a loop
  --> main.nabi:2:12
   |
 2 | if n > 2 { break; }
   |            ^^^^^
```

在循环中使用 `break`：

```nabi
for n in 0..5 {
    if n > 2 { break; }
    println(f"{n}");
}
```

```output
0
1
2
```
