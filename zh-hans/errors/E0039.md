# E0039: 嵌套项使用了外层的局部变量

嵌套的 `fn`、`struct` 或 `impl` 不能使用外层函数的局部变量或泛型参数。把值作为参数传入，或者使用能捕获它的闭包。

```nabi norun
fn wrap<T>(t: T) -> i32 {
    struct Holder { v: T; }
    0
}
```

```text check=checks/E0039.nabi
error[E0039]: `Holder` is declared inside `wrap` and can't use `T`, a generic parameter of `wrap`; declare its own instead: `struct Holder<T>`
  --> main.nabi:2:24
   |
 2 |     struct Holder { v: T; }
   |                        ^
```

给嵌套项声明它自己的参数，或者把它声明在函数之外：

```nabi
struct Holder<T> { v: T; }

fn wrap<T>(t: T) -> Holder<T> {
    Holder { v: t }
}
println(f"{wrap(5).v}");
```

```output
5
```

使用外层函数局部变量的嵌套 `fn` 也会得到同样的错误码；闭包（`let add = |x: i32| x + base;`）可以捕获该局部变量。

相关错误码：[E0027](E0027.html) 找不到值或函数，[E0058](E0058.html) 无效的闭包捕获
