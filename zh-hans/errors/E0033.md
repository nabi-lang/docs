# E0033: 无效的重新导出

`pub use` 违反了规则：它比所重新导出的项可见范围更大、它重新导出了宏，或者重新导出形成了循环。让该项与重新导出同样可见，或者修改重新导出。

```nabi norun
pub use inner::helper;

mod inner {
    fn helper() -> i32 { 1 }
}
```

```text check=checks/E0033.nabi
error[E0033]: `inner::helper` is private but re-exported as `pub` - a re-export can't be wider than its item
  --> main.nabi:1:9
   |
 1 | pub use inner::helper;
   |         ^^^^^
```

让该项与重新导出同样可见：

```nabi
pub use inner::helper;

mod inner {
    pub fn helper() -> i32 { 1 }
}
println(f"{helper()}");
```

```output
1
```
