# E0111: 无效的 `#[lang]` 项

`#[lang("slot")]`（仅限标准库）指定一个已知的槽，只能写一次，并且用在符合该槽形式的项上。

```nabi norun
#[lang("add_trait")]
trait BadAdd { fn plus(self, o: Self) -> Self; }
```

```text check=checks/E0111.nabi
error[E0111]: `BadAdd` does not match the form of lang slot `add_trait`: it needs `fn add(self, _)`
  --> main.nabi:1:1
   |
 1 | #[lang("add_trait")]
   | ^^
```

`#[lang]` 是给标准库用的。程序应当实现标准 trait：`impl ops::Add for Point` 让 `Point` 拥有 `+` 运算符。
