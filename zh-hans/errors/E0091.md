# E0091: 无效的广播

广播调用 `f.(xs)` 对 `List`、`Slice` 或数组逐元素映射，一起传入的数组长度必须相同。传入长度一致的集合。一个点表达式只能接受 core 的集合或 `Broadcastable` 类型（`Array`）之一，不能两者混用：用 `Array::from_list(xs, [xs.len()])` 把列表变成 `Array`。`.=` / `.+=` 等写入 `List`、定长数组或 `Array`（包括它们的视图），操作数必须符合其形状；`.??` 需要一个容器操作数。

```nabi norun
fn add(a: i32, b: i32) -> i32 { a + b }

let xs: [i32; 3] = [1, 2, 3];
let ys: [i32; 4] = [10, 20, 30, 40];
println(f"{add.(xs, ys):?}");
```

```text check=checks/E0091.nabi
error[E0091]: broadcast over arrays of lengths 3 and 4
  --> main.nabi:5:12
   |
 5 | println(f"{add.(xs, ys):?}");
   |            ^^^^^^^^^^^^
```

传入长度相同的数组：

```nabi
fn add(a: i32, b: i32) -> i32 { a + b }

let xs: [i32; 3] = [1, 2, 3];
let ys: [i32; 3] = [10, 20, 30];
println(f"{add.(xs, ys):?}");
```

```output
[11, 22, 33]
```

点语法的其他误用也是这个错误码，每种都有给出修正写法的 help。一个点表达式只能接受 core 的集合（`List`、`Slice`、定长数组）或 `Array` 这样的 `Broadcastable` 类型之一，不能两者混用：

```nabi
use core::array::Array;

let xs = [1.0, 2.0];
let a = Array::from_list(xs, [xs.len()]);
let b: Array<f64, 1> = [10.0, 20.0];
println(f"{a .+ b:?}");
```

```output
[11.0, 22.0]
```

`.=` 和 `.+=` 等写入 `List`、定长数组或 `Array`（包括它们的视图），操作数必须符合其形状；`Slice` 是只读的，其他目标则把运算展开来写（`x = x .+ ..;`）。`.??` 需要一个容器操作数；单个值写 `x ?? y`。
