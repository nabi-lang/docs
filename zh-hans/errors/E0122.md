# E0122: 文件包含失败

`include_str!` / `include_bytes!` 接受一个字符串路径，它相对于当前文件，并且指向一个可读的文件。

```nabi norun
let s = include_str!("missing.txt");
```

```text check=checks/E0122.nabi
error[E0122]: `include_str!` cannot read "missing.txt": no such file
  --> main.nabi:1:9
   |
 1 | let s = include_str!("missing.txt");
   |         ^^^^^^^^^^^
```

在 `main.nabi` 旁边创建 `missing.txt`，或者修正路径。路径相对于含有 `include_str!` 的文件。

相关错误码：[E0125](E0125.html) 无法读取或写入文件
