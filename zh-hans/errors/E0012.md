# E0012: 其他语言的语法

代码使用了 Nabi 没有的写法：`c ? a : b` 运算符、`++` / `--` 或 `let mut`。消息会给出 Nabi 的写法：`if c { a } else { b }`、`x += 1` 或普通的 `let`（变量是可变的）。

```nabi norun
let mut n = 0;
```

```text check=checks/E0012.nabi
error[E0012]: Nabi has no `let mut`: variables are mutable by default
  --> main.nabi:1:5
   |
 1 | let mut n = 0;
   |     ^^^
   |
   = help: drop `mut`: `let n = ..;`
```

去掉 `mut`；每个变量都可以赋值：

```nabi
let n = 0;
n += 1;
println(f"{n}");
```

```output
1
```
