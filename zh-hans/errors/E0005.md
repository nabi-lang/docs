# E0005: 未结束的字面量或注释

字符串、字符、字节串、f-string、原始字符串或块注释开始了却没有结束。加上结尾的引号或 `*/`。原始字符串结尾的 `#` 个数要与开头相同。

```nabi norun
/* the greeting
println("hi");
```

```text check=checks/E0005.nabi
error[E0005]: unterminated block comment
  --> main.nabi:1:1
   |
 1 | /* the greeting
   | ^^^^^^^^^^^^^^^
```

结束这个注释：

```nabi
/* the greeting */
println("hi");
```

```output
hi
```
