# E0062: 错误未处理

调用可能抛出错误，而这个错误既没有被捕获，也没有被声明。用 `try` 标记调用，然后捕获错误，或者把它加到外层函数的 `throws` 中。

```nabi norun
let n = "42".parse::<i32>();
```

```text check=checks/E0062.nabi
error[E0062]: this call can throw `ParseError` and must be marked with `try` (`try f()`; `try? f()` / `try! f()` to drop / panic on the error)
  --> main.nabi:1:9
   |
 1 | let n = "42".parse::<i32>();
   |         ^^^^^^^^^^^^^^^^^^^
```

用 `try` 标记调用，并在错误继续向外传递的地方声明 `throws`：

```nabi
fn parse_n(s: str) throws -> i32 {
    try s.parse::<i32>()
}

println(f"{try parse_n("42")}");
```

```output
42
```

`try? f()` 把错误变成 `none`，`try! f()` 遇到错误时触发 panic（[第 10 章](../learn/10-errors.html)）。
