# E0060: 不发散的 `let .. else`

`let .. else` 的 `else` 块在模式不匹配时运行，所以它必须离开当前作用域：以 `return`、`break`、`continue` 或 `throw` 结束。

```nabi norun
fn first(xs: List<i32>) -> i32 {
    let n = xs.first() else {
        println("empty");
    };
    n
}
```

```text check=checks/E0060.nabi
error[E0060]: the `else` block of `let ... else` must diverge (end in `return`, `break`, `continue` or `throw`)
  --> main.nabi:2:13
   |
 2 |     let n = xs.first() else {
   |             ^^^^^^^^^^
```

在 `else` 块中离开函数：

```nabi
fn first(xs: List<i32>) -> i32 {
    let n = xs.first() else {
        return 0;
    };
    n
}
println(f"{first([])} {first([4])}");
```

```output
0 4
```
