# E0145: 具名 `some` 类型不是由其模块定义的

`type X = some Tr;` 是一个具体类型，由 X 所在模块中返回 `X` 的函数（`fn make() -> X { .. }`）通过函数体给出。该模块中没有这样的函数、这些函数给出的类型不同，或者其中有泛型函数。在该模块中添加一个返回 `X` 的函数，让每个函数都返回同一个类型（让其他函数调用第一个），或者不要让类型参数参与其中：泛型的不透明结果写成 `fn f<T>(..) -> some Tr`。

```nabi norun
type Evens = some Iterator<Item = i64>;

println("no evens yet");
```

```text check=checks/E0145.nabi
error[E0145]: `Evens` has no defining function
  --> main.nabi:1:1
   |
 1 | type Evens = some Iterator<Item = i64>;
   | ^^^^
   |
   = help: a function in this module that returns `Evens` gives its type: `fn make() -> Evens { .. }`
```

添加一个返回它的函数：

```nabi
type Evens = some Iterator<Item = i64>;

fn evens(n: i64) -> Evens {
    (0..n).filter(|x| x % 2 == 0)
}

println(evens(7).count());
```

```output
4
```
